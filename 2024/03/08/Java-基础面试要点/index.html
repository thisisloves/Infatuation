Java 基础面试要点

2024-03-08
  • Java
本文总阅读量次

明月松间照，清泉石上流。

面向对象四个特征

四个词各记一句，再配一个能讲出来的例子。

  • 封装：字段私有，只通过方法读写，调用方不依赖存储方式。
  • 继承：子类复用父类成员并扩展。Java 类单继承，接口可以多实现。
  • 多态：编译期看父类型，运行期走实际子类的实现。
  • 抽象：只约定「能做什么」，「怎么做」留给子类或实现类。

name 外部改不了，这是封装。Dog 复用构造和 name()，这是继承。变量类型是 Animal，实际执行 Dog.speak，这是多态。speak 没有方法体，这是抽象。

抽象类可以带字段和已实现方法，表达「是一种」。接口表达能力，一个类可以实现多个；Java 8 起接口可以有 default 方法。

JDK、JRE 与 JVM

三者是包含关系：JDK 包含 JRE，JRE 包含 JVM。JDK 11 起不再单独发布 JRE，层次仍然是这三层。

名称 职责 组成
JVM 执行字节码 类加载、运行时数据区、执行引擎、垃圾回收
JRE 运行已编译程序 JVM + 核心类库
JDK 开发与编译 JRE + javac、javap、jdb 等

.java 由 javac 编成平台无关的 .class，再由各平台自己的 JVM 解释或即时编译成机器码。「一次编写、到处运行」靠的是字节码加上各平台 JVM，不是同一份机器码。只部署运行环境时 JRE 够用；要编译、反编译、调试，需要 JDK。

八种基本类型

局部变量里的基本类型放在栈帧的局部变量表；作为对象字段时随对象在堆上。它们不是引用。

类型 位宽 包装类 范围或备注
byte 8 Byte −128 ~ 127
short 16 Short
int 32 Integer 整数字面量默认是 int
long 64 Long 字面量加 L
float 32 Float 字面量加 F
double 64 Double 浮点字面量默认是 double
char 16 Character 无符号 Unicode 码元
boolean 未规定 Boolean 见下

boolean 的占用在《Java 虚拟机规范》里没有定义。字节码里它被当成 int 的 0 和 1；boolean[] 占多少由具体虚拟机决定，HotSpot 里常见是每个元素 1 字节。不要答「一定 1 位」或「一定 4 字节」。

byte、short、char 参与运算前会提升为 int。float 和 double 是二进制浮点，0.1 + 0.2 不等于 0.3，金额用 BigDecimal。

== 与 equals

== 比的是两边的值。基本类型比数值；引用类型比两个引用是否指向同一对象。

Object.equals 默认就是 ==。String、包装类重写后改为比内容。自己的类若按内容判等，必须同时重写 hashCode：equals 为 true 的两个对象，哈希必须相同，否则放进 HashMap、HashSet 会丢。反过来不要求：哈希相同也可以不相等，那只是冲突。

字面量进字符串常量池。JDK 7 起常量池在堆里。new String("hi") 会在堆上再分配一个对象，池中仍保留字面量那一份。intern() 把当前字符串放进池中（已有则不重复），并返回池中引用。编译期能确定的拼接会折叠成一个字面量；运行期 + 走 StringBuilder，结果默认不进池。

访问修饰符

从宽到窄：public、protected、默认（不写）、private。表中「不同包子类」指子类定义在另一个包。

修饰符 本类 同包 不同包子类 其他包
public 是 是 是 是
protected 是 是 是 否
默认 是 是 否 否
private 是 否 否 否

默认没有关键字，省略修饰符就是包可见。接口方法默认 public，不要和类成员的默认访问混为一谈。顶层类只能 public 或包可见；private、protected 用在成员和内部类上。

跨包时，子类只能访问自己继承到的 protected 成员，不能拿一个父类引用去点另一个对象的 protected 字段。

包装类与自动装箱

每种基本类型对应一个不可变包装类。编译器在需要对象时插入 valueOf（装箱），在需要基本类型时插入 xxxValue（拆箱）。

Integer.valueOf 缓存 −128 到 127。范围内多次装箱是同一对象，范围外每次新建。上限可用 -XX:AutoBoxCacheMax 调高，下限固定 −128。

Long、Short、Byte 同样缓存 −128127，Character 缓存 0127。Float、Double 没有这段缓存。new Integer(1) 绕过缓存，两个 new 用 == 一定是 false（该构造器已废弃）。

包装类比数值用 equals，或先拆成基本类型再 ==。拆箱遇到 null 会空指针：Integer x = null; int n = x; 就是在 null 上调用 intValue()。集合只能存对象，基本类型放进去必装箱，循环里的计数器不要无谓地用包装类。
