子查询

  • 一个 select 语句中包含另一个完整的 select 语句。

  • 子查询就是嵌套查询，即 SELECT 中包含 SELECT，如果一条语句中存在两个，或两个以上 SELECT，那么就是子查询语句了。

where 型子查询

  • 查询除小明之外所有同学院的同学的姓名
  1. 查询小明学院 id
  1. 查询学院所属学生
  1. 组合

from 型子查询

  • 查询在公司代码为 222333 的同学并且学院 id 为 203 的学生名
  1. 查询公司代码为 222333 的同学
  1. 查询学院 id 为 203 的学生
  1. 组合

in 子查询

  • 查询大于 21 岁的学院名
  1. 查询大于 21 岁的学院 id
  1. in 查询多个学院 id 的学院名

exists 子查询

  • 查询学生年龄大于 22 岁的学院是否存在
  1. 查询大于 22 岁学生学院 id
