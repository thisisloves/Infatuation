SQL 操作函数

2024-11-18
  • SQL
本文总阅读量次

自来积毁骨能销，何况真红一点臂砂娇。

以下示例偏 MySQL 方言；标准 SQL 里大小写常用 UPPER / LOWER，子串常用 SUBSTRING。

UCASE() / LCASE()

  • 把字符串转成大写 / 小写（等价于 UPPER / LOWER）。

MID() / SUBSTRING()

  • MID(str, start, length)：从 start（从 1 计）起取 length 个字符。
  • 取第 2、第 3 两个字符：MID(user, 2, 2)；若要「第 2 到第 4 位」共 3 个字符，应写 MID(user, 2, 3)。

LENGTH()

  • MySQL 里 LENGTH 按字节计；多字节字符用 CHAR_LENGTH 按字符计更直观。

ROUND()

NOW()

FORMAT() 与 DATE_FORMAT()

  • **FORMAT(x, d)**：把数字格式化成带千分位的字符串，并保留 d 位小数（结果是字符串）。
  • 日期格式化用 **DATE_FORMAT**，不要和 FORMAT 混用。
