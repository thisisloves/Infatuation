Java 继承

2024-07-19
  • Java
本文总阅读量次

东边日出西边雨，道是无晴却有晴。

继承是什么

继承让子类复用父类的字段和方法，并在此之上扩展。子类对象里包含父类那一部分状态。is-a 关系才适合继承：企鹅是动物。仅仅为了复用几个方法，用组合（类里放一个成员对象）更稳，继承会把父子绑死。

单继承与多层继承

Java 的类只能 extends 一个直接父类，不能像 C++ 那样同时继承两个类。没有写 extends 时，默认继承 Object。

多层继承是允许的：Grandson 继承 Son，Son 继承 Father。这时 Father 是 Grandson 的祖先类，不是「多继承」。多继承（一个类有多个父类）才是被禁止的。

多个类型能力用接口：class Tiger implements Animal, Runnable。接口之间也可以 extends 多个接口。这不是类的多继承。

说法 在 Java 中
一个类继承多个类 不允许
A→B→C 一层层继承 允许
一个类实现多个接口 允许
一个接口继承多个接口 允许

子类能访问父类的 public / protected / 同包成员，不能访问 private 成员。对象里仍然有父类的私有字段，只是子类代码不能直接读写，要通过父类提供的方法。

继承提高复用，也提高耦合：父类一改，子类全部受影响。继承层次宜短。

extends

子类类型和父类类型要各自把花括号闭合。把 class Penguin 写在 Animal 的方法后面却不闭合 Animal，会变成内部类或直接编译失败。方法名 penguin(...) 也不会变成构造器。

this 与 super

  • this：当前对象。this.字段 区分参数和字段，this(...) 调用本类另一个构造器。
  • super：父类那一部分。super.方法() 调用父类实现，super(...) 调用父类构造器。

this(...) 和 super(...) 都必须是构造器的第一条语句，因此不能同时出现。实例方法里可以用 super.eat()，那不是构造器调用。

父类方法与子类方法参数不同时，这是重载，不是重写。上面的 Dog.eat() 并没有覆盖 Animal.eat(String)。

构造器不被继承

子类不继承父类构造器，但创建子类对象时一定会先跑父类构造器。

  • 子类构造器第一条如果没写 super(...) 或 this(...)，编译器插入 super()。
  • 父类没有无参构造器时，子类必须显式 super(参数)，否则编译失败。
  • 父类构造器是 private 时，子类写不了 super(...)，也就不能在外部被继承（嵌套类另说）。

new SubClass() 输出父类无参，再输出子类无参。new SubClass(100) 只走父类的 int 构造器，不会再自动调用父类无参构造器。

名字和类一样、但写了返回类型的 public void Son() 是普通方法，不会在 new Son() 时执行。构造器没有返回类型。

继承来的成员

成员 子类
public / protected 方法 可调用，符合规则时可重写
同包的包级方法 同包可访问、可重写
private 方法 不可见，子类同名方法是全新方法
static 方法 可隐藏，不是多态重写
final 方法 可调用，不可重写
构造器 不继承，只链式调用
字段 子类同名字段会隐藏父类字段，不存在字段多态

多层继承时，Grandson 能调用祖先类上可见的实例方法。静态方法用类名调用最清楚：Father.work(...)。私有字段在子类里不能写 grandson.name 去读父类的 private name。

常见坑

  1. 为了复用而继承，子类并不真的是父类，之后无法替换进父类参数（违反里氏替换）。
  2. 构造器里调用可被重写的方法：子类字段可能还没初始化。
  3. 把普通方法当成构造器，new 之后该逻辑没执行。
  4. 子类字段和父类字段同名，读到的是哪一个取决于引用的编译期类型，不是运行期类型。
  5. 接口常量是 public static final，用 super.name 去理解「父类字段」会对不上。

小结

类是单继承、可多层；多个能力用接口。子类对象先构造父类部分。super 用来调用父类构造器或父类实现，this 指向当前对象。构造器和私有成员不能当「继承来的 API」使用。能用组合说清楚的关系，不必做成继承。
