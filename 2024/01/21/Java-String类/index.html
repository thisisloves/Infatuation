Java String 类

2024-01-21
  • Java
本文总阅读量次

可惜一溪风月，莫教踏碎琼瑶。

String 是不可变对象

字符串是对象，由 java.lang.String 表示。String 是 final 类，内部的字符内容创建后不能改。trim、replace、concat 都返回新字符串，原对象保持原样。

因为不可变，String 可以被多个线程共享，也适合做 HashMap 的键（hashCode 会缓存）。大量拼接不要用 + 循环，那会不断产生中间字符串，应使用 StringBuilder。

字面量与 new

字面量放在字符串常量池里。自 Java 7 起，常量池在堆中，不再位于永久代。相同字面量（以及编译期常量表达式）会指向池中同一对象，所以 s1 == s2 为 true，s3 与 s1 也是同一引用。

new String("Runoob") 会在堆上再做一个内容相同的新对象，s4 == s5 为 false，但 s4.equals(s5) 为 true。内容比较用 equals，不要用 ==，除非你就是在比较是不是同一个对象。

从 char[] 构造会复制字符。之后修改数组不会改已经生成的 String。

intern() 把与当前内容相等的池中字符串返回给你（没有则放入池）。滥用 intern 会撑大常量池，普通业务用 equals 即可。

常用操作

length() 返回 UTF-16 码元个数，不是「用户看到的字符数」。一个 emoji 可能占两个 char，length() 为 2。

连接：

+ 在一行字面量上会在编译期折成一个字符串。在循环里对变量反复 + 则是运行期拼接。

String.format 返回新字符串，printf 直接打到流上，两者格式相同。

方法对照

下面只列常用、签名正确的方法。equals 的参数类型是 Object，不是 Objectc。replace / replaceAll 各有各的用途，不要在表里重复两行还写错参数。

方法 作用
charAt / length 按下标取码元、码元个数
equals / equalsIgnoreCase 比较内容，后者忽略大小写（按指定规则，不是所有语言都直观）
compareTo 按字典序比较，实现 Comparable<String>
contains / startsWith / endsWith 是否包含、以前缀或后缀开始
indexOf / lastIndexOf 第一次或最后一次出现的下标
substring(begin, end) 子串，end 不含
concat 或 + 连接，得到新字符串
replace(CharSequence, CharSequence) 按字面量替换
replaceAll / replaceFirst 按正则替换。普通句点要写成 \\.
split 按正则切开。分隔符是正则
trim 去掉首尾码点 ≤ U+0020 的字符
strip / isBlank Java 11 起。strip 按 Unicode 空白裁剪，isBlank 为真表示空或只有空白
toLowerCase / toUpperCase 大小写转换，可传入 Locale，土耳其语的 i 是经典例外
valueOf 把基本类型或对象转成字符串。valueOf((Object) null) 得到 "null"；直接写 valueOf(null) 会因重载不明确而编译失败

contentEquals 可以和任意 CharSequence（包括 StringBuffer）比内容。getBytes() 使用平台默认字符集，文件和网络协议应写明 StandardCharsets.UTF_8。

Java 7u6 之后，substring 会复制底层数组，不再和原字符串共享存储。老文章里「substring 导致原大字符串无法回收」已经过时。

常见坑

  1. == 比较字符串内容。常量池碰巧相同时测试能过，new 或拼接结果一变就失败。
  2. 调用 s.equals("a") 时 s 为 null。常量放前面："a".equals(s)。
  3. split(".") 按「任意字符」切开，几乎得到一串空串。字面点号用 split("\\.")。
  4. replaceAll("$", ...) 或替换串里的 $ 被当成组引用。字面替换用 replace，或 Matcher.quoteReplacement。
  5. 循环里 s = s + piece。改成 StringBuilder。
  6. 用 length() 和 charAt 截取 emoji、汉字扩展区字符，会把代理对砍成一半。按码点用 codePointCount / offsetByCodePoints。

小结

String 不可变，字面量进常量池，new 出来的是另一个对象。比内容用 equals，拼接用 StringBuilder，子串下标是半开区间。replace 是字面量，replaceAll 是正则。涉及编码时显式使用 UTF-8。
