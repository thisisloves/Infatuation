从 println 看方法调用

System.out.println() 里，println 是方法，out 是 System 类里的静态字段（PrintStream 类型），System 是 java.lang 中的类。这句话是：用类名找到 System，用它的 out 找到输出流，再调用该对象的 println。

方法是类或对象上的一段可重复调用的逻辑。它让代码变短、便于维护，也避免把同一段计算复制到多处。

方法如何定义

  1. 修饰符：可选，如 public、static，决定谁能调用、是否依赖对象。
  2. 返回类型：要返回的数据类型。不返回值就写 void。
  3. 方法名：小驼峰，动词开头，如 addPerson。测试方法里偶尔用下划线分隔场景，如 testPop_emptyStack，普通业务方法不用下划线。
  4. 参数：形参是占位符。调用时传入的值叫实参，不是「再声明一个变量类型」。参数列表可以为空。
  5. 方法体：具体语句。

方法签名是方法名加上参数类型列表，不含返回类型，也不含参数名。int max(int, int) 和 double max(int, int) 签名相同，不能同时存在。返回类型不同解决不了重载。

void 方法可以用不带值的 return; 提前结束，不能 return 1;。非 void 方法的每条路径都必须返回对应类型的值。

参数是传值

Java 只有值传递。

  • 基本类型：形参得到实参的拷贝，方法里修改形参不影响调用方。
  • 引用类型：拷贝的是引用这个值。方法里可以改对象的字段，调用方看得到；如果形参被重新 new 或指向别的对象，调用方的变量仍指向原来的对象。

调用后 n 的实参不变，StringBuilder 的内容多了一个 !，但不会变成 "other"。

重载、可变参数与递归

同一类里方法名相同、参数类型或个数或顺序不同，就是重载。编译器根据实参静态选择，和运行时对象的真实类型无关。

可变参数必须是最后一个参数，方法内当作数组使用。void log(String level, String... msgs) 可以接受 0 个或多个 String。不要再写一个 log(String level, String[] msgs)，签名冲突。

递归方法必须有能到达的终止条件，否则 StackOverflowError。能用循环说清的，通常循环更省栈。

静态方法与实例方法

静态方法 实例方法
调用 类名.方法() 引用.方法()
this 没有 指向当前对象
能直接访问 静态成员 静态和实例成员

main 必须是 public static void main(String[] args)，因为 JVM 启动时还没有你的对象。工具函数如果只用参数计算、不碰实例状态，适合写成 static。

构造器名字与类相同、没有返回类型，负责初始化新对象。它不是普通方法，不能被继承，也不能随意当成员方法调用。

常见坑

  1. 把返回类型当成重载依据，编译器报「方法已定义」。
  2. void 方法里 return 表达式;，或漏写 return。
  3. 以为改了对象参数的引用，外面的变量会跟着变。
  4. 实例方法写成静态后继续用 this 或实例字段。
  5. 递归没有基准情况；或者基准情况在递归调用之后才判断，实际上仍会无限递归。

小结

方法用签名（名字 + 参数类型）区分，返回类型不参与签名。调用时实参按值拷贝进去。没有结果就写 void，需要中途退出就用空的 return。依赖对象状态的做成实例方法，只处理参数的做成静态方法。
