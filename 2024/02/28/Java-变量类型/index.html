Java 变量类型

2024-02-28
  • Java
本文总阅读量次

变量是什么

变量是带类型、带名字的存储位置。Java 里变量必须先声明再使用，声明时类型就固定了。

type 是数据类型，identifier 是名字。一次声明多个变量时，类型只写一遍：int i = 0, j = 1;。

命名约定：变量、参数用 lowerCamelCase；常量（static final）用 UPPER_SNAKE；类名用 UpperCamelCase。名字不能是关键字，区分大小写。

三种变量

按声明位置分，不要和「基本类型 / 引用类型」混为一谈。那是数据种类，这是变量活在哪里。

种类 声明位置 修饰 一份拷贝属于 默认值
局部变量 方法、构造器、代码块、参数 不能是 static 每次调用 无，必须赋值
实例变量 类里、方法外 无 static 每个对象 有
类变量 类里、方法外 static 整个类一份 有

局部变量

局部变量在栈帧里，方法返回就消失。编译器要求：每条可能读到它的路径上都已经赋过值（明确赋值）。只声明 int i; 然后打印，无法编译。

参数也是局部变量，由调用方传入，方法里给参数重新赋值不会改掉调用方的变量。循环变量的作用域是循环本身（Java 的 for 里声明的变量出了循环就不能用）。

成员变量可以和局部变量同名，方法里不写前缀时优先指局部变量，要用成员必须写 this.字段名。

实例变量

实例变量在方法、构造器、实例初始化块之外声明。对象被 new 出来时分配，对象不可达后由垃圾回收回收。

  • 每个对象各有一份，改 a.name 不影响 b.name。
  • 在实例方法里可以直接写字段名。
  • 在静态方法里没有 this，必须通过引用访问：emp.name。正确拼写是 objectReference.variableName。
  • 可用访问修饰符限制可见性。对子类可见不等于「全世界可写」，字段尽量 private，用方法修改。

「对象一创建，实例变量的值就确定」只对了一半：先按默认值初始化，再跑实例初始化块和构造器，之后还可以被方法改掉。

类变量

用 static 声明、写在方法外面。无论 new 多少次，静态变量只有一份，属于类而不属于某个对象。

类初始化发生在该类第一次主动使用时（创建实例、调用静态方法、读非常量静态字段等），此时按文本顺序执行静态字段初始化和静态块。不是「某个字段第一次被点名时单独诞生」，也不要理解成每个对象创建时复制一份。类可以被卸载（其类加载器可回收时），不一定非要等到进程结束。

访问方式优先 ClassName.variableName。用 对象.静态变量 能编译，但容易让人以为它是实例字段。

static final 是编译期常量时（基本类型或 String 字面量），可以在不触发类初始化的情况下内联进调用方。非常量静态字段则不行。

实例变量和静态变量都不要滥用公有可变状态。静态可变字段还会带来线程安全问题：多个线程同时 salary++ 不是原子的。

常见坑

  1. 在静态方法里直接写实例字段，编译错误：没有当前对象。
  2. 局部变量加 static 不合法。
  3. static 字段之间互相引用时，顺序就是初始化顺序，写在前面的还没赋完值，读到的是默认值。
  4. 没使用的 import java.io.* 对变量没有任何作用，示例里不需要它。
  5. 参数名和字段同名时忘记 this.salary = salary，字段保持默认值 0。

小结

先问变量属于一次调用、一个对象，还是整个类。局部变量必须赋值；实例变量每人一份；静态变量全类一份，在类初始化时准备好。对外尽量少暴露字段，用方法表达「允许怎样改」。
