两类修饰符

修饰符分访问控制和非访问两类，可以组合，但组合必须合法。

访问控制

类成员有四种可见性。default 不是关键字，而是什么都不写，又叫包级私有。

级别 写法 同类 同包 子类（不同包） 其他包
公共 public 允许 允许 允许 允许
受保护 protected 允许 允许 允许 不允许
包级 （不写） 允许 允许 不允许 不允许
私有 private 允许 不允许 不允许 不允许
  • public 可用于顶层类、接口、成员。一个源文件最多一个 public 顶层类型，且文件名必须与它相同。
  • private、protected、包级都不能修饰顶层类。它们可以修饰成员，也可以修饰嵌套类。
  • 不同包的子类能访问自己继承来的 protected 成员，但不能通过另一个父类引用去碰那个对象的 protected 成员。
  • 字段优先 private。需要给子类开洞时再用 protected，不要为了图省事写成 public。

static

static 表示属于类，不依赖实例。静态变量全类一份；静态方法没有 this，只能直接访问静态成员。局部变量不能是 static。

静态方法里出现实例字段，是编译错误，不是运行期才发现。

final

final 表示「之后不能改这份绑定」。

  • 变量：基本类型不能改值；引用不能改指向，但对象内容仍可改。实例字段可以在声明时赋值，也可以在每个构造器里赋值（空白 final）。static final 在声明处或静态块里赋值。
  • 方法：子类可以继承、可以调用，不能重写。
  • 类：不能被继承。abstract 与 final 不能同时用在类上。

final 引用加上不可变对象（例如 String）才是真正的常量。static final List 仍可以 add。

abstract

abstract 用来声明「还没实现、不能直接 new」的类或方法。

  • 含抽象方法的类必须是抽象类；抽象类可以没有抽象方法。
  • 抽象类不能实例化，可以有构造器，供子类 super(...) 调用。
  • 子类要么实现全部抽象方法，要么自己也声明为 abstract。
  • 抽象方法没有方法体，以分号结束，并且必须有返回类型：public abstract void sample();。写成 public abstract sample(); 不合法。
  • 抽象方法不能是 private、final、static：它们都无法被实例重写。抽象类里可以另有普通的静态方法。

synchronized 与 volatile

二者用于并发，不是访问级别，不能拿来「修饰那四个访问修饰符」。访问修饰符和 synchronized 只是可以写在一起，例如 public synchronized void show()。

  • synchronized 方法同一时刻只允许一个线程进入。实例方法锁的是 this，静态方法锁的是 Class 对象。它保证互斥和可见性，粒度是整段方法；只需要保护几行时用同步块。
  • volatile 保证该字段的写对其他线程立刻可见，并禁止某些重排序。它不保证 count++ 这种读改写的原子性。引用本身也可以是 null，volatile 并不负责非空。

transient

transient 标记实例字段不进入默认序列化。它不是「预处理数据类型」。静态字段本来就不属于对象，序列化不会写它，再加 transient 没有序列化上的意义。

敏感信息（密码、密钥）应 transient，或改用可控的外部格式，而不是依赖原生序列化。

其他

  • native：方法实现在 Java 之外（通常是 JNI），没有 Java 方法体。
  • strictfp：老版本用来强制浮点计算严格遵循 IEEE 754。自 Java 17 起，浮点语义始终严格，这个关键字不再改变行为。

常见坑

  1. 顶层类写成 private class。
  2. 抽象方法漏返回类型，或加上 static。
  3. 以为 final 集合不能改内容。
  4. 以为 volatile 能代替锁完成自增。
  5. 空白 final 字段在某个构造器里漏赋值。

小结

访问修饰符决定谁看得见，static 决定属于类还是对象，final 决定还能不能改绑定或继承，abstract 把实现推迟到子类。并发用 synchronized / volatile 时要分清互斥和可见性；transient 只影响序列化。
