Java 数据类型

2024-05-14
  • Java
本文总阅读量次

相遇皆缘，相伴唯心。一生一程，一程一生。

两类数据

Java 是静态类型语言：每个变量都有编译期类型。类型分两类。

类别 包含 存的是什么
基本类型 byte short int long float double char boolean 值本身
引用类型 类、接口、数组、枚举、注解 指向对象的引用；没有对象时为 null

局部变量没有默认值，必须赋值后才能读。字段才有默认值：数值是 0 / 0.0，char 是 '\u0000'，boolean 是 false，引用是 null。

整数

整数都是有符号的，用二进制补码。字面量默认是 int，超出 int 范围的长整数必须加后缀 L。

类型 宽度 最小值 最大值 字段默认值
byte 8 -128 127 0
short 16 -32768 32767 0
int 32 -2^31 2^31-1 0
long 64 -2^63 2^63-1 0L

byte / short 适合大数组省空间，单次算术往往先提升成 int，省不了多少计算。

同类型多个变量可以一次声明，类型只写一次：int x = 1, y = -2;。写成 int x = 1, int y = -2 或用中文逗号 ， 都无法编译。

浮点

float（32 位）和 double（64 位）遵循 IEEE 754。没有后缀的小数是 double，float 必须写 f 或 F。

浮点不能精确表示多数十进制小数，钱、分数不要用 float / double，用 BigDecimal（用字符串构造，避免 new BigDecimal(0.1)）。

比较时不要用 ==：0.1 + 0.2 并不等于 0.3。需要时比较差值，或直接用整数分、毫单位。

NaN 与任何值都不相等，包括它自己；Double.POSITIVE_INFINITY 表示溢出方向。字段默认值是 0.0f / 0.0d。

字符与布尔

char 是 16 位无符号 UTF-16 码元，范围 \u0000～\uffff。它不是「任意一个 Unicode 字符」：辅助平面字符（很多 emoji）要两个 char（代理对）。处理码点用 codePointAt 等 API，不要假设 length() 等于字符个数。

boolean 只有 true 和 false，不能和数值互相转换，也不能当条件里的 1 / 0。语言规范不规定它占几位；虚拟机里单个变量通常按字节或机器字存放，boolean[] 会打包。说「boolean 是 1 位整数」不准确。

引用类型

String、数组、自定义类都是引用。声明 Site site 只得到能指向 Site（及其子类）的变量，new 才创建对象。

引用类型的变量一旦声明，编译期类型不能改，但可以指向兼容的子类对象。用 == 比较的是引用是否指向同一对象，内容相等用 equals。

类型转换

混合运算时，窄类型会先提升再计算。boolean 不参与这条链。

  • byte、short、char 做二元算术时先变成 int，所以 byte + byte 的结果是 int，赋回 byte 要强转。
  • 小范围赋给大范围是拓宽转换，一般安全：int → long → double。int 转 float 可能丢精度（float 只有 24 位尾数）。
  • 大范围赋给小范围必须显式强转，可能溢出或截断小数：(int) 3.9 得到 3，(byte) 128 得到 -128。
  • 不能把 boolean 转成数字，也不能把无关类硬转（那是引用转型，失败会 ClassCastException）。
  • char 提升为 int 时零扩展，不会变成负数；byte 提升为 int 时符号扩展。

常见坑

  1. 字面量 10000000000 不加 L，编译期就超出 int。
  2. float f = 1.0; 不合法，1.0 是 double。
  3. 整数除法 5 / 2 得到 2，至少一边写成 5 / 2.0 才有小数。
  4. 包装类 Long 不是基本类型 long，拆箱遇到 null 会 NullPointerException。
  5. 局部变量没赋初值就读取，编译失败；不要指望默认值 0。

小结

八种基本类型里，整数看范围选 int / long，小数默认 double，货币用 BigDecimal，字符记住 char 是 UTF-16 码元。引用默认 null，比较内容用 equals。转换沿「窄 → 宽」自动进行，反向必须强转并自己承担溢出。
