Java 接口

接口是什么

接口用 interface 声明，描述「能做什么」，不负责保存某个对象的状态。类用 implements 实现接口，不是 extends（extends 用于接口继承接口，或类继承类）。

接口不能 new。接口类型的变量可以是 null，也可以指向实现类对象。

实现类若不是抽象类，必须实现接口里每一个抽象方法。一个类只能继承一个类，但可以实现多个接口。

实现

通过 Traveler 引用只能调用该接口里的方法。eat(String) 是实现类自己的重载，接口变量看不见它。

接口继承

接口可以继承一个或多个接口，子接口包含父接口的抽象方法。类实现子接口时，父接口的方法也得实现。

成员到底是什么

没写修饰符时，编译器会补上，不是「只能手写 public abstract，否则报错」。

成员 隐式形态 说明
字段 public static final 必须在声明时赋值，是常量，不是对象状态
无方法体的方法 public abstract 由实现类完成
default 方法 public，有方法体 Java 8 起，可被重写
static 方法 属于接口 Java 8 起，用 接口名.方法() 调用，不被实现类继承为实例方法
private 方法 接口内部 Java 9 起，给默认方法复用，实现类看不见

接口没有构造器，也没有实例初始化块或静态初始化块。可以说「没有实例字段」，不能说「Java 8 以后仍然不能有静态方法」——静态方法可以有，静态代码块仍然不行。

默认方法让接口可以演进：给 List 增加 sort 时，旧的实现类不用逐个重写。两个父接口提供了签名相同的默认方法时，实现类必须重写，明确要哪一个，可用 接口名.super.方法() 选择。

和类、抽象类的差别

和类相同的地方：都编译成 .class，源文件名要和 public 类型一致，包名对应目录。

和类不同的地方：

  1. 不能实例化，没有构造器。
  2. 不能放实例字段，常量才是 public static final。
  3. 一个类可以实现多个接口。
  4. 方法可以是抽象的，也可以是 default / static / private，不只有抽象方法。
抽象类 接口
实例字段、构造器 有 无
非抽象实例方法 普通方法 default 方法
静态方法 有 Java 8 起有
静态代码块 有 无
多继承 类只能继承一个 接口可继承多个，类可实现多个

「接口中的方法都不能有方法体」只适用于 Java 7 及更早。写新代码时不要再这么判断。

常量引用不可变，但常量如果是 List，列表内容仍可能被修改。接口里不要放可变的全局状态。

只有一个抽象方法的接口是函数式接口，可以写 Lambda。@FunctionalInterface 能在你不小心加上第二个抽象方法时编译失败。default 方法和静态方法不占用这个名额。

常见坑

  1. 实现方法漏写 public。接口方法是 public，实现时不能降成包级。
  2. 把接口字段当成员变量，每个对象各改各的。那是同一个静态常量。
  3. 两个接口默认方法冲突，实现类不重写。
  4. 在接口静态方法里调用实例方法，没有 this。
  5. 以为 private 接口方法从 Java 8 就能用。那是 Java 9。

小结

接口描述能力，类负责实现。一个类可实现多个接口。字段是常量；抽象方法交给实现类；Java 8 起有默认方法和静态方法，Java 9 起有私有方法。需要每个对象一份状态时，用类或抽象类，不要塞进接口。
