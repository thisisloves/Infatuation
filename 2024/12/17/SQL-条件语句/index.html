SQL 条件语句

2024-12-17
  • SQL
本文总阅读量次

红颜远，相思苦。几番意，难相负。十年情思百年渡，不斩相思不忍顾。

CASE：标准的条件表达式

  • 按条件取值用 CASE。它可以出现在 SELECT、ORDER BY 和 UPDATE 的赋值里。简单 CASE 做等值匹配，搜索 CASE 写任意条件。
  • 省略 ELSE 时，不匹配的行得到 NULL。CASE col WHEN NULL 匹配不上，因为 NULL 与任何值都不相等。判断空值写 WHEN col IS NULL。

IF 与 IFNULL（MySQL）

  • IF(expr, a, b) 是 MySQL 函数：条件为真取 a，否则取 b。移植时改成搜索 CASE。
  • IFNULL(expr1, expr2) 在 expr1 不是 NULL 时返回它，否则返回 expr2。标准写法 COALESCE(a, b, c) 返回第一个非 NULL，参数可以多于两个。
  • IFNULL 不把空字符串当成 NULL。

分段计数

  • COUNT 忽略 NULL，所以 COUNT(IF(条件, 1, NULL)) 就是满足条件的行数。BETWEEN a AND b 表示 >= a AND <= b，写成 BETWEEN 70 AND 60 时下界大于上界，条件恒为假。
  • 各段首尾相接、不重叠。85 分放进第一段，70 分放进第二段，60 分放进及格段：
  • COUNT(IF(条件, sid, NULL)) 在 sid 本身为 NULL 时会少计。计数用 1，不依赖业务列是否为空。NULL 分数哪一段都不进，仍算在 COUNT(*) 里。

在更新里分支

  • 不写 WHERE 会改全表。CASE 没有 ELSE 时，不匹配的行会被设成 NULL。

常见坑

  • WHERE score = NULL 滤不出空值，用 IS NULL。IFNULL 只替换投影，不改变这一行是否被 WHERE 选中。
  • 多个 IF 嵌套超过两三层时改成搜索 CASE，每一支条件互相看得见。
  • 可移植的语句优先 CASE 和 COALESCE。IF / IFNULL 留在确认只用 MySQL 的脚本里。
  • 用搜索 CASE 做排序键，可以把 NULL 分数拨到最后，其余按分数从高到低。MySQL 里 NULL 默认最小，降序时会排到末尾；换数据库时 NULL 的默认位置不同，显式写 CASE 结果才稳定。
