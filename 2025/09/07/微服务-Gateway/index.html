对应练习

  • 模块：hm-gateway
  • 重点类：
    • AuthGlobalFilter：全局 JWT 鉴权
    • DynamicRouteLoader：监听 Nacos 动态刷新路由
    • JwtTool / AuthProperties：Token 与白名单配置

Gateway 的定位

  • 前端只配一个网关地址；内部服务端口不暴露公网。

全局鉴权过滤器

注意点

  1. Gateway 基于 WebFlux，返回 Mono，不要阻塞调用。
  2. 白名单一定要配登录、验证码等路径，否则永远 401。
  3. 下游服务可再校验 user-info，防网关被绕过（内网仍建议校验）。

路由 JSON 示意

  • lb:// 表示通过负载均衡访问注册中心中的服务名。

过滤器顺序与种类

类型 说明
GlobalFilter 全局，所有路由
GatewayFilter 绑定到特定路由
工厂类 Filter 配置文件里声明，如限流、重试

跨域与安全

  • 浏览器跨域可在 Gateway 统一配 CORS。
  • 限流：RequestRateLimiter + Redis。
  • HTTPS 终结可在网关或前面的 Nginx。

排错清单

现象 排查
一直 401 白名单、Token 头名、密钥是否与签发端一致
404 路由 Path 是否匹配、服务是否注册
路由不更新 Nacos dataId/group 是否写对、监听是否建立
下游拿不到用户 是否写入 header、下游是否读取同名头

小结

  • Gateway = 门面 + 横切；常见主干是「JWT 鉴权 + Nacos 动态路由」。
  • 先保证静态路由通，再玩动态配置；先保证白名单登录通，再收紧鉴权。
