微服务 OpenFeign

2025-10-24
  • 微服务
本文总阅读量次

两岸猿声啼不住，轻舟已过万重山。

对应练习

  • 模块：hm-api 存放 Feign 接口、DTO、降级类
  • 调用关系：cart-service、order-service 通过接口访问 item-service
  • 依赖：OpenFeign、负载均衡、连接池；降级用 FallbackFactory

为什么换掉 RestTemplate

RestTemplate 把 URL、参数、返回类型散落在每个调用点。item 的路径一改，购物车和下单都要搜字符串。OpenFeign 把一次 HTTP 写成 Java 接口，注解和 Controller 对齐。它不取代注册中心：@FeignClient 的 value 仍是 Nacos 服务名，发现不到实例时一样失败。

启用客户端

接口在 hm-api 时，包名不在 cart-service 启动类的默认扫描范围，basePackages 要写上。依赖为 spring-cloud-starter-openfeign。

接口怎么写

路径、动词与 item-service 的 Controller 一致。@PathVariable、@RequestParam 必须带名字，否则运行时拼不出参数，对面返回 400。GET 不要用 @RequestBody，查询条件放在 query 上，或改成 POST。

业务代码注入 ItemClient。value 与对方的 spring.application.name 大小写一致。

抽到 hm-api

接口若留在 cart-service，order-service 只能复制一份，或依赖整个 cart 工程。边界分成三块：item-service 只留实现；ItemClient、DTO、Fallback 放进 hm-api；cart-service 和 order-service 只依赖 hm-api。这样没有循环依赖，改路径只改一处。DTO 不用数据库实体，避免表结构漏到调用方。

连接池

默认每次新建连接，批量查商品时开销明显。课堂使用 HttpClient；较新的 Spring Cloud 改为 hc5。两种不要同时打开。连接池只复用连接，不管重试和降级。

依赖是 io.github.openfeign:feign-httpclient。若该构件已经不在当前版本里，改用 feign-hc5，开关写成 spring.cloud.openfeign.httpclient.hc5.enabled: true。

日志级别

配置类放在 hm-api，只通过 @FeignClient(configuration = ...) 引用。不要再加 @Configuration 去参与组件扫描，否则会变成全局配置，还可能重复注册。

把 com.hmall.api.client 调到 debug。只改 Logger.Level、包仍是 info 时，日志是空的。NONE 不打印。BASIC 打方法、URL、状态码和耗时。HEADERS 再加头。FULL 再加体，会带出令牌，只在排错时短时间打开。练习保持 BASIC。

超时与降级

连接超时和读取超时分开。读取超时过小的时候，对面可能已经扣了库存，调用方却认为失败。扣库存用版本号或唯一业务键，使重试不会重复扣减。查询失败可以再试，扣减不能无脑再打一次。

circuitbreaker.enabled 不打开时，fallbackFactory 会被忽略，异常照样抛出。课件若使用 Sentinel，改为 feign.sentinel.enabled: true。两个开关不要都当成必须项。

查询返回空，页面提示暂时不可用。扣库存必须失败，不能让订单继续往下走。工厂类要是 Spring 的 Bean，并写在对应的 @FeignClient 上。

和 RestTemplate 对照

RestTemplate OpenFeign
写法 每个调用点拼 URL 接口加 Spring MVC 注解
服务名 需要 @LoadBalanced value 写 Nacos 服务名
参数 占位符自己对应 注解里的名字不能省
失败 自己捕获 FallbackFactory，查询与写入分开处理
适合 调用点很少 多个服务共用同一批接口

排错

现象 排查
注入失败 @EnableFeignClients 是否覆盖 hm-api 的包
400 @PathVariable、@RequestParam 是否写了名字
没有实例 服务名、Group、命名空间是否与 Nacos 一致
降级不生效 熔断或 Sentinel 开关；工厂类是否为 Bean
日志空白 级别是否为 BASIC，客户端包是否为 debug

小结

OpenFeign 把访问 item-service 收成 ItemClient，放进 hm-api，给 cart-service 和 order-service 共用。连接池减少建连，BASIC 日志用来排错，超时配合 FallbackFactory：查询可空，扣库存必须失败。实例列表仍由 Nacos 提供。
