Spring AOP

2025-03-02
  • Spring
本文总阅读量次

众里寻他千百度，蓦然回首，那人却在灯火阑珊处。

对应练习

  • 项目：spring_03_aop
  • 切面：org.example.aop.MyAdvice

AOP 解决什么问题

  • 日志、事务、权限、耗时统计等 横切关注点，若写进每个业务方法会重复且难维护。
  • AOP：在 不改业务源码（或少改）的前提下织入增强。

核心术语

术语 含义
切面 Aspect 横切逻辑的模块（如 MyAdvice）
连接点 JoinPoint 可插入增强的点（Spring 主要为方法执行）
切点 Pointcut 一组连接点的匹配表达式
通知 Advice 具体增强代码（前后环绕等）
织入 Weaving 把增强接到目标对象（运行时代理）

切面示例

通知类型与执行顺序

  • @Around 必须自行 proceed()，否则目标方法不执行。
  • 有返回值的环绕通知，返回类型要匹配，否则调用方收到意外结果。

execution 切点常用写法

示例：

  • * 任意一节；.. 任意包层级或任意参数列表。

Spring AOP 的实现机制

  1. 默认 JDK 动态代理（目标实现了接口）或 CGLIB（类代理）。
  2. 只能拦截 Spring 容器里的 Bean 的 外部调用。
  3. 同类自调用（this.xxx()）不会走代理 → 事务 / 切面失效的经典原因。

如何避免自调用失效

  • 把方法拆到另一个 Bean；
  • 或注入自身（谨慎）；
  • 或使用 AopContext.currentProxy()（需暴露代理）。

与 @Transactional 的关系

  • 声明式事务本质是 AOP 环绕：方法前开事务，成功提交，异常回滚。
  • 事务不生效时，先查：是不是 public、是不是外部调用、异常类型是否被默认回滚策略捕获。

启用 AOP

  • XML：<aop:aspectj-autoproxy/> 或注解 @EnableAspectJAutoProxy。
  • Boot：引入 spring-boot-starter-aop 通常自动启用。

小结

  • 把 MyAdvice 里的五种通知都跑一遍，观察控制台顺序；再故意在目标方法抛异常，对比 @AfterReturning 与 @AfterThrowing。
  • 透彻理解代理与自调用，后面排事务问题会快一个数量级。
