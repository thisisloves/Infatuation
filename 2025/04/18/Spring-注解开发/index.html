Spring 注解开发

2025-04-18
  • Spring
本文总阅读量次

衣带渐宽终不悔，为伊消得人憔悴。

对应练习

  • 项目：spring_02_annotation
  • 配置类：org.example.config.SpringConfig
  • 还导入了 JdbcConfig、MybatisConfig，并读取 jdbc.properties。

从 XML 到注解，变的是什么

  • 不变：仍然是 IoC 容器管理 Bean。
  • 变：用注解 / Java Config 声明 Bean，减少 XML 样板。

配置类

逐项说明

注解 作用
@Configuration 标识配置类（本身也是组件）
@ComponentScan 扫描并注册 @Component 等
@PropertySource 加载 properties，配合 @Value
@Import 导入其它配置类，模块化拆分

立体注解（派生自 @Component）

注解 习惯用于
@Component 通用组件
@Service 业务层
@Repository 持久层（可翻译部分数据访问异常）
@Controller / @RestController Web 层

依赖注入注解

  • **@Autowired**：默认按类型；多个候选加 @Qualifier("beanName") 或 @Primary。
  • **@Resource**：JSR-250，默认按名称。
  • **@Value("${jdbc.url}")**：注入配置项。

@Bean：托管第三方对象

  • 自己写的类用 @Component；第三方类无法改源码时用 @Bean 方法最合适。

启动方式

  • 测试里可用 @ContextConfiguration(classes = SpringConfig.class) + @RunWith(SpringJUnit4ClassRunner.class)（或 Spring Boot 的 @SpringBootTest）。

常见问题

  1. 扫不到 Bean：包路径不在 @ComponentScan 内。
  2. 注入失败：接口有多个实现，未指定 @Qualifier。
  3. @Value 拿不到：忘了 @PropertySource 或占位符未开（Boot 里一般自动）。
  4. 循环依赖：A↔B 构造器互依会挂；可用 setter / 重构设计缓解（Boot 2.6+ 默认禁止循环依赖）。

与 Boot 的衔接

  • Boot 的 @SpringBootApplication = @Configuration + @EnableAutoConfiguration + @ComponentScan。
  • 你现在手写的 SpringConfig，就是在理解 Boot「自动配置」之前必须经历的一步。

小结

  • 注解开发 = 声明式 IoC；配置类拆分（@Import）是微服务 / 多模块里继续会用的组织方式。
