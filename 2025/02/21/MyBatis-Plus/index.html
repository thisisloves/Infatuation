MyBatis vs MyBatis-Plus

MyBatis MyBatis-Plus
单表 CRUD 常手写 XML BaseMapper 开箱即用
条件拼接 XML <if> / 注解 QueryWrapper / Lambda
分页 PageHelper 等 内置 PaginationInnerInterceptor
  • 复杂多表、报表 SQL，仍建议手写；MP 负责 80% 单表场景。

ServiceImpl 与通用 CRUD

常用：

扣减余额 + 乐观锁

  1. 这是用「旧余额作条件」做乐观并发控制；也可用 @Version 版本号字段。
  2. @Transactional 保证读与写同事务；高并发下仍要考虑库存类专用方案。
  3. 更新失败（ok == false）要给调用方明确错误，避免静默成功。

Lambda 条件构造

  • 比字符串列名更安全，重构字段名时 IDE 能跟。

类型 用途 示例

DTO 入参 UserFormDTO
VO 出参 UserVO / AddressVO
Query 查询条件 UserPageQuery
