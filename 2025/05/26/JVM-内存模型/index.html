JVM 内存模型

2025-05-26
  • JVM
本文总阅读量次

横看成岭侧成峰，远近高低各不同。

先分清两套「内存模型」

本文说的是 运行时数据区：堆、栈、方法区各自放什么。它和并发里的 Java Memory Model（可见性、happens-before）不是同一件事。调优、OOM 先看运行时数据区；可见性问题再去看 JMM。

下面以 HotSpot、JDK 8 及以后为主。线程不共享的区域每个线程一份，共享区域全进程一份。

运行时数据区

区域 线程 放什么 常见错误
程序计数器 私有 当前线程下一条字节码指令地址 规范里唯一不会 OOM 的区域
Java 虚拟机栈 私有 栈帧：局部变量、操作数栈、返回地址 StackOverflowError，线程过多时也可能 OOM
本地方法栈 私有 Native 方法的调用状态 与虚拟机栈类似，HotSpot 里常合在一起
堆 共享 对象实例和数组 Java heap space
方法区 共享 类元数据、运行时常量池、静态变量等 JDK 8 起在元空间，Metaspace

程序计数器在 Native 方法执行时可以为空。虚拟机栈在方法调用时压入栈帧，方法结束出栈。本地方法栈为 JNI 服务，Java 栈帧解决不了的本地调用走这里。

堆与分代

堆是垃圾回收的主战场。分代假设是：多数对象朝生夕灭，熬过多次回收的才值得放进老年代。

  • 新对象优先在 Eden 分配。Eden 满了触发年轻代收集，存活对象复制到 Survivor，年龄增加。
  • 年龄达到阈值（常见默认 15，可调）或 Survivor 放不下时，晋升老年代。
  • 大对象可能直接进老年代，避免在 Survivor 之间来回复制。
  • JDK 8 去掉了永久代。类的元数据在本地内存里的 元空间（Metaspace），不再占堆。字符串常量池从 JDK 7 起位于堆中。

逻辑上的年轻代 / 老年代在 G1 里由 Region 扮演，物理上不再是两块固定连续空间，但「新对象多数短命」这条约定仍然适用。

栈帧里有什么

每调用一个 Java 方法压入一帧，返回时弹出。帧里与排错相关的主要是：

部分 作用
局部变量表 参数和局部变量；槽位复用，长生命周期引用会拖住对象
操作数栈 字节码计算的临时工作区
动态链接 指向运行时常量池中该方法的符号引用
返回地址 正常返回或异常完成时回到调用方

-Xss 决定单个线程栈的大小。递归过深、方法调用链过长会 StackOverflowError。把栈调得很大不能根治递归，还会让同样的内存只能创建更少的线程。

局部变量表里的引用也是 GC Roots。本该提前失效的对象若一直放在槽位里，会推迟回收。这在问题排查里比「栈会不会溢出」更常碰到。

OOM 出现在哪

报错信息里的区域名比猜测有用：

信息 位置 常见原因
Java heap space 堆 泄漏、堆上限过小、一次性加载超大数据
GC overhead limit exceeded 堆 GC 几乎占满时间，回收量却很少
Metaspace 元空间 类加载过多：动态代理、脚本、错误的热部署
unable to create new native thread 本地内存 / 线程栈 线程数过多，或 -Xss 偏大
Direct buffer memory 堆外直接内存 NIO 直接缓冲区未释放，上限由 MaxDirectMemorySize 约束
StackOverflowError 虚拟机栈 无限递归或调用链过深，它不是 OutOfMemoryError

程序计数器不产生 OOM。堆外内存（元空间、线程栈、直接内存）不受 -Xmx 限制，机器内存用尽时，堆仍显示还有空闲。看监控时要把堆、元空间、线程数、直接内存分开看。

方法区里有什么

JDK 8 起，方法区的实现是元空间，占的是本地内存：

  • 类的结构、字段和方法表、运行时常量池。
  • 静态变量的引用槽。被引用的如果是对象，实例仍在堆上。
  • 即时编译后的机器码放在代码缓存，既不算堆，也不算元空间。

类要卸载，通常得连同加载它的类加载器一起不可达。应用类加载器一直存活时，业务类卸不掉。元空间只增不减，优先查是不是在不断生成新类（脚本、反射生成代理），而不是先把堆调大。

和对象创建的对应关系

  • TLAB：线程在 Eden 里先领一小块，小对象在自己的块上分配，避免每次都抢堆锁。块用完再领下一块；放不下的大对象直接去 Eden 或老年代。
  • 逃逸分析：编译器确认对象不会逃出方法时，可以拆成标量，不再在堆上建对象。分配速率看起来偏低时，把这项优化和日志里的实际分配量放在一起看。
  • 静态字段、缓存里的引用会让堆上的对象一直可达。泄漏和「正常缓存」的差别，就在这块引用有没有上限、会不会释放。

小结

  • 线程私有：程序计数器、虚拟机栈、本地方法栈。共享：堆、方法区（元空间）。
  • 对象在堆，类元数据在元空间，调用链在栈帧。
  • 看到 OOM 先对上报错类型，再决定是扩容、限流，还是查泄漏。
