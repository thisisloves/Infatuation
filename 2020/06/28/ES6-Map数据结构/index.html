ES6 Map

  • ES6

拂过红尘衣袂，涤荡污浊俗心。 愿纵马而歌归故里，能得你素衣不改，白裙曳地，夹道相迎。

键不限于字符串

Object 的键会被转成字符串或 Symbol。Map 的键可以是对象、函数、数字，按 SameValueZero 比较：NaN 等于 NaN，+0 等于 -0。没有键的自动字符串化。

第三次 get 是 undefined。两个看起来一样的对象不是同一个键。要用内容当键，把稳定的原始值（id）当键，或在写入前自己规范化。

常用方法

  • set 返回 map 自身，可以链式调用。
  • get 没有该键时返回 undefined。值本身可以是 undefined，所以「有没有」用 has，不要用 get 判断。
  • delete 返回布尔。clear 清空。size 是当前个数，不是方法。
  • 迭代：keys()、values()、entries()、forEach。默认迭代是 [key, value]。插入顺序稳定，和对象字面量「整数键会重排」不同。

和对象怎么选

键是任意值、需要稳定的插入顺序、或键会频繁增删，用 Map。键是固定的一组名字、要 JSON 序列化，用对象或数组。JSON.stringify 对 Map 得到 {}，因为 Map 的数据不在可枚举自有属性上。要存盘就 JSON.stringify([...map])，读回 new Map(JSON.parse(text))。

对象当键时，Map 持有该对象的引用，键对象无法被垃圾回收。缓存若希望键消失后条目也消失，用 WeakMap。WeakMap 的键必须是对象，不能迭代，没有 size，不能 clear。

不要用 Map 模拟集合的误用

只关心键在不在，用 Set。二维计数用 Map 嵌 Map，或把复合键收成字符串，注意分隔符不要出现在数据里。

1 和 ‘1’ 是两个键

构造函数接受可迭代的 [key, value]。普通对象不能直接 new Map(obj)，先 Object.entries。

forEach 的参数顺序

数组回调是 (element, index)。Map 的 forEach 是 (value, key, map)，值在前、键在后。写成 (key, value) 会把两者看反。

size 是属性。用对象当键时 Map 会留着这个对象，键无法回收。缓存用 WeakMap，它的键必须是对象，不能 for...of，也没有 size。JSON.stringify(map) 是 '{}'，要持久化就 JSON.stringify([...map])。
