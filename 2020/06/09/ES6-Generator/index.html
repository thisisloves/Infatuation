可以暂停的函数

function* 返回生成器对象，不立刻执行函数体。每次 next(value) 跑到下一个 yield 暂停。yield 后面表达式的值成为这次 next 的 value。传给下一次 next 的参数，会成为上一个 yield 表达式的结果。

第一次 next 的参数没有对应的 yield 接收，会被丢掉。返回值形状是 { value, done }。return 时 done 为 true。之后再 next，value 一直是 undefined，done 保持 true。

遍历

生成器对象实现了迭代器协议，可以被 for...of 消费。for...of 只取 done === false 的 value，最后的 return 值不会出现在循环里。

yield*

yield* other 把另一个可迭代对象展开到当前生成器里。对方 return 的值成为 yield* 表达式的结果。用来拆分生成器，而不是手写 for (const x of other) yield x（两者对 return 值的处理并不完全相同，需要返回值时用 yield*）。

错误与关闭

g.throw(err) 在暂停点抛出，函数里的 try/catch 能接住。g.return(v) 提前结束，finally 仍会执行。生成器里若有资源，放在 try/finally，调用方中断遍历时 for...of 会调用 return。

不要用生成器代替数组方法去做同步变换，可读性更差。它适合惰性序列、以及需要把控制权交还调用方的流程（测试里的步进、saga）。异步流程优先 async/await。async function* 是异步生成器，yield 的 Promise 会被 for await...of 等待，那是另一套协议。

throw 要打在已经暂停的 yield 上

生成器还没开始时调用 throw，函数体里的 try 尚未执行，异常直接抛给调用方。return(v) 会跑 finally，适合在 for...of 提前 break 时释放资源。for...of 不会把生成器 return 的值放进循环变量，那个值只出现在最后一次 next 的 value 里。

和闭包循环

生成器每次 next 才往下走，循环里的 let 仍是每次迭代一个绑定。不要在生成器外面用 var 收集回调再指望每个回调看到当时的 yield 值，那是闭包共享一个绑定，和生成器无关。异步步骤用 async/await，不要为了「能暂停」在业务里手写 function*。
