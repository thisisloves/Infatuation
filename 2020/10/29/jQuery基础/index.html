jQuery 是 DOM 操作库

jQuery 把选择元素、绑定事件、发请求、做动画收成一套链式 API。它不是语言，也不是框架。现在的新项目更常用原生 DOM 或 Vue 这类框架；维护旧页面、或插件仍然依赖 jQuery 时，要先认准版本。

主版本 浏览器底线
1.12 含 IE6、IE7、IE8
2.x 不含 IE8 及更早
3.x 不含 IE8 及更早，实际以 IE9+ 为底线
4.x 不再支持任何 IE

「所有版本都兼容 IE6」不成立。要支持 IE8 及更早，只能锁在 1.12，并接受它收不到 3.x 的错误修复。现代浏览器用 3.x 即可。

从 CDN 引入时加上 integrity 和 crossorigin="anonymous"，避免文件被替换。

选择再操作

$ 是 jQuery 的别名。$(selector) 返回的是 jQuery 对象，不是原生 DOM。对象像数组，用 [0] 或 .get(0) 取出原生节点，用 .length 看匹配了几个。多数方法返回 jQuery 对象本身，所以能链式调用。

页面上若还有别的库占用 $，在 jQuery 之后调用 jQuery.noConflict()，它会把 $ 还给前一个主人，之后改用 jQuery。

文档就绪

ready 在 DOM 树建好后执行，不必等图片和样式表里的外部资源。可以绑定多次，按注册顺序执行。

window.onload 要等文档里的图片等资源都加载完。用 onload = fn 这种赋值只会保留最后一次。jQuery 的 ready 和它不是同一个时机，不能互相替换。

脚本如果放在 </body> 前，执行时 DOM 已经解析完，简单页面可以不包 ready。脚本在 <head> 里、或不确定加载顺序时，仍然包上。

和原生 DOM 的来回

jQuery 对象上没有 classList、querySelector 这些原生方法。原生节点上也没有 .css()、.on()。混用时先确认当前变量是哪一种。$(el) 把原生节点包回去，开销很小，但不要在循环里反复包同一批节点。

链与隐式迭代

find 把集合换成子孙。end 回到上一次的集合。绝大多数方法会对集合里的每个元素执行，不需要自己写 for。

取值类方法只作用于集合中的第一个元素，例如 .text() 不传参时读第一个。设置类方法作用于全部匹配元素。
