AJAX 指的是异步请求

AJAX 是 Asynchronous JavaScript and XML 的缩写。名字里有 XML，是历史叫法。现在请求体和响应体更多是 JSON、表单或纯文本。它的作用是：不刷新整页，向服务器要一部分数据，再更新页面上的一块区域。

jQuery 把 XMLHttpRequest 包成 $.ajax 以及几个简写。浏览器的同源策略仍然有效，跨域要服务端给出 CORS，或走同域反向代理。jQuery 不会因为你用了 $.ajax 就放开跨域。

$.ajax

method 是动词，type 是旧名字，两者写一个即可。dataType 是你期望怎么解析响应：json、xml、html、text、script。不写时 jQuery 会看响应的 Content-Type。

data 是普通对象时，默认按 application/x-www-form-urlencoded 编码。要发 JSON，自己 stringify，并关掉 jQuery 的表单转换：

HTTP 404、500 会走 fail。这和后来的 fetch 不同，fetch 在收到错误状态码时仍算请求成功，要自己看 response.ok。

jQuery 3 的 deferred 跟 Promise/A+ 对齐，$.ajax 返回的 jqXHR 可以 .then。不要再使用 async: false，它会卡住页面，新版本里也已废弃。

简写方法

它们都返回 jqXHR。$.getJSON 强制按 JSON 解析。$.getScript 会执行脚本，只加载你信任的地址。

load

.load 把响应 HTML 插进匹配元素：

URL 后空一格再写选择器，表示只插入响应文档里匹配的那一块，而不是整页。

第二个参数决定动词：普通对象走 POST，字符串走 GET 并把字符串当成查询参数。不要凭感觉认为 .load 永远是 GET。

回调签名是 (responseText, textStatus, jqXHR)。textStatus 除了 "success" 和 "error"，还有 "notmodified"、"timeout"、"parsererror"。"notmodified" 表示 304，不是失败。

jqXHR 是在 XMLHttpRequest 上扩展的对象，有 status、statusText、responseText、getResponseHeader，在 dataType: "json" 且成功时还有解析后的数据。它不是一个普通的 JSON。

全局事件与取消

$(document).ajaxStart / ajaxStop 适合做全站加载指示。单个请求用自己的 beforeSend 更清楚。

abort 之后 textStatus 是 "abort"。重复提交前先放弃上一次未完成的请求。

JSONP 只是脚本标签

dataType: "jsonp" 通过 <script> 绕过同源限制，只能 GET，且服务器必须按回调名包裹 JSON。页面会执行返回的脚本。现在应使用 CORS。不要对新接口再设计 JSONP。
