常用事件名

鼠标 键盘 表单 文档

hover 不是 DOM 事件名。jQuery 的 .hover(fnIn, fnOut) 是同时绑定 mouseenter 和 mouseleave 的便捷方法。

keypress 已废弃，且修饰键、方向键不可靠，用 keydown / keyup。unload 在刷新和移动端上不可靠，离开页面前的提示用 beforeunload，页面被冻结用 pagehide。

mouseenter 不冒泡，mouseover 会冒泡到子孙。focus 不冒泡，需要委托时改用 focusin。

用 on 绑定

jQuery 3 起 .bind()、.delegate() 被标记为废弃，.live() 早在 1.9 就移除了。统一用 .on / .off。

事件处理函数里的 this 是当前 DOM 元素，需要 jQuery 方法时再 $(this)。不要写成箭头函数，箭头函数没有自己的 this。

下面这种写法是错的：每次原生 click 都再注册一个 jQuery click，处理函数会越积越多。

解除与只执行一次

.one 执行一次后自动卸下。命名空间 .panel 让你只卸自己的监听，不影响别人绑在 resize 上的函数。.off("click") 会卸掉该元素上全部 click，范围太大。

事件对象

jQuery 把原生事件包成自己的对象，并用 event.originalEvent 留着原生那份。preventDefault 取消默认动作，stopPropagation 停止继续冒泡。处理函数 return false 时，jQuery 会同时做这两件事，这和原生监听里 return false 只阻止默认动作不一样。

.trigger("click") 会冒泡并触发默认行为。.triggerHandler("click") 只执行 jQuery 绑的处理函数，不冒泡。用代码去点提交按钮时，想清楚要哪一种。

传入数据

event.data 是绑定时的那份数据，适合循环里避免闭包拿错变量。若循环变量还会变，绑定当时就把 id 放进 data。

ready 不是 click

$(function () {}) 是 DOM 就绪，不是事件委托。动态节点的点击仍要 .on。$(window).on("load", ...) 才等到图片等资源，和 ready 的时机不同。
