读和写内容

方法 不传参 传入值
.text() 读合并后的文本，含子孙 按文本写入，标签会被转义
.html() 读第一个元素的 innerHTML 按 HTML 写入，会替换内部全部节点
.val() 读表单控件的当前值 设置 value。多选下拉要传数组

.text() 和 .html() 读取时只看集合里的第一个元素；写入时作用于每一个。用户输入不要用 .html() 塞回页面，那等于 innerHTML，会执行里面的标签。展示用 .text()。

选择器要能命中节点。$("div1") 找的是标签名 div1，页面上没有这种标签。ID 是 $("#div1")，标签是 $("div")。

attr 与 prop

.attr 读写 HTML 属性字符串。.prop 读写 DOM 属性，类型是布尔、数值或对象。

checked、selected、disabled、readOnly、multiple 用 .prop。jQuery 1.6 之后，.attr("checked") 读到的是 HTML 里写死的初始属性（没有就是 undefined），不是用户当前有没有勾选。当前状态以 .prop("checked") 为准。

href、id、title、data-id 这类用 .attr。.removeAttr("disabled") 会真正拿掉属性；禁用开关更直接的是 .prop("disabled", false)。

.data() 会读 data-* 并做类型转换，还在内部缓存。只想要属性上的原始字符串时用 .attr("data-id")。用 .data 写过之后，它不一定回写到 DOM 属性上，刷新元素 outerHTML 可能看不到。

插入

方法 插入位置
.append() / .prepend() 元素内部的末尾 / 开头
.after() / .before() 元素外部的后面 / 前面

调用者是目标容器。若手头是新内容、想插到某个目标里，用反向方法：.appendTo()、.prependTo()、.insertAfter()、.insertBefore()。

传入 HTML 字符串会解析成节点。传入已有的 jQuery 对象或 DOM 节点，会把节点移走，而不是复制。要复制用 .clone()。.clone(true) 连同事件和 data 一起复制。

删除

方法 结果
.remove() 从文档移除，并清掉 jQuery 存在这个节点上的事件和数据
.detach() 从文档移除，但保留事件和数据，便于再插回去
.empty() 只清空子节点，元素还在

已经 .remove() 的节点再插回去，之前用 jQuery 绑的事件不会还在。

类名与尺寸

.css 读到的是计算后的样式字符串。一次改很多样式时传对象，避免连着触发布局。类名用 .addClass，不要用 .attr("class", ...) 把原有类整个覆盖掉。

.width() / .height() 是内容盒尺寸。.innerWidth() 含 padding。.outerWidth() 含 border，传入 true 再含 margin。这些读的是数字，单位是像素。隐藏元素的宽高可能是 0。
