值唯一的集合

Set 按 SameValueZero 保存一组值，每个值只出现一次。NaN 只会留下一个。对象按引用区分，内容相同的两个对象可以同时在集合里。

没有下标。顺序是插入顺序，重复 add 已有的值不会改变它的位置。迭代、展开、forEach 都按这个顺序。

用数组的 includes 做交集是 O(n·m)。Set.has 平均是常数时间。

WeakSet

WeakSet 只接受对象，不阻止键被回收，不能迭代。适合标记「这个对象已经处理过」而不想让标记本身留住对象。不要拿它存放业务列表，你无法把它列出来。

和数组方法

Set 没有 map / filter。先展开成数组，再 new Set 回去。在热路径上若只是判断存在，不要为了用 filter 反复展开。

NaN 只留一个，+0 和 -0 也是一个

个数看 size，不是 length。forEach 的回调是 (value, value, set)，前两个参数相同，不要把它当成 Map 的 (value, key)。

对象按引用区分。new Set([{ id: 1 }, { id: 1 }]).size 是 2。按 id 去重用 Map，再取出 values。

遍历过程中 add 的新值，之后的迭代看得到。不要一边遍历一边假设集合的成员表是冻结的。只判断存在时用 has，不要为了用数组方法反复 [...set]。
