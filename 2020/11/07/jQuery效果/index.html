jQuery 效果

2020-11-07
  • jQuery
本文总阅读量次

世界上有两万个你一见钟情的人，但有可能你一生中一个也遇不到。

显示和隐藏

不传时长时，hide() 立刻加上 display: none，show() 恢复隐藏前的 display。传了时长，则会动画宽度、高度和透明度，结束后再改 display。

时长可以是毫秒，或字符串 "slow"（600）、"fast"（200）。第二个参数可以是缓动函数名，最后一个回调在每个元素的动画结束时执行，this 是该元素。

已经 display: none 的元素再 hide(400) 不会有动画。表格的行、单元格不适合做高度动画，布局会散。

淡入淡出

fadeIn / fadeOut / fadeToggle 只改透明度，不改宽高。fadeTo 可以停在指定透明度，而不是只能到 0 或 1。

fadeOut 结束后会 display: none。fadeTo 不会把元素从文档流里拿掉，即使用 0，元素仍占据位置且可被点到。需要真正收起时用 fadeOut 或 hide。

滑动

slideDown 把隐藏元素的高度从 0 放到内容高度，slideUp 相反，slideToggle 来回切。

滑动读的是内容高度。动画过程中如果内容高度又变了，结束高度可能不对。面板里有图片时，等图片有尺寸后再滑开，或给图片预留高度。

animate

能动画的是数值型 CSS 属性。background-color 这类颜色默认不能动画，除非再引入 jQuery Color 或改用 CSS。方向要用 left / top 时，元素需要非 static 定位。

"+=20"、"-=20" 是相对当前计算值。"hide"、"show"、"toggle" 可以当属性值，用来在自定义动画里顺便做显示切换。

队列

同一元素上的动画默认排队。下面会先滑再淡：

不同元素的动画并行。.delay(300) 只延迟动画队列，不延迟后面的 .css() 这类非动画方法。

.stop(clearQueue, jumpToEnd)：

  • .stop()：停掉当前这一段，队列里下一段还会开始。
  • .stop(true)：清掉后面排队的动画。
  • .stop(true, true)：清队列，并把当前动画立刻跳到终点。

快速连点手风琴时，如果不清队列，动画会补很久。常用 $("#panel").stop(true, true).slideToggle(200)。

:animated 能选中正在动画的元素。jQuery 3 的动画定时用 requestAnimationFrame，页面在后台时会暂停，这是预期行为。

和 CSS 过渡怎么选

颜色、位移、简单显隐，用 CSS transition 更顺，也不占主线程去改每一帧样式。jQuery 动画适合旧页面里已经大量使用、且要在回调里串多步的场合。不要对同一属性一边 CSS 过渡、一边 .animate()。
