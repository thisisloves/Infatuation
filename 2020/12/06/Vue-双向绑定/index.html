Vue 双向绑定

2020-12-06
  • Vue
本文总阅读量次

看尽人间繁华，三千浮生若水。

两层意思不要混

日常说的「双向绑定」多指表单指令 v-model：数据变了改输入框，输入框变了改数据。

Vue 自己的响应式系统负责的是「数据变了，通知用到它的视图」。视图回写数据，靠的是事件，不是 Object.defineProperty 去监听 DOM。

v-model 是语法糖

Vue 2 里，文本框等价于绑定 value，再监听 input：

表单控件 绑定的 DOM 属性 监听的事件
text / textarea value input
checkbox / radio checked change
select value change

修饰符：.lazy 改为监听 change；.number 用 parseFloat 转数字，空串会得到 NaN，提交前要再判断；.trim 去掉首尾空白。

组件上的 v-model

Vue 2 默认把 value 传给子组件，并把子组件的 input 事件写回父数据：

子组件用 this.$emit('input', newValue) 通知父级。若要改名字，用选项 model: { prop: 'price', event: 'change' }。另一个属性的双向同步用 .sync，等价于 :title 加 @update:title。

Vue 3 改了这套名字，旧写法对不上：

  • 默认 prop 是 modelValue，事件是 update:modelValue。
  • 可以多个 v-model：v-model:title、v-model:price。
  • 去掉了 .sync 和组件选项 model。
  • 修饰符会额外传入 modelModifiers。Vue 3.4 起也可以用 defineModel()。

同一份组件代码不能同时按 value/input 和 modelValue/update:modelValue 去猜版本，要看项目是 Vue 2 还是 Vue 3。

Vue 2 如何做到数据变视图就变

把普通对象交给 data 后，Vue 2 会递归遍历它的属性，用 Object.defineProperty 把每个属性换成 getter/setter。读取时收集依赖（哪个渲染 Watcher 用到了它），写入时通知这些依赖重新渲染。

上面只说明拦截读写。真正的 Vue 还要有：

  1. Observer：把对象、嵌套对象都变成响应式。
  2. Dep：每个属性一份依赖名单。
  3. Watcher：组件渲染 Watcher，或用户写的 watch。getter 阶段把自己放进 Dep，setter 阶段再统一通知。
  4. 调度：同一轮里多次改数据，会合并成一次刷新，而不是改一次刷一次 DOM。

数组的 push、pop、shift、unshift、splice、sort、reverse 被 Vue 2 包过一层，用它们改数组可以触发更新。Vue.set 与实例上的 this.$set 是同一件事。

根数据对象不能中途整个替换掉再指望新属性自动被观测；替换某个已经是响应式的对象属性则可以，新对象会被重新 observe。

Vue 3 换成 Proxy

Vue 3 的 reactive 用 Proxy 拦截整个对象，新增属性、删除属性、按下标改数组、改 length 都能被追踪。ref 包一层 .value，用来装基本类型。

因此 Vue 3 去掉了 Vue.set / this.$set。Vue 2.7 虽然带了组合式 API，响应式内核仍是 Object.defineProperty，$set 还在。

Proxy 无法拦截的也要知道：对原始对象的外部引用不会走代理；解构 reactive 对象会丢失响应性，需要 toRefs。
