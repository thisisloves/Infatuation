ECharts 异步与动态数据

2022-08-30
  • Echarts
本文总阅读量次

生如夏花，开到荼蘼。

先有空坐标系，再填数据

容器先 init，立刻 setOption 出坐标轴和空系列，请求完成后再 setOption 数据。这样加载过程中布局稳定。请求期间用内置加载动画：

默认合并会按索引改 series[0] 的 data，坐标轴 data 也会被新数组换掉。若系列条数会变，用 { replaceMerge: ['series'] }，避免旧系列残留。

轮询与卸载

定时器的 id 要在组件卸载时 clearInterval，并 chart.dispose()。卸载后再 setOption 会抛错。请求用 AbortController，卸载时 abort，回到回调里先看实例是否还在。

后返回的旧请求会覆盖新数据。带上递增的请求序号，回包时序号不一致就丢掉。

追加大量点

折线持续追加时，每次全量 setOption 会重新处理整段数组。ECharts 提供 chart.appendData({ seriesIndex: 0, data: points }) 给部分系列追加。它不适合「还要改坐标轴类目」的场景，类目变化仍要 setOption。点数设上限，超出就切片丢掉头部，否则页面会越来越慢。

setOption 第三种做法是 lazyUpdate: true，把同一帧里的多次更新合成一次。高频 WebSocket 先把点攒在数组里，用 requestAnimationFrame 再推给图表。

loading 与空数据

showLoading 只盖住画布，不会取消请求。数据为空时用 graphic 画一句「暂无数据」，或把系列设为空数组并保留坐标轴。不要让空数组把 yAxis.min / max 留在上一次的范围里造成误解，空数据时把轴也重置。

失败时 hideLoading 一定要走到，放在 finally 里，否则界面停在转圈。
