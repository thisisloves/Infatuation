ECharts 基础配置

2022-08-20
  • Echarts
本文总阅读量次

离愁渐远渐无穷，迢迢不断如春水。

名称与版本

图表库的官方名称是 Apache ECharts，书写用 ECharts。包名和全局变量仍是小写 echarts。下面按 5.x 的 option 来写。ECharts 2 的 dataRange、主题文件里的 categoryAxis 已经不是现行配置，新图不要再抄那份默认主题。

最小例子

容器必须有非 0 的宽高。父级高度若是 auto，百分比高度会变成 0，图是空白的。

离开页面或组件卸载时调用 chart.dispose()，再把监听摘掉。对同一个 DOM 再次 init 之前必须 dispose，否则会有两份实例抢容器。

echarts.init(dom, theme, opts) 的第三参可以指定 renderer: 'canvas'（默认，数据量大）或 'svg'（需要矢量、数量不多）。宽高也可以在这里写死，否则读容器的客户区。

setOption 是合并

默认把新 option 合并 进旧的。数组（尤其是 series）按索引合并，不会因为你少传一项就删掉旧系列。要整段换成新配置：

只想替换 series、保留坐标轴时用 replaceMerge: ['series']。lazyUpdate: true 把这次更新推迟到下一帧，连续推数据时少做几次布局。

结构

  • title、legend、tooltip、toolbox、grid 管装饰和绘图区边距。grid 的 containLabel: true 让轴标签留在绘图区内。
  • xAxis / yAxis 的 type 常用 category、value、time、log。类目轴的 data 与系列数据按下标对齐。
  • dataset 把表格数据和系列拆开，系列用 encode 指定哪一列是 x、哪一列是 y。多系列共享一份表时比在每个 series.data 里各写一遍清楚。
  • series.type 决定图的种类。

常用 series.type

  1. bar 柱状 / 条形
  2. line 折线，areaStyle 变面积
  3. pie 饼
  4. scatter / effectScatter 散点与涟漪
  5. radar 雷达
  6. tree 树图
  7. treemap 矩形树图，和 tree 不是同一个类型
  8. sunburst 旭日
  9. boxplot 箱线
  10. candlestick K 线
  11. heatmap 热力
  12. map 地图，另需注册 GeoJSON：echarts.registerMap
  13. parallel 平行坐标
  14. lines 线图，常配合坐标系做迁徙
  15. graph 关系
  16. sankey 桑基
  17. funnel 漏斗
  18. gauge 仪表
  19. pictorialBar 象形柱
  20. themeRiver 主题河流
  21. custom 自定义系列，用 renderItem 画

直角坐标系里的柱、线、散点需要 xAxis 和 yAxis。饼图、仪表盘不要再配类目轴，否则空白或报找不到坐标系。

主题

echarts.init(dom, 'dark') 使用内置暗色。自定义主题是一份 option 形态的对象，在 init 时作为第二参，或 echarts.registerTheme('name', theme) 之后按名字使用。主题只提供默认值，setOption 里的同名字段会盖过它。ECharts 2/3 时代的默认主题字段和 5.x 手册不同，不要照搬旧主题结构。

手册以 https://echarts.apache.org/zh/option.html 为准。
