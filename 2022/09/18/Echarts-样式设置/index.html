ECharts 样式设置

2022-09-18
  • Echarts
本文总阅读量次

离恨却如春草，更行更远还生。

颜色给谁

ECharts 的样式写在 option 里，单位是数值像素，不是 CSS 的 rem。color 是全局调色盘，系列按顺序取色。单个系列用 itemStyle.color 盖过调色盘。

emphasis 是悬停，blur 是「别的数据被选中时，这项变淡」，select 是选中。三者都是状态样式，不要只改 itemStyle 却指望悬停变色。

线、点、文字

折线的线宽和线型在 lineStyle，拐点在 symbol、symbolSize。面积是 areaStyle，可以是纯色或 LinearGradient。

label 控制数据标签。formatter 可以是字符串模板 '{c}' 或函数 (params) => params.value。标签太多会互相遮挡，用 labelLayout.hideOverlap，或只在 emphasis 里显示。

坐标轴文字是 axisLabel，轴线是 axisLine，刻度是 axisTick，网格线是 splitLine。想隐藏轴线就把 axisLine.show 设为 false，不要把颜色设成和背景一样蒙混，导出图片时背景不一定还在。

调色盘函数

itemStyle.color 可以是函数，按 params.dataIndex 返回颜色。大图里这个函数会走很多次，不要在里面创建复杂对象或读 DOM。

渐变、纹理属于 graphic.LinearGradient / RadialGradient。直接写 CSS 渐变字符串不会生效。

文本样式

textStyle 出现在 title、legend、axisLabel 等组件上，字段是 color、fontSize、fontFamily、fontWeight。fontSize 是数字。全局默认可以放在根上的 textStyle，各组件再覆盖。

暗色背景要用深色主题或自己把 axisLabel.color、splitLine.lineStyle.color 调亮。只改系列颜色、不改轴文字，深色页面上字会看不见。

样式不要写进数据

data: [{ value: 10, itemStyle: { color: 'red' } }] 能针对单点上色，但主题一换就要改数据。能用 visualMap 表达的映射，不要给每个点写死颜色。见《ECharts 数据视觉映射》。

易错

ECharts 5 里 emphasis、blur、select 与 itemStyle 平级。itemStyle.normal 和 itemStyle.emphasis 是 4.x 的套法，现在仍兼容，新配置不要再包一层 normal。

内置主题名是 'light' 和 'dark'。不传第二个参数时用的是 ECharts 5 的默认色板，和 echarts.init(dom, 'light') 不是同一套颜色：'light' 是另外注册的调色盘。自定义主题要先 echarts.registerTheme(name, theme) 再 init。没注册的名字会变成 undefined，图退回默认外观，不会抛错。

折线的 itemStyle.color 会同时变成线的颜色。线和点要分开时，线写 lineStyle.color，点写 itemStyle.color。某一系列自己的调色盘写在该系列的 color 数组上，只影响这一系列的数据项；itemStyle.color 仍然盖过调色盘。打开了按数值上色的 visualMap 时，调色盘和写死的 itemStyle.color 都可能被映射结果盖掉。
