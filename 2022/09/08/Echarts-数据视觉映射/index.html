ECharts 数据视觉映射

2022-09-08
  • Echarts
本文总阅读量次

人生自是有情痴，此恨不关风与月。

visualMap 取代 dataRange

ECharts 3 起，用数值区间映射颜色、大小、透明度的组件叫 **visualMap**。ECharts 2 的 dataRange 已废弃，新 option 里不要再写。

两种类型：

  • continuous：连续型，一条色带。
  • piecewise：分段型，离散区间或类目。

dimension 指数据的哪一维参与映射。类目轴 + 数值的常规柱状图里，数值常常是第 0 维；用 dataset 时要按列下标对准。映射错列，颜色会看起来「随机」。

能映射的视觉通道

inRange / outOfRange 里常见：color、symbolSize、opacity、colorAlpha、colorLightness、colorSaturation。散点图用数值控制 symbolSize，热力图用数值控制 color。

calculable: true 让用户拖色带两端过滤。过滤是视觉上的隐藏，不等于把 series.data 删掉。监听 datarangeselected 才能知道用户选了哪一段。

分段

人数、等级这种本来就是档的数据用 piecewise，避免连续色带暗示不存在的中间值。

区间是否包含端点由 min / max 与 lt、lte、gt、gte 控制。相邻段把同一个端点各写一次时，要确认点落在哪一段，避免两端都匹配或都不匹配。

和系列 itemStyle 的优先级

单点上写了 itemStyle.color 会压过 visualMap。整系列写死颜色也会让映射看起来「没生效」。要映射就不要再给系列固定 color，把调色交给 inRange。

多个 visualMap 用 seriesIndex 指到不同系列。不写时作用于所有支持的系列，饼图这类没有二维量的系列可能出现不符合预期的着色。

min 和 max

不写 min / max 时，ECharts 用数据自己的极值。数据更新后极值变了，同一种颜色代表的数值会变，两张图不能直接对比。对比场景把 min、max 写成业务口径的固定值。
