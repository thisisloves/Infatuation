React 父组件调用子组件方法

  • React

曾经拥有的，不要忘记。不能得到的，更要珍惜。属于自己的，不要放弃。已经失去的，留作回忆。

先考虑要不要调用

父组件想「调用一下子组件」，多数是状态放错了层。把状态提升到父组件，子组件变成受控的，父组件改 props 即可，不必拿子组件的方法。剩下的才是命令：聚焦、滚动到某行、播放器跳转、第三方实例的 resize()。

类组件：ref 指向实例

ref.current 在子组件 commit 之后才是实例。渲染父组件的函数体时不要调用。onClick 里调用是安全的。

函数组件：forwardRef

函数组件没有实例。React 18 用 forwardRef 把 ref 接进来，再用 useImperativeHandle 暴露方法。不要把整个 DOM 都交出去。

React 19 可以把 ref 直接写进子组件参数，不必 forwardRef。库要兼容 18 时仍用 forwardRef。API 名是 forwardRef。

调用前判断 null

子组件条件渲染为 null 时，childRef.current 是 null。用可选调用。列表里要调用某一项时，不要假设一个 ref 能代表所有项，用回调 ref 记到 Map 里，key 用稳定 id。

命令式调用不参与渲染。若父组件需要知道「子组件现在是否聚焦」来画界面，那份信息要用 state 抬上来，而不是在渲染时读 ref。
