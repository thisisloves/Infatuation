React 组件

2022-04-20
  • React
本文总阅读量次

愿将你葬此，三生成牵挂。

组件是返回元素的函数

函数组件接收 props，返回 React 元素、null、布尔值、字符串、数字或它们的数组。名字必须大写，否则 JSX 会把它当成 DOM 标签。

类组件继承 React.Component，实现 render()。需要错误边界时才必须用类。其余新代码用函数组件和 Hooks。

一个文件可以有多个组件，但只把页面会引用的那些导出。小组件放在使用它的文件里即可，不必一律拆文件。

props 是只读的

不要改 props 上的字段，也不要改 props 里的对象。父组件把同一对象传给别人时会被一起改掉。需要变化就放 state，或调用父组件传入的函数请父组件改。

children 是 props 的一个字段。<Layout><Main /></Layout> 里，Main 元素就是 Layout 的 props.children。

组合而不是继承

React 不用继承组件来扩展界面。把可变区域做成 children，或做成具名的元素 prop：

继承 React.Component 只为了接入生命周期或错误边界，不要再建 BaseButton extends Button 这种组件层级。复用行为用自定义 Hook。

纯渲染

同样的 props 和 state 应返回同样的元素结构。不要在函数体里请求数据、订阅、直接改 DOM、用 Math.random() 决定结构（除非那就是状态的一部分并已存进 state）。列表必须有稳定 key。

组件状态属于哪一层，就定义在哪一层。只被一个子组件用的草稿，放在子组件。兄弟都要读，放到它们的父组件，再通过 props 传下去。
