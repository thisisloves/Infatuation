JDBC 是什么

  • JDBC（Java Database Connectivity）是 JDK 提供的访问关系型数据库的标准 API。
  • 厂商提供 驱动 JAR（如 MySQL Connector/J），实现 java.sql 接口；业务代码面向接口编程。
  • 典型流程：加载驱动 → Connection → Statement/PreparedStatement → ResultSet → 关闭资源。

练习项目结构（jdbcManage）

  • 连接信息放在 **jdbc.properties**，由 DBUnit 静态块加载，避免把账号密码写死在业务代码里。

为什么用 PreparedStatement？

  • 预编译 + 占位符 ?，降低 SQL 注入风险。
  • 同类 SQL 可复用执行计划，性能通常更好。
  • 切忌 "... where eid = " + eid 这种字符串拼接。

事务

  • Spring 的 @Transactional 最终也是在管理 Connection 的提交 / 回滚。

常见坑

问题 原因 / 处理
ClassNotFoundException: com.mysql.cj.jdbc.Driver 驱动依赖未引入或类名写错（8.x 用 cj）
Communications link failure 地址、端口、防火墙、MySQL 未启动
结果集用完才关 Connection 导致连接泄漏，池被耗尽
getNString / 编码乱码 URL 加 characterEncoding=utf8，表字符集一致
