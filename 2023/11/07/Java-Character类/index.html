Java Character 类

包装一个 char

char 是基本类型。需要对象（例如集合元素、泛型）时用包装类 Character。它是 final 类，继承 Object，实现 Comparable<Character> 和 Serializable，不继承 Number。

自 Java 5 起可以自动装箱、拆箱。Java 9 起，new Character('a') 被标记为废弃并计划移除，不要再调用构造器。

Character.valueOf 对 '\u0000' 到 '\u007F' 返回缓存里的同一批对象，所以这个范围内 == 可能为真。超出缓存后 == 比较的是两个对象。判断字符是否相同，比较基本类型 char，或用 equals。

把 char 传给需要 Character 的方法时发生装箱；返回 Character 再赋给 char 时拆箱。拆箱对象若是 null，抛 NullPointerException。

转义序列

字符串或字符字面量里，反斜杠开头的序列由编译器解释，不是 Character 类的方法。

写法 含义
\t 制表符
\b 退格（U+0008），不是正则里的单词边界
\n 换行
\r 回车
\f 换页
\' \" \\ 单引号、双引号、反斜杠
\uXXXX 四位十六进制 Unicode 码元

正则表达式里的 \b、\d 是另一套规则，写在 Java 字符串里还要再转义成 "\\b"。不要和字面量转义混用。

判断与转换

这些方法大多是静态的，参数是 char 或码点 int。带 int 的重载才能正确处理辅助平面字符。

方法 作用
isLetter / isDigit 是否字母、是否数字（Unicode 意义，不限于 ASCII）
isLetterOrDigit 字母或数字
isWhitespace 是否 Java 定义的空白
isUpperCase / isLowerCase 大小写
isDefined 是否已分配的 Unicode 码点
toUpperCase / toLowerCase 转换。个别字符需要 Locale，这些方法不用区域设置
toString(char) 得到长度为 1 的字符串
digit(char, radix) 按进制取数值，不是数字时返回 -1
forDigit(int, radix) 反过来得到字符

ASCII 判断不要只用 c >= '0' && c <= '9' 去处理用户输入里的全角数字，除非你故意只接受 ASCII。反过来，做编程语言词法分析时，往往就要限制成 ASCII，这时用码点范围比 isLetter 更合适，因为 isLetter 会把汉字也当成字母。

码元和码点

char 只有 16 位，存的是 UTF-16 码元。U+FFFF 以后的字符要两个 char。

遍历字符串的「字符」时应按码点，而不是每个 charAt(i) 都当成独立字符：

Character.MIN_VALUE 是 '\u0000'，MAX_VALUE 是 '\uFFFF'。这是码元范围，不是「Unicode 最大码点」。最大码点是 Character.MAX_CODE_POINT（U+10FFFF）。

常见坑

  1. new Character('a')。用字面量装箱或 valueOf。
  2. 缓存范围内用 == 比较 Character，换一个大于 127 的字符就失败。
  3. 把 isDigit 理解成「只有 '0' 到 '9'」。
  4. 用 char 截断 emoji，写入数据库时变成乱码或半个代理项。
  5. 字符串里的 "\b" 和正则 "\\b" 含义完全不同。
  6. 示例里调用了不存在的 test('x')。转换应使用 Character 上真实存在的静态方法。

小结

Character 是 char 的不可变包装，用装箱而不是构造器。判断、转换优先用它的静态方法，并分清 ASCII、Unicode 码元和码点。转义序列属于字面量，不属于这个类的运行期 API。
