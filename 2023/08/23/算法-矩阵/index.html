矩阵

矩阵是什么

矩阵是按长方形排列的一组数。m 行 n 列记作 m × n，第 i 行第 j 列的元素写成 aij，整个矩阵可以记成 (aij) 或 Amn。元素是实数时叫实矩阵，是复数时叫复矩阵。行数和列数都是 n 时叫 n 阶方阵。

在程序里，矩阵就是二维数组，几乎总是行主序：第 i 行第 j 列放在 a[i][j]。列主序会先沿列连续存放，和 Fortran、部分数值库一致。两种布局相乘之前要先说清楚，否则下标会读串。

线性运算

同型矩阵才能相加或相减，也就是行数相同、列数相同。对应位置相加，结果仍是 m × n。加减法和数乘合称线性运算。

加法满足交换律和结合律，前提仍是三个矩阵同型。不同型的矩阵没有加法。

减法是加上相反数：每个元素取负再相加。

数乘把标量乘到每一个元素上。它满足结合律，以及对数的加法和矩阵的加法的分配律。

这些运算每个元素只看自己的位置，时间是 O(mn)。

转置、共轭、共轭转置

转置把第 i 行变成第 i 列，m × n 变成 n × m。(Aᵀ)ᵀ = A，并且 (A + B)ᵀ = Aᵀ + Bᵀ，(kA)ᵀ = kAᵀ。方阵若等于自己的转置，就是对称矩阵。

共轭把每个复数元素的虚部取负，实部不动。共轭转置是先共轭再转置，记作 A*。实矩阵的共轭转置就是转置。

乘法

A 是 m × n、B 是 n × p 时，乘积 C 是 m × p。C 的第 i 行第 j 列，是 A 的第 i 行与 B 的第 j 列对应相乘再相加。A 的列数必须等于 B 的行数，否则乘法没有定义。

把两个因子对调，形状首先就不一定成立。即便都是方阵，AB 和 BA 也通常不相等。乘法满足结合律，对加法满足分配律，不满足交换律。

单位矩阵 I 的主对角线是 1，其余是 0。方阵 A 满足 AI = IA = A。不是每个方阵都有逆矩阵；有逆时才写 A⁻¹，并且 AA⁻¹ = I。

朴素乘法做 m × p × n 次乘加，时间 O(mnp)，方阵就是 O(n³)。Strassen 一类算法渐近更快，常数大，小矩阵仍用三重循环。

k 放在 j 的外层，是为了让 A 的一个元素复用，并让 C 的一行写得更连续。先写对三重循环，再谈换循环顺序。

注意

  • 向量是 n × 1 或 1 × n 的矩阵。用行向量还是列向量，会影响它乘在左边还是右边。
  • 下标在数学里常从 1 开始，在 C 和 JavaScript 里从 0 开始。抄公式时要换算。
  • 整数矩阵相乘会溢出。排名、图的可达性若只关心 0 和 1，可以用布尔或取模，不要默认用 32 位整数硬乘。
