Java Math 类和 Number 类

2023-12-15
  • Java
本文总阅读量次

这世界上有一千种等待，最好的那种叫做来日可期，我愿意从这一秒开始倒数等待多年后的相遇。

基本类型和包装类

八个基本类型对应八个包装类，包装类都是 final，不能继承。

基本类型 包装类 是否继承 Number
byte short int long Byte Short Integer Long 是
float double Float Double 是
char Character 否
boolean Boolean 否

Number 是 java.lang 里的抽象类，表示「可以取出数值」。BigInteger、BigDecimal、原子整数类也继承它。Character 和 Boolean 不是数，不继承 Number。

自 Java 5 起自动装箱、拆箱：

Java 9 起，new Integer(1) 这类构造器已废弃，用 valueOf 或字面量装箱，才能用到缓存。

Number 上有哪些方法

Number 自己的方法是把值取成基本类型：

方法 作用
intValue longValue floatValue doubleValue 抽象方法，子类必须实现
byteValue shortValue 默认实现是对 intValue 做窄化转换，可能溢出

compareTo、equals、toString 来自 Object 或 Comparable，不是 Number 声明的。valueOf、parseInt 是各包装类自己的静态方法，例如 Integer.parseInt("12")。不要写成 number.parseInt()。

parseInt 解析失败抛 NumberFormatException。它不接受小数，也不要拿来解析用户输入里的千分位逗号。Integer.parseInt 还有带进制的重载。

拆箱前先看是不是 null：Integer n = null; int x = n; 会空指针。

整数缓存与比较

Integer.valueOf 默认缓存 -128 到 127。这个范围内两次装箱可能是同一对象，== 为 true；范围外 == 为 false。equals 比较数值。

缓存上界可以用系统属性调大，下限仍是 -128。不要依赖 ==。Long 也缓存一小段，Double 不缓存可预测的整数区间。

包装类参与 ==、< 等运算时会拆箱。Integer 和 int 比较会拆箱；两个 Integer 用 == 则比较引用。

Math

java.lang.Math 是 final 类，构造器私有，不能 new。方法全是静态的。三角函数的参数是弧度，不是角度。toRadians / toDegrees 负责换算。

Math.PI 和 Math.E 是 public static final double。

方法 作用
abs 绝对值。Integer.MIN_VALUE 的绝对值仍是它自己，因为正数一侧放不下
ceil 不小于参数的最小整数，返回 double。ceil(1.1) 为 2.0，ceil(-1.1) 为 -1.0
floor 不大于参数的最大整数，返回 double
round(float) 返回 int
round(double) 返回 long。等价于 (long) floor(x + 0.5)
min / max 两个同类型参数里较小或较大的一个
pow pow(a, b) 是 a 的 b 次方，返回 double
sqrt 非负参数的算术平方根，负数得到 NaN
random [0.0, 1.0) 上的 double，不含 1。要整数范围用 Random 或 ThreadLocalRandom，不要对 random() 做有偏的取模

round 对正数看起来是四舍五入，.5 朝正无穷方向走：round(1.5) 为 2，round(-1.5) 为 -1 而不是 -2。需要「一半向偶数舍入」或十进制精度时用 BigDecimal，不要用 Math。

Math 里很多方法是平台内建实现。要求跨 JVM 逐位一致的结果时看 StrictMath，它更慢。自 Java 17 起默认浮点语义已经是严格的，一般计算用 Math 即可。

随机数

Math.random() 共用一个 Random，方便但有竞争。多线程用 ThreadLocalRandom.current().nextInt(origin, bound)，bound 不含。加密场景用 SecureRandom，不要用 Math.random() 生成令牌。

常见坑

  1. 认为八个包装类都继承 Number。
  2. 在 Number 上找 parseInt 或 valueOf。
  3. Integer 用 == 比较，127 能过、128 失败。
  4. Math.sin(90) 当成正弦 90 度。90 弧度不是直角。
  5. round(-1.5) 的结果和「远离 0 的四舍五入」不同。
  6. (int) Math.ceil(x) 在 x 很大时溢出；钱用 BigDecimal。

小结

数值包装类继承 Number，Character 和 Boolean 不继承。装箱用 valueOf，比较数值用 equals 或先拆箱。Math 的方法是静态的，角度先换成弧度，舍入规则以 floor(x + 0.5) 为准。精确十进制用 BigDecimal。
