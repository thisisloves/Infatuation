数据结构 栈

2023-06-18
  • 数据结构
本文总阅读量次

你本无意过堂风，偏偏孤倨引山洪。

栈是什么

栈是后进先出的线性表，只在栈顶插入和删除。顺序栈用数组加下标，缓存友好，要处理栈满。链栈用结点，一般不受固定容量限制，每次多一次指针跳转。

push、pop、peek 都是 O(1)。空栈不能 pop。数组栈满时要么报错，要么扩容；扩容那一次是 O(n)，均摊仍是 O(1)。

函数调用也是栈，但那是进程的调用栈。手写的数据栈满了可以改容量，调用栈过深会直接让进程崩溃。递归能写的算法，都应知道最深会压多少层。

用在哪里

  • 括号匹配、中缀表达式转后缀、语法分析里的符号栈。
  • 深度优先搜索的非递归写法：栈里放待访问的结点。
  • 单调栈：从栈底到栈顶保持递增或递减，用来求「右边第一个更大的元素」。每个下标最多进栈出栈一次，整体 O(n)。

单调栈处理 [2, 1, 4] 时，1 右边第一个更大是 4，2 的右边第一个更大也是 4。比当前元素小的栈顶不可能再成为更左元素的答案，所以弹出。

顺序栈与括号

top 表示元素个数。空栈是 0，压入写到 a[top] 再自增，弹出先减再读。

{[()]} 每种右括号都遇见对应的左括号，最后栈空，结果是 1。([)] 里，期待 ) 时遇见 ]，结果是 0。只统计个数是不够的：([)] 的三种括号数量都配平，顺序仍然错。

扫完后栈里还剩左括号，同样失败。这就是「最后要检查栈空」的原因。

注意

  • 栈适合「最近未完成的事情先处理」。需要先进先出时用队列，不要用栈硬模拟。
  • Java 里作栈应使用 ArrayDeque 的 push、pop、peek。java.util.Stack 继承自 Vector，方法带同步，新代码不必用它。
  • 表达式求值时，操作数栈和运算符栈是两套。运算符入栈前要先把优先级更高或相等的栈顶算掉，相等时先算栈顶才能保证从左到右。

括号栈要看顺序

([)] 的左右括号个数都相等，扫描到 ) 时期待的栈顶却是 [，应判失败。只计数字会判成成功。扫完后栈里若还剩左括号，同样失败，(( 就是这种。

单调栈求右边第一个更大元素时，栈里从底到顶保持递减。新元素弹出所有比它小的栈顶，那些被弹出的下标，右边第一个更大就是当前元素。每个下标进出一次，整体 O(n)，不是为每个位置向右扫描的 O(n²)。

调用栈不是这个数组

递归过深时崩溃的是进程调用栈，把手写栈的容量调大解决不了。手写栈满了可以返回失败或扩容。top 表示元素个数时，空栈是 0，弹出前要先判断。Java 里用 ArrayDeque，不必用继承 Vector 的旧 Stack。
