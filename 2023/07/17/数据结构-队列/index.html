队列是什么

队列先进先出：队尾入队，队头出队。用数组实现时，如果每次出队都把后面的元素左移一格，单次出队是 O(n)。循环队列或链式队列把入队、出队都做成 O(1)。

操作 含义 循环队列
enqueue 队尾放入 写到 (front + len) % cap
dequeue 取出队头 front 前进一格
peek 只看队头 不改 front 和 len

链式队列用头尾两个指针，入队改尾，出队改头，也是 O(1)。队列空时两个指针都是空，出队最后一个元素后要把尾指针一并清空，否则尾指针悬空。

变种

双端队列两端都能进、能出，可以当作栈，也可以当作队列。滑动窗口的单调队列用它在队尾弹出已经不可能成为最大的元素，在队头弹出滑出窗口的下标。

优先队列按优先级出队，不是按进入顺序。二叉堆是它的常见实现，出队 O(log n)，和这里的 FIFO 队列不是同一结构。

只使用 front 和 rear、不保存长度时，队空和队满都可能表现为两个指针重合。解决办法是浪费一个空位：(rear + 1) % cap == front 表示满。下面的例子改用 len，容量可以全部用上。

循环队列

front 指向队头，len 是当前元素数。队满是 len == cap，队空是 len == 0。头指针前进时取模，数组不用整体左移，这就是避免假溢出。

入队 1 到 5，出队顺序仍是 1 2 3 4 5。若先出队两次再入队 6、7，6 会写进数组前部空出来的槽，逻辑顺序不变。

广度优先搜索

无权图上从源点逐层扩展，队列里放当前层的顶点。每个顶点入队一次、出队一次，邻接表上的时间是 O(V + E)。队列里同时存在的顶点不超过一层的宽度。

二叉树层序遍历是同一件事：先放入根，每一轮把当前队列长度记下来，正好弹出这一层，并把孩子们排到队尾，成为下一层。

注意

  • rear 有人定义成「下一个空位」，有人定义成「最后一个元素」。和 front 混用时先写清楚，否则空、满判断会差一格。
  • Java 的 ArrayDeque 作队列用 offer 和 poll，不要用会在失败时抛异常的 add、remove，除非你确实要异常。
  • 多线程里普通队列没有原子性。一个生产者一个消费者可以用并发队列，不能只在外面加一个没覆盖全部读写的标志。

假溢出

容量 4 的数组，先入队 1、2、3、4，再出队两次。逻辑上只剩 3 和 4，数组后半却已经写满。若 rear 只加不取模，会认为队列满，前两个空位用不上，这就是假溢出。rear 和 front 对容量取模后，下一次入队写回下标 0，容量仍然是 4。

用 len 区分空和满时，四个槽都能放元素。若不想保存 len，就要空出一个槽，(rear + 1) % cap == front 才是满。两种约定不能在同一段代码里各用一半。

层序遍历就是这个队列

根先入队。每一轮记下当前长度，正好弹出一层，孩子排到队尾。shift 在数组上是线性搬移，总时间会变成平方。用头下标前进，每个结点只处理一次，才是 O(n)。优先队列按键值出队，不是这一节的先进先出。

链式队列出队到空时，头尾指针都要置空。只移动头指针、尾指针仍指向已释放结点，下一次入队会写到已经 free 的内存。循环数组没有这个问题，槽位一直在，len 为 0 就是空。

双端队列两端都能进出，滑动窗口用它维护可能成为最大的下标。那是单调队列，出队顺序不再等于入队顺序。
