图

图 G = (V, E)，V 是顶点，E 是边。边可以有向或无向，也可以带权，权表示距离、费用或容量。无向边在存储时通常存成两条有向边。n 个顶点的无向简单图最多 n(n - 1) / 2 条边，有向简单图最多 n(n - 1) 条。

稀疏图的边数接近顶点数量级，稠密图接近顶点的平方。选存储结构先看哪一种。

存储

结构 空间 查一条边 遍历一个点的邻居 适用
邻接矩阵 O(V²) O(1) O(V) 稠密图、需要快速判断有没有边
邻接表 O(V + E) O(度) O(度) 稀疏图，大多数实际网络

矩阵里 adj[i][j] 非 0 表示有边。无向图的矩阵对称。带权时用权值代替 1，并用一个矩阵里不会出现的数表示「没有边」，0 只在权不可能为 0 时才能当空。

遍历

深度优先用递归或显式栈，沿着一条路走到不能再走，再回溯。广度优先用队列，先访问离起点更近的顶点。

邻接表上两者都是 O(V + E)。邻接矩阵上检查所有可能的边，是 O(V²)。无向图的连通分量：从每个未访问顶点启动一次搜索。有向图的强连通分量要用 Tarjan 或 Kosaraju，普通 DFS 不够。

无权图（每条边代价都是 1）上，广度优先第一次到达某点的层数就是最短路。边权不等时这个结论不成立。

邻接矩阵上的广度优先

顶点编号 0 到 5。队列用 rear 和元素个数，容量等于顶点数，因为每个点最多入队一次。

从 0 出发，先访问邻居 1 和 2，再扩展他们的未访问邻居。一种合法顺序是 0 1 2 3 4 5。入队时就标记已访问，而不是出队时才标记，否则一个顶点会被多个前驱重复入队。

常见算法该看权

问题 算法 限制
无权最短路 广度优先 边权都是 1
非负权最短路 Dijkstra 不能有负权
可有负权、无负环 Bellman-Ford 可检测负环
所有点对 Floyd-Warshall O(V³)，实现短
最小生成树 Kruskal、Prim 无向连通、权可比较
拓扑序 入度为 0 的点反复入队 仅有向无环图

Dijkstra 每次扩展当前距离最小的未确定顶点，用二叉堆时是 O((V + E) log V)。有负权时「已经确定」这个前提不成立，要换 Bellman-Ford。

注意

  • 遍历前先把访问数组清零。多个测试用例复用同一块数组时，这是最常见的漏掉。
  • 有向边只放入 adj[u][v]，不要习惯性地再写对称的一条，除非图确实无向。
  • 稀疏图用矩阵既费内存，遍历邻居也慢。顶点编号若不连续，先离散化再当矩阵下标。

入队时标记

广度优先在把邻居放进队列时就标成已访问。出队时才标记，会让多个前驱把同一个顶点反复入队。无权图上第一次到达的层数是最短路。边权不等时改用 Dijkstra，并且要求权非负。邻接表的遍历是 O(V+E)，矩阵是 O(V²)。
