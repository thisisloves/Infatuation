数据结构 堆

2023-05-30

忍把浮名，换了浅斟低唱。

二叉堆

这里的堆是一棵完全二叉树，并且满足堆序：大根堆里父结点大于等于孩子，小根堆里父结点小于等于孩子。堆顶就是当前最值。它不是内存管理里的「堆区」，两个词只是同名。

完全二叉树用数组存放时没有空洞。下标从 0 开始，结点 i 的父结点是 (i - 1) / 2，左孩子是 2i + 1，右孩子是 2i + 2。下标从 1 开始则父结点是 i / 2，孩子是 2i 和 2i + 1，除法用整数。

操作代价

操作 做法 时间
查看最值 读堆顶 O(1)
插入 放到末尾再上浮 O(log n)
弹出最值 末尾补到堆顶再下沉 O(log n)
建堆 从最后一个非叶结点开始下沉 O(n)
堆排序 建堆后弹出 n 次 O(n log n)，不稳定

建堆是 O(n)，因为靠近叶子的结点下沉高度很小。高度为 h 的结点大约 n / 2^(h+1) 个，总代价按高度求和仍是线性。不要把建堆写成 n 次插入的 O(n log n)，那是另一种写法，更慢。

优先队列的抽象是「每次取最值」。二叉堆是它最常见的实现。Java 的 PriorityQueue 默认是小根堆，要大根堆需提供相反的比较器。TopK、合并 K 路有序链表、Dijkstra 都用它。

堆排序与 TopK

升序可以把数组建成大根堆，把堆顶换到末尾，再对前 n - 1 个元素下沉，重复 n 次。它是原地排序，额外空间 O(1)，最坏也是 O(n log n)。相等元素可能交换到对方前面，所以不稳定。

只需要最大的 K 个元素时，维护大小为 K 的小根堆。新元素大于堆顶才替换堆顶并下沉。时间是 O(n log K)，堆里留下的是最大的 K 个，堆顶是这 K 个里最小的那个。

注意

  • 上浮只跟父亲比，下沉要跟左右孩子里更符合堆序的那个比。删堆顶后如果还用上浮，堆序会坏。
  • 数组容量和元素个数是两个量。下沉时孩子下标必须先和 size 比较，否则会读到已弹出的旧值。
  • 斐波那契堆的摊还插入是 O(1)，实现复杂。教学和业务代码里的「堆」默认指二叉堆。
