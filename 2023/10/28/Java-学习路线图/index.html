Java 学习路线图

2023-10-28
  • Java
本文总阅读量次

山有木兮木有枝，心悦君兮君不知。

写在前面

  • 本系列按由浅入深的练习顺序整理。
  • 路径：语言基础 → JDBC / Servlet → Spring 核心 → SSM / Boot 单体 → 微服务与中间件。
  • 已有语言篇（数据类型、集合、反射、泛型、多态等）可继续保留；本路线图之后的文章侧重 工程化与框架，文中会引用示例工程里的类名与配置。

能力地图（一图看懂）

阶段一：语言基础练习

目录：javaStudy、bookManage、javaItem

主题 练习里大致对应 建议掌握程度
OOP 继承 / 接口 / 抽象类 / 多态 Demo 能手写类图对应代码
集合与泛型 ArrayList / HashMap / Generics_Test 清楚 List / Map / Set 选型
IO / 序列化 ObjectInputStream 等 理解流与关闭资源
多线程 TestThread2 / ThreadClassDemo 知道 Runnable 与可见性
Java 8 java8/* Lambda、Stream、Optional 能写
GUI 小项目 Swing、图书管理、五子棋 理解事件驱动即可

自学检查清单

  1. 值传递 vs 引用传递：改对象字段会不会影响实参？
  2. equals / hashCode 契约：HashMap 的 key 要注意什么？
  3. 受检异常与运行时异常分别何时用？
  4. 线程安全：为什么 ArrayList 多线程下不安全？

阶段二：数据访问与 Web

目录：jdbcManage、servletDemo

  1. JDBC：DBUnit 读 properties、DAO 查 employee、PreparedStatement 防注入。
  2. Servlet：生命周期、Cookie / Session、上传下载、ServletContext。
  3. 目标：弄清「浏览器 → Tomcat → 业务类」调用链，否则后面看 DispatcherServlet 会懵。

与后续关系：Spring MVC 的前端控制器本身就是 Servlet；MyBatis / MP 底层仍是 JDBC。

阶段三：Spring 核心

目录：spring_01_bean ~ spring_05_ssm

项目 核心收获
spring_01_bean XML IoC、构造器 / setter / 自动装配、生命周期
spring_02_annotation @Configuration、@ComponentScan、@Import
spring_03_aop @Aspect、@Around、切点 execution
spring_04_mvc @RestController、JSON CRUD 雏形
spring_05_ssm 三层整合 + 业务 / 系统异常分层

为什么一定要按这个顺序？

  • 没有 IoC，注解只是「语法糖」；
  • 没有 AOP，看不懂 @Transactional 为何有时失效；
  • 没有 MVC，Boot 里的 @GetMapping 只是魔法；
  • 没有 SSM，Boot 自动配置会像黑盒。

阶段四：持久化、Boot 与 JVM

  1. MyBatis-Plus → Spring Boot 自动配置 / 配置与起步 / 项目实践
  2. Spring 事务管理（单库）
  3. JVM：内存模型 → 垃圾回收 → 调优
  4. 工程：mybatis-plus-item、bookSystem、sky-item

检查点：能否画出「登录 → JWT → 拦截器 → Service → Mapper → MySQL」；能否说清一次 Full GC 可能从哪查起。

阶段五：微服务主线（12 篇，无 day 编号）

对照商城练习工程 hmall，建议阅读顺序：

  1. MyBatis-Plus
  2. Docker
  3. 微服务 概述与拆分
  4. 微服务 Nacos 注册发现
  5. 微服务 OpenFeign
  6. 微服务 Gateway
  7. 微服务 JWT 网关鉴权
  8. 微服务 Nacos 配置管理
  9. 微服务 Sentinel 服务保护
  10. Seata 分布式事务
  11. RabbitMQ → 微服务 RabbitMQ 高级
  12. 微服务 Elasticsearch

加餐：负载均衡、Redis、微服务面试要点。

组件 工程位置 要搞懂
拆分 user / item / cart / order / pay 边界与数据私有
Nacos 注册 + 配置 Namespace / Group / 鉴权
Feign hm-api 超时、降级
Gateway hm-gateway 路由、JWT、动态路由
MQ / Seata mq-demo、TC 可靠投递、映射与集群

推荐阅读顺序（本站）

  1. 本篇路线图
  2. Java 8 → JDBC → Servlet
  3. Spring IoC → 注解 → AOP → MVC → 事务 → SSM
  4. MyBatis-Plus → Boot 自动配置 / 配置 → 项目实践
  5. JVM：内存模型 → 垃圾回收 → 类加载 → 调优
  6. 上面微服务 12 篇 + 加餐
  7. 下方「高频面试对照」查漏

学习方法建议

  1. 每学一块至少跑通一个最小 Demo，并整理笔记。
  2. 出问题先画调用链：客户端 → 网关 → 服务 → DB / MQ / Seata。
  3. 配置对齐：地址、Group/Namespace、账号（Nacos / Seata）。
  4. 笔记里记下真实报错与处理，比只抄组件名单有用。
