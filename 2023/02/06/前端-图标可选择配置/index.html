前端 图标可选择配置

  • 前端

图标要能选，并且能画出来

后台里让运营选择图标时，需要两份东西：一份是图标清单，用来渲染下拉框；一份是运行时能画出这个图标的资源。iconfont（iconfont.cn，阿里巴巴矢量图标库）下载的压缩包里，iconfont.json 是清单，iconfont.js 是 Symbol 脚本。不要把 JSON 当成 scriptUrl。

Ant Design 的 createFromIconfontCN 要求 scriptUrl 指向 Symbol 的脚本地址，可以是包里的 iconfont.js，也可以是在线生成的 //at.alicdn.com/t/c/font_xxx.js。在线地址升级图标后会变，项目里锁定文件更稳。

JSON 里每个图标有 font_class。Symbol 的引用名一般是 icon- 加上这个 class。两边要使用同一套前缀，和生成脚本时的设置一致。

选择器

Option 要从 antd 引入，或者改用 Select.Option。下面只保留和图标有关的代码。

key 用 icon_id，不要用数组下标，否则清单排序后选中状态会串。存进数据库的是 font_class 字符串，例如 user。展示时再拼成 icon-user。不要把整个 SVG 存进业务表。

下拉框很宽、图标很多时，Select 打开 showSearch，按 font_class 或中文名过滤，避免一次渲染上千个 SVG。

菜单里再画出来

菜单数据里只有保存的 icon 字段。渲染时用同一个 IconFont。

item.icon 为空时不要渲染 IconFont，否则控制台会提示找不到 symbol。可以准备一个默认图标名。

字体方式和 Symbol 方式

下载页若选的是 font-class，页面要引 CSS，再用 <i className="iconfont icon-user" />。这种方式是字体，多色图标会丢颜色。createFromIconfontCN 走的是 Symbol，彩色图标能保留，所以脚本必须是 JS，不是 CSS，也不是 JSON。

两种方式的 class 前缀要和项目里实际引用的前缀一致。混用「CSS 的 font_class」和「Symbol 的 type」会画出空白方框。

可访问性

图标旁边已有文字时，给 SVG 加 aria-hidden，避免读屏读两遍。只有图标、没有文字的按钮，用 aria-label 写明动作。不要把图标的英文 class 当按钮名称读出来。
