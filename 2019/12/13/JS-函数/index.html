概念

函数是可调用的值，不依赖事件也能执行。事件处理只是调用方式之一。

创建方式：

声明可以被提升后提前调用；表达式和箭头函数要等赋值执行到。箭头函数没有自己的 this、arguments、prototype，不能当构造函数。

形参是定义时的名字，实参是调用时传入的值。两者数量不必一致：实参少了，多出的形参是 undefined（除非写了默认值）；实参多了，普通函数里多余的值在 arguments 或剩余参数里。

没有 return，或 return 后面不带值，结果都是 undefined。return 同时结束函数。

构造函数用 new 调用时，this 是新对象。普通调用时 this 取决于调用方式，严格模式下落成 undefined。

常见坑

  • function fn(a, b) //形参 { 这种写法非法。注释不能插在参数列表和函数体之间把 { 隔开。
  • 「形参和实参必须一一对应」不是语言规则。
  • 箭头函数里没有 arguments，向外层普通函数去取会拿到外层的实参，经常不是你以为的那一组。
  • 默认值在调用时、且该参数为 undefined 时才求值。传入 null 不会触发默认值。
  • 参数名和函数里的 var 同名时，提升会搅在同一个绑定上。块里用 let 更清晰。
  • 立即执行函数若写成 function () {}() 会被解析成声明，括号位置不对就语法错误。外面再包一层括号，或用 void function () {}()。

调用和返回值

普通函数、方法、构造函数是同一种函数值的不同调用方式。fn()、obj.fn()、new fn() 的 this 不同，函数体不必写成三种。箭头函数固定使用外层 this，适合回调，不适合做需要动态 this 的方法，也不能 new。

return 后面换行时，自动分号可能让函数返回 undefined，实际要返回的对象字面量变成了下一句孤立表达式。左花括号跟在 return 同一行。

剩余参数必须是最后一个形参，它是真数组。默认值里可以引用前面的形参，不能引用后面的。参数过多时，现代代码不必再读 arguments；若和剩余参数同时出现，arguments 不再包含被剩余参数「单独列出」之外的那种旧映射，不要两边同时改同一个参数还指望它们联动。

默认参数在传入 undefined 时求值，传入 null 不会。剩余参数是真正的数组，放在形参列表最后：

箭头函数没有 arguments，也不要把它当构造函数。立即执行的函数表达式外面要有括号，否则解析器会把它当成函数声明，声明不能立刻跟一对调用括号。

小结

函数是值。声明可提升，表达式不行；箭头函数没有 this 和 arguments。参数数量可以不匹配，多余实参用剩余参数接收，返回值缺省是 undefined。
