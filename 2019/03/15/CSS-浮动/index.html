CSS 浮动

  • float: left | right 让盒子靠向包含块一侧，直到碰到包含边或另一个浮动盒。
  • 浮动盒脱离普通流：后面的块级盒子在布局上会「当它不存在」，但行盒 / 文字仍会环绕浮动（典型图文混排）。

相关属性

属性 作用 常用值
float 是否浮动、向哪边 left right none
clear 哪一侧不允许出现浮动 left right both none

高度塌陷与清浮动

父元素里只有浮动子元素时，父级高度可能收成 0（背景、边框「塌掉」）。

常见清浮动手段：

  1. 末尾加 clear: both 的空块
  2. 父级 overflow: hidden / auto 触发 BFC（注意裁切与滚动条副作用）
  3. 伪元素 clearfix：

现在怎么用

  • 整页栅格、居中、等高列：优先 Flex / Grid，少靠浮动搭布局。
  • 浮动仍适合：文字环绕图片、少量 legacy 页面。需要「包住浮动」时用 clearfix / BFC，而不是层层 height 写死。
