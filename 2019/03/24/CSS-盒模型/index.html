CSS盒模型

2019-03-24
  • CSS
本文总阅读量次

长道相依，几恨别离，锦绣断相思意，待人相惜。

盒子由四层构成

  • 页面上每个元素都生成矩形盒。从外到内是 margin、border、padding、content。

  1. content：文字、图片或子元素。width / height 在默认模型里只量这一层。
  2. padding：内容与边框之间的留白，可点、可铺背景。
  3. border：可设宽度、样式、颜色。border 的粗细算进占位，outline 画在边框外且不占位。
  4. margin：边框外的透明间隔。box-sizing 不包含 margin。两个盒子的占位宽度还要再加左右外边距。

两种算法

  1. 标准盒模型（content-box，初始值）

  • 写出的 width / height 只指内容区。左右 padding、左右 border 加在宽度外面。
  • width: 200px; padding: 0 20px; border: 2px solid 的边框盒总宽是 200 + 40 + 4 = 244px。
  1. **border-box**（旧式 IE 在怪异模式下的算法，现已是标准可选值）

  • 写出的 width / height 含内容、padding、border。内容区被挤小，边框盒仍是你写的那个数。
  • 上面同一组声明，边框盒就是 200px，内容区约为 200 - 40 - 4 = 156px。

全局改成 border-box

  • 组件库和栅格几乎都按「你写的宽度就是占位宽度」来设计。在根上设定，再用继承传下去，第三方组件仍可自行改回 content-box：
  • 直接写 * { box-sizing: border-box } 也能用，但子组件想恢复标准模型时要逐个再声明。继承写法只改根或某一支。

和宽度百分比一起算

  • width: 100% 在 content-box 下是「内容区等于父级内容区」。再加上自己的 padding、border 就会超出父级。
  • 换成 border-box 后，100% 指边框盒，padding 向内吃内容，这是重置盒模型的主要原因。
  • min-width / max-width 跟随同一个 box-sizing。margin 仍然加在百分比之外。

行内盒与替换元素

  • 非替换行内元素的 width / height 无效，高度主要由 line-height 和字体决定；垂直 padding 会画出背景，却不一定把行距撑开。
  • img、video、input 等替换元素可以设宽高。图片还有默认的行内基线空隙，父级出现几像素「神秘高度」时，把图片设成 display: block，或让父级 line-height: 0。

外边距折叠

  • 纵向相邻的块级盒，外边距会折叠成一条（同号取绝对值更大者）。这发生在 margin 层，与 box-sizing 无关。
  • 新建 BFC、在中间放 padding 或 border，折叠就会断开。弹性布局和网格布局的子项之间不折叠，间距改用 gap。详见《CSS-BFC》。

量盒子时看哪一圈

  • offsetWidth 含 content、padding、border，不含 margin。clientWidth 含 content 与 padding，不含 border 与滚动条。
  • getComputedStyle 读到的 width 是用在内容区上的像素宽度。border-box 元素样式表里写 width: 200px，读出来的往往是减去 padding 和 border 之后的内容宽度。
  • box-shadow 和 outline 画在边框盒之外，不占布局，也不进 offsetWidth。用阴影做「间距」时，旁边的元素仍会叠上来。

宽度从哪来

  • 块级盒的 width: auto 会伸到包含块内容区减去自身水平 margin 之后的剩余宽度，这叫「填满可用空间」。这时再加 padding，在 content-box 下会溢出，在 border-box 下向内挤压内容。
  • max-width: 100% 能挡住图片、视频被固有宽度撑破父级。替换元素的固有尺寸先于 width: auto 的拉伸规则，裸 <img> 常常忽略父级宽度，直到写上 max-width: 100%; height: auto。
  • inline-size / block-size 是逻辑宽高，横排时分别对应 width 和 height，同样遵守当前的 box-sizing。

边框会吃掉内容

  • 表单控件常有浏览器自带的 padding 和 border。父级按 100% 排输入框时，不设 border-box 就会比格子宽出几像素，出现横向滚动。
  • outline 不占宽度，焦点环用它，避免焦点时布局抖动。border 一变粗，content-box 下整行都会被撑开。
