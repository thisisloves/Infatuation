CSS转换

2019-04-12
  • CSS
本文总阅读量次

霜雪明，照流星；千古事，任侠行。

transform 改变的是绘制

  • transform 在元素排好之后做移动、旋转、缩放、倾斜。文档流里的占位仍是变换前的盒子，旁边的元素不会躲开，点击区域则跟着变换后的形状走。
  • 多个函数写在同一条 transform 里。再写一条 transform 会整条替换，前后两次声明不会叠加。
  • 函数从右向左作用：transform: translateX(40px) rotate(30deg) 先旋转，再平移。顺序不同，落点不同。
  • 默认变换原点是元素中心 transform-origin: 50% 50%。绕左上角转时改成 0 0。
  • 非 none 的 transform 会建立层叠上下文，并成为固定、绝对定位后代的包含块。用来做动画的父级，常常因此「咬住」里面的 position: fixed。

平移 translate

  • translate(tx, ty) 沿自身坐标系移动。只写一个值时 ty 为 0。百分比相对元素自身边框盒，所以 translate(-50%, -50%) 可以把元素中心对准某个点。
  • 独立属性 translate: 50px 100px 与函数等价，且能和 rotate、scale 分成几条声明，不用挤在一个列表里。旧浏览器只认函数形式。
  • 位移动画优先改 transform，它走合成，不反复触发布局。改 top / left 会触发布局。

旋转 rotate

  • rotate(30deg) 在屏幕平面内顺时针转（Y 轴向下）。负角度逆时针。turn、rad 也可以，一圈是 1turn 或 360deg。

缩放 scale

  • scale(sx, sy) 是宽、高方向的倍数。只写一个值时两个轴用同一个倍数。scale(2, 3) 是宽 2 倍、高 3 倍。小于 1 缩小，负数相当于翻转后再缩放。
  • 缩放同样不改变布局占位。把图标放大 1.05 做悬停时，父级若 overflow: hidden 会裁掉溢出的角。

倾斜 skew

  • 现行写法是 skewX()、skewY()。两个参数的 skew(30deg, 20deg) 来自早期草案，主流浏览器仍接受，新代码分开写更清楚。负角往另一侧倾。

3D

  • rotateX / rotateY / rotateZ 绕对应轴转。没有景深时，绕 X、Y 的旋转只是压扁，看不出远近。景深写在父元素的 perspective，或写进子元素函数列表里的 perspective()。
  • perspective 数值越小，透视越强。transform-style: preserve-3d 让子元素待在同一个三维空间里；默认 flat 会把子级变换拍扁到父级平面。
  • backface-visibility: hidden 在卡片翻面时藏起背面。
  • translateZ(40px) 或 translate3d(x, y, z) 让元素靠近或远离观察者。正的 Z 在有景深时显得更大。
  • 早期 WebKit 与 IE9 需要 -webkit-transform、-ms-transform。IE9 只支持 2D。现在的浏览器认无前缀写法，前缀只留给必须兼容的旧环境。

常见坑

  • 写在右边的函数先作用。rotate(45deg) translateX(100px) 先沿元素自身的 X 轴移动，再旋转，落点在斜线上。translateX(100px) rotate(45deg) 先原地旋转，再沿水平方向平移。
  • transform 不能把行内非替换元素变成可变换盒的可靠对象时，先设 display: inline-block 或块级。
  • 变换后的元素用 position: fixed 的子孙会相对它定位。弹层被裁切或跟着卡片滚，先检查祖先有没有 transform。
  • 无限旋转用 animation 配 linear 与 infinite。在 @keyframes 里写 transform，会覆盖元素自身同一条 transform，入场前需要的缩放要写进关键帧的 from。
  • 关键帧里只写 rotate 时，元素原来的 scale 在动画期间会丢失。两边的关键帧带上同一份缩放，旋转才不会把尺寸打回 1。
