CSS边距

  • CSS
本文总阅读量次

既不回头，何必不忘。 既然无缘，何须誓言。 今日种种，似水无痕。 明夕何夕，君已陌路。

边距在盒上的位置

标准盒从内到外是内容、内边距、边框、外边距。box-sizing: content-box（初始值）时，width 只量内容。border-box 时，width 含内容和左右的 padding、border。

  • padding（内边距）在边框与内容之间，背景会铺到这块区域。点击也算在这里。
  • margin（外边距）在边框外侧，用来推开相邻盒子，本身透明，点不中，也挡不住后面的背景。
  • padding 不能为负。margin 可以为负，用来回拉或重叠。

简写

一到四个值都按上、右、下、左顺时针记；缺的边抄对边：

写法 含义
10px 四边都是 10px
10px 20px 上下 10px，左右 20px
10px 20px 30px 上 10、左右 20、下 30
10px 20px 30px 40px 上、右、下、左

逻辑属性 margin-inline、padding-block 跟书写方向走。从右到左排版时不用把左右对调。

margin: auto

块级盒设了确定的 width（或 max-width）且没占满一行时，左右 auto 会平分剩余空间，于是水平居中。宽度仍是 auto 的普通块已经占满包含块，左右 auto 算出 0，看不出居中。上下 auto 对普通文档流里的块级盒也算出 0，不能靠 margin: auto 做垂直居中。

绝对定位要居中，四边 inset: 0 配合 margin: auto，并给出确定的宽高。弹性、网格子项上的 auto 外边距会吃掉该方向的剩余空间，常用来把一项推到行尾。

百分比

margin 与 padding 的百分比一律相对包含块的宽度，包括 margin-top 和 padding-bottom。父级变窄时，上下留白一起变小。不要按包含块高度去算垂直内边距。

行内非替换元素只有水平 margin 参与排版，垂直 margin 不增加行盒高度。替换元素（如图片）的垂直外边距会参与行盒。

垂直外边距折叠

同一块格式化上下文里，相邻的、都在文档流中的块级盒，垂直外边距会合成一条。水平外边距不折叠。结果按这三条规则算：

  1. 都是正数：取较大值。
  2. 都是负数：取更负的那个。
  3. 有正有负：最大正值加上最负值。

两个 20px 叠在一起仍是 20px。想要 40px 的间距，把留白放到其中一侧，或改用 padding、gap。

会贴在一起的情况有四种：相邻兄弟的上下外边距；父级顶部和第一个孩子的顶部；父级底部和最后一个孩子的底部；自身高度是 auto，又没有边框、内边距和行内内容时，自己的上下外边距合成一条。空盒子看起来会比两个外边距之和更矮。

父子折叠的条件是：父级没有上边框、上内边距，也没有隔开的内容，而且父级没有自己形成新的块格式化上下文。这时子级的 margin-top 会穿透父级，父级一起被推下去。

折叠会消失的情况：

  • 中间隔了 padding、border，或清除浮动留下的空隙。
  • 父元素建立了新的 BFC（overflow 不是 visible，或 display: flow-root），父子之间不再穿透。
  • 浮动和绝对定位脱离文档流，不和在流里的盒子折叠。
  • 弹性、网格子项之间不折叠。子项内部若还是普通块，那些块自己仍会折叠。

相邻兄弟即使其中一个自己是 BFC，只要还紧挨在同一个父级里，垂直外边距仍然折叠。不能靠「给其中一个加 overflow: hidden」来把两个兄弟的外边距加总。

常见坑

  • width: 100% 再加左右 padding，在默认 content-box 下会比父级更宽并溢出。改 box-sizing: border-box，或不要再给已经占满一行的盒子加左右外边距。
  • 标题、段落自带浏览器默认垂直外边距，紧贴导航或卡片边缘时先把这一侧 margin 归零。
  • 负外边距把元素拉出父级后，父级若 overflow: auto 会出现滚动条。点击区域仍以边框盒为准，负外边距本身不可点。
  • 折叠取的是较大值，不是相加。排卡片间距时优先用父级的 gap 或单侧 margin，避免上下两个外边距互相吃掉。
