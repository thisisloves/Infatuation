CSS 语法

  1. 每个 CSS 样式由两部分组成，即选择符和声明，声明又分为属性和属性值
  2. 属性必须放在花括号中，属性与属性值用冒号连接。
  3. 每条声明用分号结束。
  4. 当一个属性有多个属性值的时候，属性值与属性值用空格分隔。
  5. 在书写样式过程中，空格、换行等操作不影响属性显示。

基础选择器

  1. 标签选择器
  1. id 选择器
  • 选中带有指定 id 属性的元素；同一文档中 id 应唯一。
  1. class 选择器
  • 可复用；同一元素可有多个类名（空格分隔）。

复合选择器

  • 复合选择器是建立在基础选择器上，对基本选择器进行组合形成的。
  1. 后代选择器
  1. 子元素选择器
  1. 并集选择器
  1. 伪类选择器

兄弟选择器（补充）

  1. 相邻兄弟 A + B：与 A 同父且紧挨在 A 后面的那一个 B。
  2. 一般兄弟 A ~ B：与 A 同父、且在文档顺序中位于 A 之后的所有 B（不必相邻）。

特异性（优先级）速记

  • 大致：内联 style > #id > .class / [attr] / :伪类 > **标签 / ::伪元素**；* 与结合符不计入计数。
  • 同优先级时，后出现的规则覆盖先出现的；!important 可打破常规比较但应少用。
