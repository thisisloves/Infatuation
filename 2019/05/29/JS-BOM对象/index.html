JS BOM 对象

本文总阅读量次

袭微雨，荡尽心中尘埃，缕清风，吹开陌上花红，如此，心在此岸已无岸，人在天涯已无涯。

概念

BOM（Browser Object Model）是浏览器提供的窗口级 API，没有一份像 DOM 那样统一的旧标准，现在大多落在 HTML 规范里。核心是 window，表示当前浏览上下文。document、location、history、navigator、screen 都从这里访问。

经典脚本里，全局 var 和函数声明会变成 window 的属性。ES Module 有自己的作用域，顶层绑定不会挂到 window。判断全局对象用 globalThis。

内置构造函数（Object、Array、Date、RegExp）由语言提供；window、document 由宿主提供。Math、JSON 是内置对象，不是必须 new 的构造函数。

正确示例

window 上常用的是方法；scrollX、scrollY 是属性，不要写进方法表还带括号。

confirm 确定返回 true，取消返回 false。prompt 取消返回 null。

方法名是 history，不是 histroy。history.length 是会话历史条数。history.go(0) 会重新加载当前页。location.reload() 的强制跳过缓存参数已废弃，缓存用响应头控制。

appCodeName 几乎总是 "Mozilla"，appName、appVersion 也是历史字段。浏览器识别不要解析 UA，用特性检测。第二个「appVersion 返回 user-agent」是把 navigator.userAgent 抄错了行。

常见坑

  • window.close() 只能关脚本自己打开的窗口，不能随便关掉用户的标签。
  • open 不带 noopener 时，新页可以通过 window.opener 操作来源页。
  • 模块里 var a = 1 之后 window.a 仍是 undefined。依赖全局泄漏的旧脚本搬进模块会失效。
  • location.href = url 会导航走，当前调用栈后面的语句不一定还有意义。
  • screen.width 是整块屏幕，不是浏览器窗口。窗口视口用 window.innerWidth，布局视口还要考虑滚动条。
  • 全角括号 function（） 不是合法的函数表达式，监听器根本注册不上。

导航和视口

单页应用改地址优先 history.pushState，它不发请求，也不会立刻触发 popstate。用户点后退时才有 popstate，页面要自己根据 location.pathname 渲染。location.hash 适合页内锚点，变化时听 hashchange。

窗口尺寸看 innerWidth / innerHeight（含滚动条与否由浏览器决定，布局计算更稳的是 document.documentElement.clientWidth）。screen.width 是显示器。移动浏览器的地址栏伸缩会改变 innerHeight，不要把它当成设备的固定高度。

setTimeout 和 setInterval 的最小间隔在后台标签会被拉长，倒计时用 Date.now() 校正，而不是数回调次数。open 返回的窗口引用在跨源后不能读它的 document，只能 postMessage 或关掉自己打开的窗口。

模块里的 window

ES Module 的顶层 this 是 undefined，顶层 const 也不会变成 window 的属性。页面上要给内联事件或老插件留全局函数时，显式赋值 globalThis.app = { start() {} }，不要再靠省略 var 泄漏。

history.back() 没有可退记录时什么也不做，不会抛错。history.go(-1) 同理。length 包含当前页，所以长度为 1 时已经没有后退项。location.reload() 重新请求当前文档，是否命中 HTTP 缓存由响应头决定，老的 reload(true) 参数不要再写。

navigator.userAgent 可以记日志。用它判断「是不是某款浏览器」会在兼容模式和 WebView 里误判。能力探测写成 'serviceWorker' in navigator 这种形式。window.open 可能被拦截而返回 null，调用前要判断。

pagehide 比 unload 更适合做离开页面前的收尾，而且不阻止往返缓存。resize 触发很密，回调里只记尺寸，重的计算交给节流或 requestAnimationFrame。

sendBeacon 适合在页面离开时发一小段统计。不要在 beforeunload 里同步 fetch，浏览器可能直接丢掉这个请求。

小结

BOM 围绕 window。历史和地址用 history、location，浏览器信息用 navigator.userAgent 只作日志，不作分支。模块顶层不再等于 window，定时器成对清除，reload(true) 不要再用。
