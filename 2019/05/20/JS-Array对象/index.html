概念

数组是有序的对象，用数字下标存一组值，length 比最大下标大 1。创建优先用字面量。new Array(3) 得到长度 3 的空槽数组，不是 [3]；Array.of(3) 才是 [3]。

方法分三类：

  • 会改原数组：push pop shift unshift splice sort reverse fill copyWithin
  • 返回新数组：map filter slice concat flat flatMap，以及 ES2023 的 toSorted toReversed toSpliced with
  • 归约或查找：reduce forEach find findLast some every includes indexOf

Array.isArray、Array.from、Array.of 是静态方法。下面这些回调测的是任意元素，不是「数值元素」：

方法 作用
forEach 遍历，返回值永远是 undefined，不能 break
map 映射成等长新数组
filter 留下回调为真的项
find / findIndex 第一个满足条件的值 / 下标
some / every 是否有一项 / 是否全部满足
reduce 从左折成一个结果

sort 默认把元素转成字符串再按 UTF-16 比较，不是数值大小。

常见坑

  • forEach / map 会跳过空槽，但不会跳过值为 undefined 的显式元素。new Array(3).map(x => 1) 得到的仍是空槽数组。
  • map 的返回值必须 return。漏写时新数组全是 undefined。
  • [10, 2].sort() 得到 [10, 2]，因为 '10' < '2'。数字排序要传比较函数。
  • indexOf 用 ===，找不到 NaN。判断有没有 NaN 用 includes。
  • 稀疏数组的 length 可以远大于实际元素数，forEach 不会补洞，for 循环会访问到空槽。
  • 在 forEach 里 push 进正在遍历的数组，新增项不会被访问；删元素则容易跳项。需要中途停止就用 for / for...of。
  • reduce 不传初始值时，空数组会抛 TypeError。求和、拼对象时把初始值写上。

稀疏数组和排序

Array(3) 没有下标 0、1、2 这三个属性，forEach 和 map 都会跳过，for...of 则会给出三次 undefined。要三个 0，写 Array.from({ length: 3 }, () => 0)。

sort 的比较函数应返回负数、0 或正数。返回布尔值会被当成 0 或 1，顺序不稳定。数字按 a - b。对象按字段：(a, b) => a.age - b.age。原数组还要用就先 slice() 或 toSorted。

includes 能找到 NaN，indexOf 不能。删除元素用 splice 或 filter 出新数组，给长度为 n 的数组赋 arr[n] = x 会在末尾追加并可能留下空洞。push 返回的是新长度，不是被推进去的元素，链式调用时不要用它的返回值当数组。

拷贝和空槽

slice、concat、扩展运算符、toSorted 得到新数组，嵌套对象仍共享。要断开嵌套，用 structuredClone。sort 和 reverse 改的是原数组，返回值也是它自己，容易把「已排序的副本」和原数据写成同一个引用。

forEach 跳过空槽，展开和 for...of 会把空槽读成 undefined。判断「这项有没有值」不能只看回调有没有执行。Array.isArray(document.querySelectorAll('a')) 为假，那是 NodeList，需要时再 Array.from。

小结

用字面量或 Array.from / Array.of 创建数组。sort 要传比较器，map 记得返回，forEach 没有新数组。不想改原数组时用 toSorted、slice，而不是 sort、splice。
