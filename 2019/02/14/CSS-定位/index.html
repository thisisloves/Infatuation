position 的五个值

position 决定元素相对谁偏移，以及是否还在文档流里占位。top / right / bottom / left（或逻辑属性 inset）只在非 static 时生效。

值 是否占位 相对谁偏移
static 占 不偏移
relative 占，偏移后原位留空 自己原来的位置
absolute 不占 包含块
fixed 不占 默认视口；某类祖先会变成包含块
sticky 占，越过阈值后粘住 最近的滚动祖先

  1. **static**（初始值）。按正常流排。块级盒竖排，行内盒在行盒里折行。偏移属性和 z-index 都忽略。

  2. **relative**。先按正常流占位，再相对自己原来的位置偏移。后面的兄弟不会挤上来。偏移后可能盖住别的盒。

  3. **absolute**。离开正常流，原占位关闭。相对包含块放置。行内级的 display 会被块化：inline / inline-block 按块级盒算，inline-flex 变成 flex，inline-grid 变成 grid。

  4. **fixed**。同样脱离正常流。默认包含块是视口，滚动页面时它停在屏幕上。祖先若有不为 none 的 transform、filter、perspective、backdrop-filter，或 will-change 指向这些属性，或 contain: paint，包含块就改成该祖先，fixed 会跟着那个祖先走。

  5. **sticky**。未越过阈值时像 relative，占位仍在。越过阈值后粘在滚动容器的边缘，像限制在父级范围内的 fixed。必须写出 top / right / bottom / left 之一，否则没有粘滞距离，表现与 relative 相同。参照的是最近的滚动祖先。祖先 overflow 不是 visible 时，粘滞经常失效。父级要比粘滞元素更高，否则没有可滑动的路程。

绝对定位

包含块是最近的、position 不为 static 的祖先。没有这样的祖先时，用初始包含块（连续媒体上就是视口）。祖先即使是 static，只要 transform、filter、perspective、backdrop-filter 不为 none，也会成为绝对定位后代的包含块。

left 与 right 同时给出、宽度是 auto 时，绝对定位盒的宽度被拉到填满包含块在这两个偏移之间的空间。只写 left 时，宽度由内容或 width 决定。相对定位不是这样：书写方向从左到右时，left 和 right 都写了，以 left 为准，right 被忽略，盒子不会被拉宽。

百分比的 top / height 相对包含块的高度。包含块高度若由内容撑开，百分比高度会落成 auto。left / width 的百分比相对包含块的宽度。

相对定位

left: 30px 是向右移，top: 20px 是向下移。腾出的原位置留空，旁边的文字不会流进来。给父级加 position: relative 且不写偏移，是为了当绝对定位子元素的包含块，父级自己仍占原来的位置。

层叠

z-index 只对定位元素，以及弹性、网格子项生效。static 上写 z-index 无效，除非它是弹性或网格子项。

auto 在比较时按 0 参与，但相对、绝对定位元素的 z-index: auto 不新建层叠上下文。写成 0 会新建。所以 auto 和 0 不是同一个值。

下面任一条件都会新建层叠上下文，不需要同时满足：

  • 定位元素的 z-index 不是 auto（fixed、sticky 即使是 auto 也会新建）
  • 弹性或网格子项的 z-index 不是 auto
  • opacity 小于 1
  • transform、filter、perspective、backdrop-filter 不为 none

上下文内部的层级再高，也整体夹在父上下文的两个邻居之间，不会穿出父级。同级里后来的元素，在层级相同且都未建立新上下文时，通常盖住先来的元素。

常见坑

  • fixed 导航在带 transform 的轮播或动画父级里会突然跟着父级走。把定位元素挂到不会变换的祖先上。
  • 粘滞表头和滚动容器之间，不要夹着 overflow 不是 visible 的祖先，并且滚动容器要比表头更高。top 写成希望停住的距离；上面已有固定顶栏时，写成顶栏高度。
  • 绝对定位元素不撑开父级高度。父级只剩绝对定位子元素时高度会塌成 0，背景和点击范围一起消失。
  • 想压住一个定位层，先让自己成为定位元素或弹性、网格子项，再写 z-index。只把数字写在 static 上不会生效。
