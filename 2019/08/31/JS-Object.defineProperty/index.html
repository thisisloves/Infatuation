概念

Object.defineProperty(obj, key, descriptor) 在对象上新增或改写一个属性的描述符。方法名是 defineProperty，没有 definedProperty。

描述符分两类，不能混用。数据描述符含 value / writable，访问器描述符含 get / set。两类都能带 enumerable 和 configurable。用这个 API 定义时，省略的布尔标志默认是 false，不是 undefined：

字段 含义 默认
configurable 能否删除、能否再改描述符（writable: true 改成 false 除外仍受限制） false
enumerable 是否出现在 for...in 和 Object.keys false
value 数据属性的值 undefined
writable 能否用赋值改值 false
get / set 读取和写入时调用的函数 未提供则没有该方向

普通赋值 obj.a = 1 得到的是可写、可枚举、可配置的数据属性。defineProperty 不写标志时，属性会变成「不可写、不可枚举、不可配置」。

内部槽（如 [[Prototype]]）不是普通属性，要用 Object.getPrototypeOf 这类方法访问。

Object.defineProperties(obj, map) 一次定义多个。查看用 Object.getOwnPropertyDescriptor。

和 Proxy 的差别：defineProperty 改的是原对象上已点名的属性，拦不到新增键，也拦不到数组的 length 变化。Proxy 包出新对象，原对象不动，有 get、set、has、deleteProperty、ownKeys、apply 等陷阱，适合整体监听。Vue 2 用 defineProperty 遍历已有键，所以后加的属性要 Vue.set；Vue 3 改用 Proxy。

常见坑

  • 数据描述符和访问器描述符写在同一个对象里会抛 TypeError。
  • writable: false 时，非严格模式赋值静默失败，严格模式抛错。
  • configurable: false 之后不能再 delete，也不能把 enumerable 改回去。
  • 只定义 get 不定义 set，赋值在严格模式下抛错。
  • enumerable: false 的属性 obj.a 仍能读到，只是 Object.keys 和 JSON.stringify 会跳过它。
  • 在数组下标上 defineProperty 不会自动维护 length 的全部监听语义，不要用它实现「监听整个数组」。

默认值和不变对象

字面量赋值得到的描述符是可写、可枚举、可配置。一旦用 defineProperty 且 configurable: false，以后不能再把普通属性改成访问器，也不能 delete。想做只读配置，可以 writable: false, configurable: false，并在严格模式下赋值以便及时抛错。

批量定义：

Object.freeze 是浅冻结：自身数据属性不可写、不可配置，也不允许新增和删除，但嵌套对象仍能改。要整棵树不变，得递归冻结，函数和循环引用要单独处理。Object.seal 只禁止增删，已有属性仍可写。

Vue 2 无法发现「新增一个键」，是因为 defineProperty 必须事先知道键名。给数组下标赋值、修改 length，同样不在它自动拦截的范围内。新代码监听整个对象用 Proxy，get 里返回的嵌套对象也要继续包一层，否则只有第一层是代理。

小结

defineProperty 精确控制单个已有属性，省略的 writable / enumerable / configurable 都是 false。getter 不要读回同名属性。要监听任意新增字段和数组，用 Proxy。
