JS Math 对象

概念

Math 是内置对象，不是构造函数，new Math() 会抛错。常量和方法都直接挂在 Math 上，例如 Math.PI、Math.sqrt。

方法 作用
abs(x) 绝对值
sqrt(x) / cbrt(x) / pow(x, y) 平方根、立方根、乘方
exp(x) e 的 x 次方，不是「Ex」
log(x) / log2 / log10 自然对数及指定底
ceil / floor / trunc / round 向 +∞、向 -∞、截断小数、四舍五入
max(...) / min(...) 最大、最小。没有参数时 max 为 -Infinity，min 为 Infinity
random() 半开区间 [0, 1) 的伪随机数，取不到 1
sin cos atan 弧度制。atan 的范围是 [-π/2, π/2]
atan2(y, x) 从 x 轴到点 (x, y) 的角，范围是 [-π, π]，不是 ±π/2

round 对正数是常见的四舍五入，.5 朝 +∞：Math.round(-1.5) 是 -1，不是 -2。

数字字面量没有「八进制前导 0」这种现行语法。012 在严格模式和模块里是语法错误。八进制写 0o12，十六进制写 0x，二进制写 0b。

常见坑

  • IEEE 754 双精度不能精确表示所有十进制小数。0.1 + 0.2 === 0.3 为假，7 * 0.8 可能是 5.6000000000000005。金额用整数分，或在展示前按小数位 toFixed（它返回字符串）。
  • Math.min(3, 4, 0, 12) 的最小值是 0。注释若写成 3，是把列表里的 0 漏看了。
  • Math.max() 不传数组。Math.max([1, 2]) 得到 NaN。展开：Math.max(...arr)。空数组展开后等于没传参，max 变成 -Infinity。
  • atan2 的参数顺序是 (y, x)，写反会得到另一个象限。
  • 三角函数的参数是弧度。角度要先乘 Math.PI / 180。

取整和随机整数

floor 向 -∞，ceil 向 +∞，trunc 只去掉小数。负数时 floor(-1.2) 是 -2，trunc(-1.2) 是 -1。金额用「分」做整数运算时，不要用 round 代替银行家舍入，先定规则再选方法。

max 要包含在结果里，乘数就是 max - min + 1。random() 取不到 1，所以不会得到 max + 1。Math.random 不能用于口令、抽奖兑奖这类需要密码学随机的场景，那种用 crypto.getRandomValues。

hypot(x, y) 计算距离，避免自己先平方再相加溢出。imul 做 32 位整数乘法。比较两个浮点数是否「足够接近」用一个误差，而不是 ===：

比较函数和浮点

max、min 会把对象转成数字。空对象变成 NaN，于是整个结果变成 NaN。数组要展开，不能包一层：

大数组展开可能超出参数个数限制，此时用循环或 reduce。round 对负数的一半朝 +∞ 走，展示金额前先约定位数，再用整数运算，最后格式化成字符串。toFixed 返回的是字符串，和数字继续 + 会变成拼接。

角度和弧度不要混在一个公式里。sin 的参数是弧度，90 度要写成 Math.PI / 2。atan2(y, x) 在 x 为负时能区分第二、第三象限，atan(y / x) 做不到，除法还会在 x === 0 时出问题。

小结

Math 不能 new。random 是 [0, 1)，atan2 的范围到 ±π，min 会看列表里的每一个数。进制用 0o / 0x，小数运算不要直接当十进制精确值。
