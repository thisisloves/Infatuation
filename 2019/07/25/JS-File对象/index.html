JS File 对象

2019-07-25
  • JS
本文总阅读量次

你凭栏而待，眉目自成诗三百，鬓如春风裁。

概念

File 继承 Blob，表示用户选择或脚本构造的文件：二进制内容加上 name、lastModified（毫秒时间戳）。浏览器出于安全不会把真实磁盘路径交给页面，name 只是文件名；目录上传时相对路径在 webkitRelativePath。

来源主要是 <input type="file"> 的 files，以及拖放事件的 dataTransfer.files。两者都是 FileList，类数组但不是数组，没有 map，用 Array.from 或下标遍历。脚本不能给 file input 指定本机路径。

bits 是字符串、ArrayBuffer、Blob 等组成的序列。options.type 是 MIME，options.lastModified 默认 Date.now()。

FileReader 异步读取 Blob / File。readyState：0 空闲，1 读取中，2 完成。结果在 load 之后从 result 取。readAsBinaryString 已废弃。

方法 result
readAsText(blob, encoding?) 字符串，默认 UTF-8
readAsDataURL(blob) data: URL
readAsArrayBuffer(blob) ArrayBuffer
abort() 中止，readyState 变为 2

正确示例

预览图片优先 URL.createObjectURL(file)，它生成 blob: URL；readAsDataURL 会把整文件变成长字符串。img 加载完成后 URL.revokeObjectURL。

常见坑

  • 类型名是 FileReader，不是 FileRead 或 leReader。
  • lastModifiedDate 已废弃，而且是 Date。新代码只读数字 lastModified。用本地时区的 new Date(2018, 1, 1) 去对一个写死的 UTC 时间戳，会随时区变化。
  • 同一个 FileReader 在 readyState === 1 时再次 readAs* 会抛 InvalidStateError。一个读操作一个 reader，或等 loadend。
  • files 在部分浏览器里是只读快照。再次选择同一文件，change 可能不触发，需要把 input.value = '' 清掉。
  • accept="image/*" 只是提示文件选择器，不能代替对 file.type 或文件头的校验。
  • FileReader 走事件回调，不要写成同步返回值。包一层 Promise，或用 blob.text() / blob.arrayBuffer()（Blob 上的新方法，更短）。

读内容和上传

Blob 已经提供 text()、arrayBuffer()、stream()。文本文件不必再构造 FileReader，除非要听 progress。进度和中止仍是 FileReader 合适的场合：onprogress 里用 event.loaded 和 file.size，abort() 停止读取。

上传用 FormData，字段名要和接口一致。File 作为 Blob 传入时，文件名用它自己的 name。不要把整个 FileList 放进一个字段；逐个 append。同一 input 想重复选择同一文件，在 change 处理完后把 input.value 设为 ''。

构造 File 不会产生磁盘文件，只是内存中的文件形对象，刷新即消失。lastModified 是毫秒数字，展示时再 new Date(file.lastModified)。不要把本地时区的日期反推成某一个写死的 UTC 时间戳去对测试。

FileList 和拖放

FileList 没有 map。拖放时还要取消浏览器默认的打开文件行为，否则页面会导航走：

name 不含目录。用户通过带 webkitdirectory 的输入框选文件夹时，相对路径在 webkitRelativePath。脚本不能把 input.value 设成 C:\secret.txt 来读取本机任意文件，赋值只会失败或被忽略。

读取用 file.text() 或 FileReader。一个 FileReader 同时只能有一个未完成的 readAs*。进度事件里的 result 在完成前可能不完整，处理文本要等 load。

小结

File 是带名字和时间戳的 Blob，路径不可见。用 FileList 取用户选择的文件，用 FileReader 或 blob.text() 读内容。废弃的是 readAsBinaryString 和 lastModifiedDate。
