CSS单位

2019-01-17
  • CSS
本文总阅读量次

泉涸，鱼相与处于陆，相呴以湿，相濡以沫，不若相忘于江湖。

长度单位分两类

  • 相对长度跟着字号、视口、容器或包含块变，适合随界面缩放。
  • 绝对长度锚定物理量或参考像素。屏幕上最常用的是 px；pt、cm 多见于打印。

em 与 rem

  • em 用在 font-size 上时，相对父元素的字号。用在 padding、width、letter-spacing 等其它属性上时，相对当前元素自己已算出的 font-size。
  • 父级 16px、子级 font-size: 2em 得到 32px；子级再写 padding: 1em 则是 32px。嵌套多层 font-size: 1.2em 会连乘，字号越嵌越大。
  • rem 相对根元素 html 的字号。改一处根字号，整站用 rem 的尺寸一起变，没有 em 的嵌套连乘。
  • 根元素自己的 font-size 若写成 rem，参照的是浏览器初始字号（常见 16px），避免自引用。html { font-size: 62.5%; } 会让默认环境下 1rem = 10px，但用户若改了浏览器默认字号，10px 这个假设就不成立。

百分比

  • 百分比的参照因属性而异。width 相对包含块的宽度；height 相对包含块的高度。父级高度是 auto 时，子级 height: 100% 往往算成 auto，看起来像「百分比高度失效」。
  • margin、padding 的百分比，上下左右都相对包含块的宽度。padding-top: 10% 随宽度变，常用来做固定宽高比，也常让纵向间距在窄屏上变小。
  • transform: translate(50%, 50%) 的百分比相对元素自身边框盒，和 top/left 的百分比参照不同。

视口单位

  • 1vw 是视口宽度的 1%，1vh 是视口高度的 1%。vmin / vmax 取宽高里较小或较大的一边。
  • 经典坑：部分浏览器里 100vw 含滚动条宽度，和 100% 不一致，页面会多出横向滚动。布局宽度优先用 % 或网格的 fr。
  • 移动端地址栏伸缩时，vh 可能把内容顶到屏幕外。svh（小视口）、lvh（大视口）、dvh（动态视口）分别对应工具栏展开、收起和随滚动变化的高度。

其它相对单位

  • ch 约等于当前字体「0」的宽度，适合限制验证码、等宽输入的字符数。ex 约等于「x」的高度。
  • lh 相对元素的 line-height。容器查询单位 cqw / cqh / cqi 相对查询容器，使用前给容器设 container-type。

px、pt 与设备像素

  • CSS 的 px 是参考像素：规范里 1px = 1/96in。它是逻辑像素。设备像素比（DPR）为 2 时，1 个 CSS 像素大约覆盖 2×2 个设备像素。边框要写 1px，写 0.5px 在低 DPR 上可能被抹成 0 或发虚。
  • pt 是印刷点，1pt = 1/72in，约等于 1.333px。屏幕排版用 px/rem，打印样式表再用 pt。
  • 同属绝对长度的还有 in、cm、mm、pc（1pc = 12pt）。它们在屏幕上会按参考像素换算，量出来的尺子刻度未必等于物理尺子。

把单位拼在一起

  • calc() 里 + / - 两侧要留空格，* / / 可以不留。不能把单位不同且无法换算的量直接相加。
  • 经验：字号用 rem，发丝边框用 px，栏宽用 % / fr / min()，随视口流动的标题再用 clamp()。

角度、时间与分辨率

  • 旋转用 deg（360 为一圈）、turn（1 为一圈）、rad。transform: rotate(0.25turn) 与 90deg 相同。
  • 过渡和动画的时间用 s 或 ms。0 可以不写单位，其它数值省略单位会整条声明作废。
  • dppx 表示每 CSS 像素的设备像素，和 resolution 媒体查询一起用：@media (min-resolution: 2dppx) 圈出 DPR 至少为 2 的屏。dpi 是每英寸点数，96dpi 等于 1dppx。

单位怎么配

场景 更合适的单位
正文字号、组件间距 rem，跟根字号一起缩放
图标里跟字号走的内边距 em，嵌套时注意连乘
边框、发丝阴影、位图像素对齐 px
栏宽、图片最大宽度 %、fr、min()
全屏封面的高度 dvh 或 svh，少用单独的 100vh
打印样式 pt、mm
  • background-size 用 CSS 像素写显示尺寸，图片文件本身用 2 倍像素，避免高分屏发糊，也避免把布局单位写成设备像素。
  • line-height 写成无单位的数字（如 1.5）时，按元素自己的字号相乘，而且这个倍数会继承下去。写成 1.5em 再继承，子元素会按父级已经乘过的行高再乘一次。
