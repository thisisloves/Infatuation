CSS 是什么

  • CSS（Cascading Style Sheets，层叠样式表）描述文档如何呈现：颜色、字体、盒、布局与动效。结构留给 HTML，行为留给脚本。
  • 层叠是多条规则打到同一元素时的裁决。比较顺序是：来源与重要性、特异性、源码先后。优先级相同时，后出现的声明覆盖先出现的声明。

  • @import 必须写在样式表除 @charset 外的最前面，会额外发起请求并推迟后续规则解析。日常用 <link> 即可。

一条规则的组成

  • 选择器圈定元素，如 p、.btn、#nav。
  • 声明块写在 {} 里。每条声明是 属性: 值;，用英文冒号分隔，用分号结束。
  • 最后一条分号可省略，补一条声明时最容易漏掉，习惯上都写上。

层叠怎么比

  1. 来源与重要性：浏览器默认样式 < 作者普通声明 < 作者 !important < 用户 !important（过渡样式另计）。!important 把这条声明提到同来源的普通声明之前，调试时会盖住后面所有正常规则。
  2. 特异性：大致按 (行内, ID, 类/属性/伪类, 元素/伪元素) 从左到右比，左边大则整组更大。0,1,0,0 高于 0,0,9,9。
  3. 顺序：前两项都相同，写在后面的生效。
  • 行内样式相当于带了一份 ID 级之上的权重。要盖过它，需要另一条行内样式，或作者样式里的 !important。
  • 通用选择器 *、组合符、:where() 不增加特异性；:is() / :not() 取参数里最高的那一项。

继承

  • color、font、line-height、visibility 等会沿树向下继承。margin、padding、border、background、width 不继承。
  • inherit 强制继承父元素的计算值；initial 回到该属性的初始值；unset 对可继承属性等同 inherit，其余等同 initial；revert 退回来源上的上一层（常是浏览器默认）。

简写的副作用

  • 简写会把没写到的子属性恢复成初始值。background: red 会清掉先前设置的 background-image；font: 16px/1.5 sans-serif 也会重置 font-weight、font-style。
  • 要改其中一个长属性，写长属性名，避免整组被重置。

注释

  • 注释用 /* */，可以跨行。浏览器丢弃注释，注释不能嵌套：第一个 */ 就会结束。

常见坑

  • 选择器没命中时，先看是否写错类名、是否被更特异或 !important 压住，再用开发者工具看「被划掉的声明」来自哪一条。
  • margin: 0 auto 只在该方向的 margin 为 auto、且元素有确定宽度时水平居中块级盒。浮动、行内非替换元素不吃这一套。
  • 自定义属性 --brand 区分大小写，继承下去之后用 var(--brand, #333) 取，第二个参数是未定义时的后备。var() 在解析期无效时，该声明整条被忽略。
