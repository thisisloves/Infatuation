path 可以是字符串，也可以是对象。带参数时优先用对象，避免自己拼接编码。

路径参数 params

先在路由表声明动态段，刷新和分享链接都能还原：

地址会变成 /about/1。这里的参数在刷新后还在。

两条必须记住的规则：

  1. 同时写了 path 和 params 时，params 会被忽略。要么只写 name，要么把参数拼进 path 字符串。
  2. 没有写进 path 的 params 不会出现在地址栏里。Vue Router 4 不再支持这种「隐式 params」，刷新必然丢失。Vue Router 3 虽然能在当次跳转的内存里拿到，刷新同样丢失。

所以「params 刷新一定丢失」只对没写进路径的参数成立。:id 这种路径参数刷新后仍在 $route.params 里。

params 的值都会变成字符串。对象要自己 JSON.stringify，接收后再解析，并考虑长度和敏感信息。

查询参数 query

地址是 /about?tab=info&page=1。刷新不会丢。query 可以和 path 一起用，也可以和 name 一起用。

query 的值同样按字符串处理。page: 1 取出来是 "1"，计算前用 Number。布尔值会变成 "true" / "false"。嵌套对象会被序列化成带括号的键，不稳定，复杂结构不要直接塞进 query。

接收方式

同一组件被不同 params 复用时（从 /about/1 到 /about/2），不会重新 created。在 beforeRouteUpdate 或 watch: { '$route.params.id'() {} } 里重新请求。

也可以让路由把 params 映射成 props，组件就只依赖 props，方便测试：

props: true 只映射 params，不映射 query。

解码与可选参数

路径参数默认解码。需要保留 / 时使用自定义正则，Vue Router 4 的可重复参数写成 /:chapters+。可选参数在 Vue Router 4 是 /:id?。这些写法以所用主版本的文档为准，不要把 Vue Router 3 的 * 和 Vue Router 4 的 (.*)* 混在一张表里。

不要用 params 传递的东西

密码、令牌不要出现在路径或 query 里，它们会进历史记录、访问日志和 Referer。跨页的大块状态放状态库或会话存储，地址栏只留 id。
