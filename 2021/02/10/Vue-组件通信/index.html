Vue 组件通信

2021-02-10
  • Vue
本文总阅读量次

时光清浅处，一步一安然。

组件实例互不可见

每个组件实例的数据是隔离的。父组件模板里写了子组件，不表示子组件能读父组件的 data。常见方向是：父组件用 props 把数据交给子组件，子组件用事件把变化告诉父组件。

props 向下

父组件绑定，子组件声明类型。不要在子组件里给 props 重新赋值，改了既违反单向数据流，对象和数组还是引用，会悄悄改到父级。

对象和数组的 default 必须是工厂函数，否则所有实例共用一份。

子组件需要本地草稿时，用 props 初始化 data，或使用计算属性的 getter/setter。父组件之后再改 props，不会自动覆盖子组件已经复制出去的 data，要自己 watch。

事件向上

Vue 2：this.$emit('save', payload)。父组件 @save="onSave"。

Vue 3 建议在 emits: ['save'] 里声明。未声明的事件会挂到组件根元素上（原生监听），声明之后才确定是组件事件。

$listeners 只存在于 Vue 2，里面是父组件传下来的 v-on。Vue 3 把它并进了 $attrs，监听以 onSave 这种名字出现。配合 v-bind="$attrs" 透传时，Vue 3 会把 class、style、属性和监听一起传下去。

v-model 与 .sync

Vue 2 组件 v-model 是 value + input。.sync 是 update:propName。

Vue 3 组件 v-model 是 modelValue + update:modelValue，多个字段用 v-model:title。没有 .sync。

父子引用

$parent 能拿到父实例，耦合强，只适合极少数库内部。$children 在 Vue 2 里顺序不稳定，Vue 3 已删除。要命令式调用子组件，用 ref。Vue 3 的 <script setup> 还要 defineExpose。

provide / inject

适合多层祖先把主题、当前用户交给子孙，避免逐层转发。

Vue 2 里 provide 的值默认不是响应式的。要让子孙跟着变，提供一个对象并修改它的属性，或提供函数。Vue 3 可以直接 provide 一个 ref 或 computed，子孙 inject 之后仍然是响应式的。

provide / inject 是隐式依赖，公共组件优先用 props，跨多层的配置再用注入。

事件总线

Vue 2 可以利用实例上的 $on / $off / $emit：

组件销毁时要 $off，否则会重复执行。

Vue 3 去掉了实例的 $on、$off、$once，new Vue() 不能再当总线。需要发布订阅时用独立的小型事件库（如 mitt），或改用状态库。

状态库

兄弟组件、跨页面共享的数据放 Vuex（Vue 3 对应 Vuex 4）或 Pinia。不要为了两个相邻组件专门上 Vuex，props 和事件足够。
