Vuex Mutation

2021-04-26
  • Vuex
本文总阅读量次

清欢不渡，白茶不予。

修改 state 的同步入口

开启严格模式时，只有 mutation 回调里的赋值是合法的。每个 mutation 有一个类型字符串和一个处理函数，处理函数拿到的第一个参数是当前模块的 state。

处理函数必须是同步的。里面写 setTimeout、请求，开发工具里的时间旅行会对不上，严格模式下异步赋值也会落到回调之外。异步放 Action。

载荷

第二参数是 payload。多个字段时传一个对象：

对象风格把 type 和字段放在同一个对象里，处理函数收到的 payload 就是这个对象，因此仍然读 payload.name：

两种风格选一种用到底。对象风格容易和「第二个参数才是载荷」的习惯混淆：类型和数据在同一个对象上。

常量类型

项目变大后，类型可集中成常量，避免字符串打错：

小项目直接写字符串即可。Vuex 不要求必须用常量。

mapMutations

mapMutations 映射到 methods，不是 computed。

组件里调用 this.setName(payload)，等价于 commit("setName", payload)。

命名空间：...mapMutations("home", ["setName"])。

替换与新增字段

在 mutation 里可以替换对象、push 数组。Vue 2 上给已有对象新增字段，使用 Vue.set(state.user, "age", 18)，否则新字段不是响应式的。Vuex 4 跑在 Vue 3 上时可以直接加字段。

不要在 mutation 里替换整个 root state。要换某个子树，替换那个字段即可，例如 state.list = payload.list。

订阅

mutation.payload 是这次提交的载荷。订阅用于插件和持久化，不要在订阅里再提交会连锁触发的 mutation，以免递归。subscribe 返回取消函数。
