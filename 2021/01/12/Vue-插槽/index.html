Vue 插槽

2021-01-12
  • Vue
本文总阅读量次

雁字回时，月满西楼。花自飘零水自流。

插槽把模板留给父组件

子组件用 <slot> 留出位置，父组件在使用子组件时填入模板。数据仍按组件边界走：父模板里的表达式看父组件，子组件 <slot> 上的回退内容看子组件。

默认插槽

父组件没填内容时，显示 <slot> 里面的「暂无内容」。填了就整段替换。

具名插槽

Vue 2.6 起使用 v-slot，缩写是 #。旧写法 slot="header" 在 2.6 被标为弃用，Vue 3 已移除。

v-slot 写在 <template> 上。只有默认插槽、且不接收数据时，内容可以直接写在组件标签里。独占默认插槽也可以写在组件标签上：<box-item v-slot="slotProps">。一旦还有具名插槽，默认插槽也要放到 <template v-slot:default> 里。

作用域插槽

子组件把数据交给插槽，父组件决定怎么画。用在表格列、列表项。

Vue 2.6 之前写在真实元素上的 slot-scope 已弃用：

新代码用 v-slot。slot-scope 在 Vue 3 中不可用。

编译后插槽长什么样

Vue 2 普通插槽的内容在父组件作用域编译，子组件用 this.$slots.header 拿到的是 VNode 数组。作用域插槽在 this.$scopedSlots 里，是函数。

Vue 3 取消了这个分裂：$scopedSlots 删除，所有插槽都在 slots 上，并且都是函数。渲染函数里调用 slots.default()、slots.header()。

动态插槽名与禁用继承

<slot> 上的非 props 属性会合并到父组件填入的根元素上。Vue 3 若父组件填入的是多根节点，这些属性没有自动合并目标，Vue 会给出警告，需要在父侧用 v-bind="$attrs" 自己接。

和 props 怎么选

子组件只需要父组件给一份数据，用 props。同一块数据在不同页面要画出不同结构，用作用域插槽，把「数据」留在子组件，把「结构」交给父组件。
