Vue 指令

2021-01-03
  • Vue
本文总阅读量次

往来皆过客，何曾有归人。

指令在模板里做什么

指令是带 v- 前缀的特殊属性。除 v-for、v-slot 等少数语法外，期望值是单个 JavaScript 表达式。表达式的依赖变了，指令会更新 DOM。v-on、v-bind、v-slot 有缩写：@、:、#。

插值 {{ }} 把文本写进节点，也会随数据更新。它只能出现在标签体里，不能用来拼属性，属性要用 v-bind。

文本：v-text 与 v-html

v-text 设置元素的文本内容，会替换该元素内部全部节点，效果接近 textContent。{{ name }} 可以和其它文字混写，v-text 不行。

v-html 按 HTML 写入，等价于写 innerHTML。只用于可信内容。用户昵称、评论、后台富文本若未消毒，会成为 XSS 入口。需要纯文本时用插值或 v-text。

v-once 只渲染一次。v-pre 跳过这块模板的编译，适合原样展示花括号。v-cloak 配合 CSS [v-cloak] { display: none }，避免编译完成前闪出 {{ }}。

v-show 与 v-if

v-show 只切换 display。元素仍在 DOM 里，初次仍会渲染。频繁开关用它更合适。

v-if / v-else-if / v-else 是真正的条件渲染，不满足时不创建节点。切换成本高于 v-show，适合运行期间很少改变的条件。v-else 必须紧跟在 v-if 或 v-else-if 元素后面。

<template v-if> 可以包一组元素，且不会多出一个真实 DOM。

v-for

对象遍历的参数顺序是 (value, key, index)。key 用稳定且唯一的 id。用 index 当 key 时，插入、排序会导致错误复用输入框的状态。

同一元素上 v-if 和 v-for 的优先级，两个大版本相反：

  • Vue 2：v-for 优先于 v-if。v-if 能看到 v-for 的变量，但会在每一项上都判断。要先过滤再渲染时，应使用计算属性。
  • Vue 3：v-if 优先于 v-for。v-if 看不到 v-for 的变量。过滤列表用计算属性，或把 v-for 放到内层元素上。

范围遍历 v-for="n in 10" 从 1 计到 10。

在 <template> 上写 v-for 可以渲染多个根节点而不增加包裹元素。Vue 2 的 <template v-for> 不能带 key，key 要写到真实子节点上；Vue 3 可以把 key 写在 <template> 上。

v-bind 与 v-on

绑定 class、style 时，Vue 会和普通的 class、style 属性合并。

事件修饰符按书写顺序执行：.stop、.prevent、.capture、.self、.once、.passive。按键修饰符如 .enter、.esc。.exact 要求系统键组合完全一致。

v-model

文本框是 :value 加 @input。组件上的约定两个版本不同：Vue 2 是 value + input，Vue 3 是 modelValue + update:modelValue。细节见同系列的《Vue 双向绑定》。

.number 和 .trim 作用在用户输入上，不会回头改你在 data 里已经放好的初始值。

自定义指令

Vue 2 的钩子是 bind、inserted、update、componentUpdated、unbind。

Vue 3 换成与组件生命周期对齐的名字：created（元素还没有父节点，此名容易和组件的 created 混淆）、beforeMount、mounted、beforeUpdate、updated、beforeUnmount、unmounted。旧名字不会被调用。

钩子参数是 el、binding、vnode。binding.value 是指令值，binding.arg 是参数（v-pin:top 里的 top），binding.modifiers 是修饰符。组件上使用指令时，Vue 2 的 el 是组件根元素；Vue 3 片段组件没有单一根元素，指令应写在组件内部的真实元素上。

全局注册用 Vue.directive（Vue 2）或 app.directive（Vue 3）。局部注册写在组件的 directives 选项里。
