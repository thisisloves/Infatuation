React JSX

2021-07-11
  • React
本文总阅读量次

曾经沧海难为水，除却巫山不是云。

JSX 是 createElement 的写法

JSX 会编译成函数调用。经典转换是 React.createElement(type, props, ...children)。React 17 起的新 JSX 转换从 react/jsx-runtime 引入 jsx，**文件里只用 JSX、不用 Hooks 时可以不写 import React**。使用 useState 等仍要按名字导入。

编译后的元素是普通对象：type、props、key。它不是 DOM 节点。渲染器之后才创建 DOM。

表达式和属性

花括号里放任意 JavaScript 表达式，不放语句。if 要写成三元或提前 return。class 写成 className，for 写成 htmlFor，因为它们是 JavaScript 保留字。样式用对象：style={{ marginTop: 8 }}，数值的无单位属性按像素处理的是 DOM 的 style，不是所有字段。

布尔、null、undefined 不产生文本。数字 0 会渲染成字符 0。条件列表要用 count > 0 && <List /> 这种不会把 0 显示出来的判断。

组件和标签

小写开头当成 HTML/SVG 标签字符串。大写开头当成变量里的组件。组件当变量存在作用域里：const Button = ... 然后 <Button />。

props.children 是开始标签和结束标签之间的内容，可以是文本、元素或数组。需要把 children 当函数用时就是 render props，注意那时子元素的类型是函数，不要把它放进 <> 里当节点渲染，除非调用它。

key 不属于 props

key 给 Diff 用，组件里读 props.key 拿不到。要在组件内使用同一份身份，另起一个 prop，例如 id。key 写在直接被遍历的那个元素上。详见《React Diff 算法》。

安全

JSX 的文本子节点会转义，默认不会把字符串当 HTML。dangerouslySetInnerHTML={{ __html }} 才会插入 HTML，内容必须先消毒。不要把用户输入直接放进 __html。
