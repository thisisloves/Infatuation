Vuex State

2021-05-06
  • Vuex
本文总阅读量次

千灯万盏，我只想去有你的那户人家。

单一状态树

state 是一个对象，应用里要共享的数据都放在这棵树上。调试时可以一次看到整份快照。Vuex 的 state 是响应式的：用 Vue 2 时仍受 Object.defineProperty 限制，后加字段要用 Vue.set；用在 Vue 3 上时由 Proxy 追踪。

组件里不要写 this.$store.state.name = "小明"。开启 strict 时这会报错；没开也会绕开开发工具里的 mutation 记录。

在计算属性里读取

计算属性会在依赖的 state 变化后重新求值，模板跟着更新。把 this.$store.state.name 复制到 data 里，之后 store 再变，这份副本不会变。

mapState

多个字段都手写计算属性时，用 mapState 展开到 computed：

数组形式要求计算属性名和 state 字段名相同。对象形式可以改名，值是函数时第一个参数就是模块看到的 state。

mapState 返回的是计算属性定义，所以展开到 computed，不要放到 methods。

模块里的 state

没有命名空间时，子模块的 state 仍然嵌在父 state 上：

读取路径是 this.$store.state.home.name。mapState 默认看根 state，要写成 mapState({ homeName: (state) => state.home.name })，或在命名空间模块上使用 mapState("home", ["name"])。命名空间的写法见《Vuex Module》。

替换整个状态

测试或时间旅行时可以 store.replaceState(newState)。业务代码不要用它来更新某个字段。服务端渲染注水时，通常在创建 store 之后、挂载之前替换一次。

和组件 data 的边界

store 里放登录用户、字典、跨页购物车。当前对话框是否打开、输入框临时字符串，放组件自己的 data。state 要能被序列化，便于调试快照，不要把 DOM 节点、类实例放进去。
