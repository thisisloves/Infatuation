网络 STP

终日两相思，为君憔悴尽，百花时。

STP 解决什么

STP（Spanning Tree Protocol，IEEE 802.1D）在有物理环路的交换网里算出一棵逻辑上无环的树。一部分端口转发，冗余端口阻塞。正在使用的链路断开后，阻塞端口可以转为转发，从而恢复连通。它消除的是二层环路，不选择三层路由。

桥 ID 由优先级和桥 MAC 组成。优先级数值越小越优先，默认 32768。优先级相同再比 MAC，MAC 小的赢。说「优先级 ID 最小」容易把两个字段混成一个。根桥是 root bridge，不是「跟网桥」。

计算过程

  1. 全网选举一个根桥：桥 ID 最小者。
  2. 每台非根桥选出一个根端口：到根桥的路径开销最小。开销相同再比上游桥 ID、端口 ID。
  3. 每个网段选出一个指定端口：由离根更近的那台桥转发这个网段的流量。
  4. 既不是根端口也不是指定端口的端口进入阻塞，只收 BPDU，不转发用户帧。
  5. 拓扑变化时，原先阻塞的端口按状态机进入转发，树重新收敛。

路径开销累加的是端口开销。把某条不想使用的链路上的端口开销调大，可以影响谁被阻塞。

端口状态

状态 收 BPDU 学 MAC 转发用户帧 默认停留
Blocking 是 否 否 最多约 20 秒（Max Age）
Listening 是，也发送 否 否 15 秒（Forward Delay）
Learning 是 是 否 15 秒
Forwarding 是 是 是 稳定转发
Disabled 否 否 否 直到管理上打开

Learning 会把收到的源 MAC 写入地址表，但仍然不转发用户数据。Learning 状态仍不转发用户数据。从阻塞到转发，Listening 加 Learning 约 30 秒；若还要等 Max Age 判定根信息失效，整段收敛可以到大约 50 秒。

RSTP（802.1w）把 Blocking、Listening 和 Disabled 合成 Discarding，并用提议/同意机制让备用端口快速进入转发。端口角色也更明确：根端口、指定端口、替换端口和备份端口。

配置

stp root primary 把优先级调到足够小，使这台交换机成为根桥。secondary 给备份根一个次优优先级。开销改的是「该接口」，不是「改接口」。

接 PC 的端口不会形成交换环路，可以设成边缘端口，省掉 30 秒的 Listening 和 Learning。同时打开 BPDU 保护：一旦边缘端口收到 BPDU，就认为有人接入了交换机，端口被关掉，避免整棵树被重新计算。

命令中间只有一个空格，stp edged-port enable。

注意

  • 根桥应放在拓扑中心、性能稳定的交换机上。谁的 MAC 碰巧最小，谁就当根，流量会绕远。
  • 边缘端口只用于终端。接到另一台交换机却打开边缘端口，会短期形成环路。
  • STP 不限制广播的内容，它只保证活动拓扑无环。VLAN 很多时要用 MSTP，让不同 VLAN 走不同的树，否则所有 VLAN 共用一棵树，备份链路完全空闲。

桥 ID 怎么比

默认优先级都是 32768 时，MAC 较小的交换机会成为根。流量会向这台也许接在边缘的设备集中。stp root primary 把优先级降到 0 或 4096 这一档，让指定的核心交换机当根。secondary 设为 8192 一类的次优值，根失效后由它接替，而不是再退回比 MAC。

路径开销沿根端口累加。把 SW3 的某口开销改成 20000，是让这条口在比较时变差，从而阻塞它，不是在端口上写一个「阻塞」标志。

边缘端口

PC 接入的端口从 Listening 走到 Forwarding 要大约 30 秒，这 30 秒里网卡已经链路 up，DHCP 却发不出去。边缘端口跳过这段学习，链路 up 后马上转发。一旦收到 BPDU，BPDU 保护把端口关掉，因为终端口上不该出现交换机。

注意

  • Learning 学习源 MAC，不转发用户帧。只有 Forwarding 两者都做。
  • 根桥不要靠「谁先开机」决定。优先级应写进配置。
  • RSTP 的替换端口已经知道备份路径，链路断开后可以立即转发，不必再等 30 秒。经典 STP 没有这个角色。

Learning 不转发

Blocking 收 BPDU。Listening 收发 BPDU，仍不学习 MAC、不转发数据。Learning 开始写 MAC 表，用户帧继续丢弃。Forwarding 才转发。从阻塞到转发，两段 Forward Delay 约 30 秒。边缘端口给终端用，可以跳过这 30 秒；收到 BPDU 应被保护机制关掉。根桥写 root，不是「跟网桥」。

桥 ID 先比优先级，数值小的优先，再比 MAC。默认 32768 时，MAC 最小的边缘交换机会变成根，流量绕远。primary 把希望当根的交换机优先级降下来，secondary 作为它失效后的下一位。开销改大是为了在比较路径时输掉，不是在端口上做一个名叫阻塞的开关。
