HTML 元素

  • HTML 文档由元素嵌套而成：开始标签、可选内容、结束标签（空元素除外）。
开始标签 元素内容 结束标签
<p> 这是一个段落 </p>
<a href="default.htm"> 这是一个链接 </a>
<br> 换行 （空元素）
  • 起始标签 / 闭合标签：成对元素中前者为开始，后者为结束。

元素语法要点

  • 元素以开始标签起、结束标签止（空元素在起始标签处结束）。
  • 内容位于起止标签之间；空元素无内容模型上的「内部文本」。
  • 开始标签上可写 属性（name="value" 或布尔属性简写）。

按布局习惯的分类（与 CSS display 相关）

下表多为历史教材列举；其中 center、font、big、strike、acronym、isindex 等已在 HTML5 中废弃或不再推荐使用，新项目请用 CSS + 语义标签替代。

  1. 块级（block）（默认表现概括）
  • 独占一行（默认纵向堆叠）；可设宽高（视具体元素与规范而定）；margin / padding 在块轴上通常较直观。
标签 描述
address 地址
blockquote 块引用
center 居中对齐（废弃）
dir 目录列表（废弃）
div 通用块容器，布局常用
dl 定义列表
fieldset 表单分组
form 表单
h1–h6 标题
hr 主题分隔（横线）
menu 工具栏/菜单（语义随规范演变，需查文档）
ol / ul 有序 / 无序列表
p 段落
pre 预格式化文本
table 表格
  1. 行内（inline）（默认表现概括）
  • 默认在同一行内折行排布。非替换行内元素的垂直 margin 不参与行盒高度；水平 margin 生效。padding / border 会画出背景，纵向往往撑出重叠，需结合 line-height 理解。宽高对多数非替换行内元素无效；替换元素（如 img）可以设尺寸。
标签 描述
a 超链接
abbr 缩写
b / strong b 是无额外重要性的文体偏移；strong 表示内容重要。默认样式都可能加粗
br 换行
code / samp 代码 / 样例输出
em 强调
i 另一种语态、术语或外来语；斜体只是常见默认样式
label 关联表单控件的说明文本
q 行内引用
span 无语义行内容器
sub / sup 下标 / 上标
  1. inline-block 等（由 display 决定）
  • 横向排列、可设宽高，仍参与行内格式化上下文。textarea 的内容模型是短语内容，但浏览器默认把它画成 inline-block，不要放进「垂直外边距无效」的那一类非替换行内元素。
标签 说明
img 替换元素，默认 inline，但可以设宽高
input 多数类型默认 inline-block
textarea 多行文本域，默认 inline-block，不是不能设高的行内盒
button 按钮，默认多为 inline-block

HTML5 里按内容模型看

块级、行内是 CSS 的默认 display，也是旧教材的分法。HTML 现在按内容模型约束谁能包谁：流内容、短语内容、标题内容、嵌入内容、交互内容。div 可以包流内容；p、span 只能包短语内容，所以 p 里不能放 div。

新页面优先用语义元素，而不是表里那些已废弃的 center、dir：

元素 表示
header / footer 页或文章的页眉、页脚，可以不止一套
nav 导航链接区
main 页面的主体。可见的 main 只放一个，且不要套进 article、aside、nav、header、footer
article 可以单独分发的一块，例如一篇帖子
section 文档中的一节，里面通常有标题
aside 和正文相关、但可分开的内容
figure / figcaption 图、代码或引用，以及它的标题
button 按钮。不跳转的操作用它，不要用 div 加点击事件来冒充

menu 在现行规范里表示一组命令（工具栏），条目仍用 li。它不是早期那种目录元素，也不要把它当成 ul 的废弃替代品随手替换。
