HTML SVG

2018-11-02
  • HTML
本文总阅读量次

相顾无相识，长歌怀采薇。

SVG 是什么

  • SVG（Scalable Vector Graphics）用 XML 描述二维图形，放大后边缘仍然清晰。规范在 W3C SVG。
  • HTML 里可以直接嵌一段 <svg>。独立文件用 .svg，再由 img、object 或 CSS 背景引用。HTML5 的内嵌 SVG 可以不写 xmlns，独立文件需要 xmlns="http://www.w3.org/2000/svg"。

特点

  1. 文本可被编辑器、脚本和搜索索引处理，路径也能用脚本改。
  2. 适合图标、示意图、简单图表。节点上千、又要逐帧改属性时，绘制成本会高于一张位图，这时更适合 Canvas。
  3. 默认占位常见是 300×150。写出 width、height 或只留 viewBox 再用 CSS 拉宽，图形才不会被裁掉。

圆

  • cx、cy 是圆心，r 是半径，单位是当前用户坐标系，由 viewBox 决定，不是 CSS 像素。
  • viewBox="minX minY width height" 把这块用户坐标映射到视口。外面的 width / height 改变时，图形按比例缩放。

矩形、线与文字

  • currentColor 跟随外面 CSS 的 color，图标换色时不用改每条属性。
  • 表现属性（fill、stroke）能被 CSS 覆盖。选择器写在页面样式表里即可，特异性按普通 CSS 算，表现属性的权重很低。

多边形

  • points 是一串 x,y。fill-rule: evenodd 让这颗星的中心按奇偶规则挖空；nonzero 会把中心也填上。
  • 更复杂的轮廓用 <path d="...">。M 移动、L 直线、C 三次贝塞尔、Z 闭合。

三种引用方式

方式 结果
内嵌 <svg> 可被页面 CSS 和脚本选中，可加 <title> 做无障碍名称
<img src="icon.svg" alt=""> 作为替换元素，内部节点进不了页面 DOM，页面 CSS 改不了里面的 fill
object / iframe 能加载独立文档，交互和脚本受嵌入策略限制
  • 装饰性图标给内嵌 SVG 加 aria-hidden="true"，或给 img 写空 alt。有含义的图写 <title>，并设 role="img" 与 aria-labelledby。

Canvas 与 SVG

Canvas SVG
位图画布，放大后按像素取样 矢量，缩放仍清晰
画完通常只剩像素，命中检测要自己算 每个图形是节点，能直接听 DOM 事件
大量精灵、逐帧重绘更常见 图标、示意图、需要 CSS 换色的图形更常见
toBlob / toDataURL 导出位图直接 节点很多时，样式与命中的成本上升

常见坑

  • 只写了图形、没写 viewBox，CSS 把 SVG 拉大后图形仍停在默认坐标系的一角，看起来像「缩放失效」。
  • stroke 默认画在路径中线，一半可能落在 viewBox 外被裁掉。留出半个线宽的边，或设 vector-effect: non-scaling-stroke。
  • 内嵌 SVG 里的 id 属于整份 HTML 文档，和页面上的 id 冲突时，<use href="#icon"> 会引用错节点。图标 id 加前缀。

用 use 复用图标

  • <symbol> 自己不绘制，配 viewBox 后被 <use> 引用。href 指向同一文档的片段。外链 SVG 雪碧图还要服务器允许 CORS，否则画不出来。
  • 图标尺寸用 1em 时跟按钮字号走。stroke="currentColor" 让线条颜色等于按钮的 color。
  • 旧写法 xlink:href 已由 href 代替。两份都写只为迁就非常旧的浏览器。

和 CSS 的边界

  • 内嵌 SVG 的 fill 可以用类选择器改。img 引用的 SVG 被当成一张图，页面里的 .icon { fill: red } 进不去。
  • preserveAspectRatio 默认是 xMidYMid meet，图形居中并完整可见。要铺满视口并允许裁切时设 slice。和 CSS 的 object-fit 角色相近，作用在 SVG 视口上。
