端口是什么

传输层用端口区分同一 IP 上的不同进程。TCP 和 UDP 各有一套端口空间，范围都是 0～65535，一共 65536 个。端口 0 保留，实际分配给应用程序的是 1～65535。

端口不等于物理接口，也不是进程号。一个套接字由协议、本机地址、本机端口、对端地址、对端端口共同确定。

三段范围

范围 名称 用法
0～1023 公认端口 绑定熟知服务，如 80 是 HTTP。在类 Unix 上常需要特权才能监听
1024～49151 注册端口 可向 IANA 登记，也常被客户端拿去当临时端口
49152～65535 动态端口 供临时分配。有的系统从 1024 或 32768 就开始分配临时端口，实现并不死守 49152

熟知端口表示惯例，不是协议强制。HTTP 可以改听 8080，只要客户端也去连这个端口。

常见端口

FTP 的 20 和 21 不能对调：21 是控制连接，20 是主动模式下服务器的数据源端口。POP3 是 110；109 是已经淘汰的 POP2。3389 是远程桌面 RDP，不是「超级终端」。超级终端是旧版 Windows 里的串口和 Telnet 客户端。

端口 传输 服务
20 TCP FTP 数据（主动模式）
21 TCP FTP 控制
22 TCP SSH
23 TCP Telnet，明文
25 TCP SMTP，服务器之间投递邮件
53 UDP/TCP DNS。普通查询多走 UDP，大响应和区域传送走 TCP
67 / 68 UDP DHCP 服务器 / DHCP 客户端
80 TCP HTTP
110 TCP POP3
123 UDP NTP
143 TCP IMAP
161 / 162 UDP SNMP 查询 / Trap
179 TCP BGP
443 TCP HTTPS
445 TCP SMB，现代 Windows 文件共享
587 TCP 邮件提交
3306 TCP MySQL
3389 TCP RDP
5432 TCP PostgreSQL
6379 TCP Redis
8080 TCP 常见的 HTTP 备用端口，不是另一个协议

137、138 是 NetBIOS 名字和数据报，多走 UDP；139 是 NetBIOS 会话，走 TCP。现代 Windows 共享主要看 445，不要把三个端口都写成「名字服务」。111 是 RPC portmapper，不是 110。

连接上看见的端口

访问网页时，目的端口是 80 或 443，源端口是客户端临时端口。回复报文把两者对调。服务器可以同时接受成千上万条目的端口为 443 的连接，因为源 IP 和源端口不同。

防火墙规则要写明方向。放行「目的端口 443」允许出去访问 HTTPS；放行「目的端口 3389 且发往本机」才是允许别人远程桌面进来。只记住数字、不看方向，规则会开反。

注意

  • 扫描到端口开放，只说明有进程在听，不说明服务没有访问控制。
  • 同一端口在 TCP 和 UDP 上可以是不同服务。53 两者都是 DNS，是特意对齐，不是普遍规律。
  • 把服务改到非标准端口能减少无意的访问，不能代替认证和加密。Telnet 23、FTP 21 的口令仍然是明文。

一组容易写反的端口

错误记法 实际
20 是 FTP 命令，21 传数据 21 是控制；20 只是主动模式的服务器数据源端口
67 是客户，68 是服务器 DHCP 服务器 67，客户端 68
109 是 POP3 POP3 是 110；109 是 POP2
110 是 RPC portmapper 是 111
3389 是超级终端 3389 是 RDP
最大端口 655535 最大是 65535，从 0 数起共 65536 个

邮件还要分方向。25 是服务器之间的 SMTP。用户提交新邮件常用 587。110 和 143 取信，加密后是 995 和 993。只放行 25，客户端仍可能发不出邮件。

注意

  • 一条连接有两个端口。说「打开 443」时要说明是本机监听，还是允许访问别人的 443。
  • UDP 没有连接，防火墙看到的是双向数据报。放行 DNS 时，回来的响应源端口是 53。
  • 注册端口可以被临时端口占用。服务若绑死 3306 以外的高端口，可能和客户端短暂冲突，所以服务端口应固定，临时端口留给出站。

方向

本机浏览器访问网站，目的端口是 443，源端口是临时端口。防火墙若只放行「源端口 443」，网页出不去，远程桌面却可能误开。3389 是 RDP。21 是 FTP 命令，20 是主动模式数据。DHCP 服务器监听 67，客户使用 68。POP3 是 110，不是 109。

0 保留，1 到 65535 才是可用编号，总数 65536，不是 655535。公认端口 0 到 1023，注册端口到 49151，其余是动态端口。系统也可以从 1024 就分配临时端口，范围是惯例加实现，不是每台机器都从 49152 起跳。

同一数字在 TCP 和 UDP 上可以是不同服务。53 两边都是 DNS，是特意对齐。
