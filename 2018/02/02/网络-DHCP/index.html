网络 DHCP

DHCP 是什么

DHCP（Dynamic Host Configuration Protocol）给主机自动分配 IP 地址、掩码、网关、DNS 等参数。它基于 UDP，服务器端口是 67，客户端端口是 68。DHCP 不是 Windows 安装组件的说明；任何实现只要符合协议就能当服务器或客户端。

它要保证同一时刻一个地址只租给一个客户，也能按管理员的绑定发放固定地址，并和手工配置的主机会共存。设计上还兼容更早的 BOOTP。

三种分配

方式 行为
自动分配 客户第一次拿到地址后长期使用
动态分配 地址带租期，到期或客户释放后可以分给别人
手工分配 管理员按 MAC 绑定地址，DHCP 只负责告诉客户

现网最常见的是动态分配加重少量绑定。

DORA

客户和服务器用事务号 xid 配对。发现阶段的目的 IP 是 255.255.255.255，帧也是广播，因为客户还没有可用地址。

  1. 客户广播 DHCPDISCOVER，寻找服务器。
  2. 收到的服务器各自回 DHCPOFFER，里面带拟分配的地址和参数。
  3. 客户选一个提议，广播 DHCPREQUEST。广播有两个作用：告诉被选中的服务器「我用你的地址」，也告诉其余服务器收回提议。
  4. 被选中的服务器回 DHCPACK，客户才把地址配上接口。若请求不合法，服务器回 DHCPNAK，客户重新发现。

客户在使用地址前常用 ARP 探测冲突。发现别人已在用，就发 DHCPDECLINE，再重新申请。不用时可以发 DHCPRELEASE 归还。

报文 作用
DHCPDISCOVER 客户寻找服务器
DHCPOFFER 服务器给出地址和参数
DHCPREQUEST 客户请求选定的地址，或续租
DHCPACK 服务器确认
DHCPNAK 服务器拒绝
DHCPDECLINE 客户发现地址冲突
DHCPRELEASE 客户归还地址

租期

租期到 50%（T1）时，客户单播 DHCPREQUEST 给原服务器续租。若到 87.5%（T2）仍未成功，改为广播，向网上任何服务器续租。租期耗尽仍无 ACK，客户必须停用该地址并重新 DISCOVER。续租失败不一定是因为「别的客户抢先占用」，服务器拒绝、服务器不可达都会走到 T2。

服务器和客户在同一网段

接口地址池由接口地址决定网段。全局地址池要写清楚网络、网关和 DNS。命令是 dhcp，不是 dhep；地址中间不能加空格。

接入交换机只需要把终端划进对应 VLAN，并把上联做成 trunk。DHCP 跑在三层接口上。

不在同一网段：中继

广播过不了路由器。客户网段的三层接口要做 DHCP 中继，把广播改成发往服务器的单播，并写上 giaddr，服务器据此选择地址池。中继可以由路由器或三层交换机完成，不是只有路由器可以。

服务器上为 192.168.10.0/24 建地址池，网关填中继接口 192.168.10.1，并写一条回程路由，下一跳是 10.10.10.1。没有回程路由，ACK 到不了客户所在网段。

端口和续租

客户端用 UDP 68，服务器用 UDP 67，方向写反则抓包对不上。租期过半时单播续租，到 87.5% 仍失败才广播。命令是 dhcp select，不是 dhep。地址中间不能加空格。中继接口要填写服务器地址，服务器要有回到客户网段的路由，下一跳不是「下一条」。

DISCOVER 和 REQUEST 在客户还没有确定地址时用广播。OFFER 和 ACK 可以单播，也可以在客户要求广播时广播。事务号 xid 用来把应答配回那一次请求。客户在使用地址前若 ARP 发现冲突，发送 DECLINE，然后重新发现。不用的地址用 RELEASE 归还。
