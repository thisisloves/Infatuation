CSMA

CSMA（Carrier Sense Multiple Access，载波侦听多路访问）让多个设备共用一条信道：发送前先听，信道忙就等待，信道空闲才发送。多路访问指这些设备都有权使用同一介质。

只做载波侦听仍会碰撞。两台设备同时听成空闲，就会一起发送。CSMA/CD 在发送过程中发现碰撞，CSMA/CA 尽量在发送前避开碰撞。

CSMA/CD

载波侦听多路访问/碰撞检测用于传统共享式以太网和半双工链路。

  1. 发送前侦听。介质空闲就发送；忙则继续听，直到空闲。退避等待的长度由算法决定。
  2. 发送期间继续听。若两路信号叠在一起，就检测到碰撞。
  3. 立即停止发送数据，并发送 32 位强化碰撞的 jam 信号，让所有站点都知道发生了碰撞。
  4. 按截断二进制指数退避，随机等待若干时隙后再从第 1 步开始。连续失败 16 次则丢弃这一帧，并向上层报告。

口诀是：先听后发，边发边听，碰撞停发，随机再发。

10 Mbit/s 和 100 Mbit/s 以太网的时隙是 512 比特时间，最短帧 64 字节。帧必须足够长，发送方才能在发完之前听到最远处赶回来的碰撞。这就是共享以太网有长度和距离限制的原因。全双工交换式以太网每个方向独占介质，不再使用 CSMA/CD。

共享介质上的会议

一间屋子里每个人都只能听见别人。发言前先听，屋里安静才开口，这是载波侦听。每个人都有权开口，这是多路访问。两个人同时说，谁也听不清，这是碰撞。说话时发现撞车就停下来，随机等一会儿再试，试太多次就放弃。这个比方对应 CSMA/CD，不对应无线网络：无线站点往往不能一边发一边听自己造成的碰撞。

CSMA/CA

CSMA/CA（Collision Avoidance）用于 802.11。无线设备通常不能边发边检测碰撞，而且存在隐藏终端：A 和 C 都听不见对方，却都能被 B 听见。

  1. 侦听到信道空闲后，还要等一个帧间间隔，再加一段随机退避，不是一空闲就立刻发送。
  2. 可选地先发送很短的 RTS，接入点或对端回 CTS。听到 CTS 的站点会设置网络分配矢量，在这段时间里保持沉默。
  3. 数据帧发出后，接收方若校验通过，经过 SIFS 回 ACK。发送方收不到 ACK，就认为失败并重试。
  4. 没有 ACK 不等于一定检测到了电信号上的碰撞，所以上层看到的是「没确认」，不是 CD 那种即时碰撞。

RTS/CTS 是可选机制，短帧或网络关闭这项功能时不会每次都发。

CD 与 CA

CSMA/CD CSMA/CA
重点 发出去之后检测碰撞 发送前退避，并等待确认
典型介质 半双工同轴或双绞线以太网 无线局域网
碰撞之后 jam，截断二进制指数退避 收不到 ACK 再退避重传
全双工交换以太网 不再使用 不涉及

两者都先侦听。差别是：有线共享以太网相信发送方能听见碰撞；无线网络更多依靠退避、帧间间隔和 ACK。

退避怎么数

以太网碰撞 k 次后，等待的时隙数在 0 到 2^m - 1 之间均匀随机，m = min(k, 10)。第 1 次碰撞等 0 或 1 个时隙，第 10 次以后上限不再翻倍，第 16 次仍失败就放弃这一帧。10 Mbit/s 以太网一个时隙是 51.2 微秒。

上限截断是为了让重试不要无限拉长；16 次放弃是为了让故障链路不要永远占着发送队列。

无线里听不见的两种情况

隐藏终端：A 和 C 互不在载波范围内，却都向 B 发送。A 听成空闲，C 也听成空闲，碰撞发生在 B。RTS/CTS 让 C 听见 B 发出的 CTS 后保持沉默。

暴露终端：A 向 B 发送时，C 听见了 A，于是不敢向另一侧的 D 发送。C 其实不一定会干扰 B。CSMA/CA 会误伤这种并发，吞吐低于「所有听得见的站点真的都不能同时发」的理想情况。

注意

  • 全双工交换机每个端口独占收发，不需要 CSMA/CD。抓包里看不到碰撞，不代表链路没有其他问题。
  • 无线速率越高，同样一次退避占用的空气时间越短，但前导码和 ACK 的开销占比会变大。
  • 把有线的「边发边听」直接搬到无线网卡上做不到：自己的发射功率会淹没收回来的碰撞信号。

帧太短会怎样

10 Mbit/s 以太网要在发完帧之前听见最远 2500 米处折返的碰撞，所以最短帧定成 64 字节，时隙 512 比特。帧更短时，发送方已经传完并认为成功，碰撞才回到本地，这一次碰撞就检测不到。交换式全双工取消了这个限制，短帧不再为了碰撞检测而填充，但以太网帧头尾的最小长度习惯仍在。

无线没有这个「边发边听」的距离公式。它用 ACK 超时判断失败，超时时间要盖住帧间间隔和一次往返，而不是盖住同轴电缆上的传播延迟。

一次碰撞的时间线

两台机器同时判定空闲并发送。信号在电缆中点相遇，各自再过半个传播延迟才发现异常，于是停止数据、发出 32 比特 jam，然后按第 1 次碰撞的规则在 0 或 1 个时隙里选一个再试。若再次同时选中 0，就发生第 2 次碰撞，候选范围变成 0 到 3。这个过程只出现在半双工共享介质上。

步骤 CSMA/CD CSMA/CA
发送前 听到空闲就发 空闲后再退避
冲突 边发边听，发出 jam 多数时候听不见，靠无 ACK
重试 截断二进制指数，最多 16 次 同样退避，窗口由无线标准规定
适用 半双工以太网 802.11

全双工交换以太网两边可以同时收发，碰撞域消失，CD 的最短帧限制不再为了检测碰撞而存在。
