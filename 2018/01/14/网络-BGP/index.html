网络 BGP

  • 网络
本文总阅读量次

欲寄彩笺兼尺素，山长水阔知何处。

BGP 的位置

BGP（Border Gateway Protocol）是自治系统之间使用的外部网关协议。OSPF、IS-IS、RIP 是内部网关协议，负责一个 AS 内部的路径。BGP 的重点不是发现一条链路的带宽，而是按策略选择和传播路由。它是路径矢量协议：路由带着经过的 AS 列表。把它叫成普通距离矢量，就丢掉了 AS_PATH 这个防环的核心。

AS 之间交换的是前缀和属性，用来构造 AS 级拓扑，并消除路由环路。

运行特点

  1. BGP 使用 TCP 179。对等体要先有 TCP 连通，本地端口任意，目的端口 179。TCP 提供可靠传输，BGP 自己不再做报文重传。
  2. 支持 CIDR，通告的是前缀而不是分类网络。
  3. 稳定之后只发送变化的路由，适合承载互联网上的大量前缀。
  4. 收到的 AS_PATH 里如果已经有自己的 AS 号，就丢弃该路由，从而避免 AS 之间的环路。
  5. 从 IBGP 学到的路由，不向其他 IBGP 对等体再通告。这是 IBGP 水平分割，避免 AS 内部的控制平面环路。数据包在 AS 内怎么转发，由 IGP 决定，不是「BGP 学到的路由不在 AS 内转发」。
  6. 可以用策略过滤、修改属性。路由抖动抑制用来降低前缀反复撤销带来的振荡。

早期的 IGP 与 BGP 同步要求：IBGP 路由只有在 IGP 里也能找到时才向 EBGP 通告。现代网络默认关闭同步，靠全网状 IBGP 或路由反射器保证转发下一跳可达。

四种报文

报文 作用
OPEN TCP 建立后的第一份报文，协商版本、AS 号、Router ID 和保持时间
KEEPALIVE 周期发送，维持会话，默认约 60 秒
UPDATE 通告可达前缀，或撤销不可达前缀
NOTIFICATION 发现错误后发送，随后会话断开

邻居状态

状态 含义
Idle 初始状态，拒绝接受连接，准备发起 TCP
Connect 正在等待 TCP 完成。成功则进 OpenSent；失败则进 Active
Active 正在重试 TCP。这里的 Active 是「活跃地重连」，不是「行动」
OpenSent 已发送 OPEN，等待对端 OPEN
OpenConfirm OPEN 已接受，等待 KEEPALIVE
Established 会话建立，可以交换 UPDATE

OPEN 检查失败会发 NOTIFICATION 并回到 Idle。保持时间超时同样回到 Idle。

通告原则

  1. 到同一目的有多条路径时，只把选出的最佳路径放进路由表并通告出去。多路径负载分担是额外配置。
  2. 从 EBGP 学到的最佳路由，可以通告给 EBGP 和 IBGP 对等体。
  3. 从 IBGP 学到的路由，不通告给其他 IBGP 对等体。路由反射器和联盟是例外。
  4. 对端支持路由刷新且发来 REFRESH 时，本端把相应路由重新通告一遍。
  5. 平滑重启结束时，重启方会重新通告自己的 BGP 路由。

IBGP 不通告给 IBGP，所以一台边界路由器从外部学到的路由，AS 深处的路由器看不见，除非每台 BGP 路由器两两建立 IBGP，或使用路由反射器。反射器把从一个客户学到的路由反射给其他客户，并用 CLUSTER_LIST、ORIGINATOR_ID 防环。

选路与属性

思科设备上常见的比较顺序可以收成：最高 Weight，最高 LOCAL_PREF，本地发起优先，AS_PATH 更短，ORIGIN 中 IGP 优于 EGP、优于 incomplete，MED 更低，EBGP 优于 IBGP，IGP 度量更小，Router ID 更小。Weight 是思科私有的，不是所有实现都有。

类别 属性 作用
公认必遵 ORIGIN 路由从哪来：IGP、EGP 或 incomplete
公认必遵 AS_PATH 经过的 AS 序列，用于选路和防环
公认必遵 NEXT_HOP 到达前缀的下一跳。EBGP 通告时，下一跳一般是通告者自己；IBGP 默认不改下一跳，所以内部要有到该下一跳的 IGP 路由，或配置 next-hop-self
公认自决 LOCAL_PREF 本 AS 出口偏好，越大越优先，只在 AS 内传递
公认自决 ATOMIC_AGGREGATE 说明做过聚合，明细信息已不可见
可选传递 AGGREGATOR 谁做的聚合，带 AS 号和 Router ID
可选传递 COMMUNITY 一组标记，供下游策略使用
可选非传递 MED 建议相邻 AS 从哪个入口进来，越小越优先。默认只比较来自同一相邻 AS 的 MED
可选非传递 ORIGINATOR_ID、CLUSTER_LIST 路由反射防环

注意

  • 先有 IGP 或静态路由让 TCP 能通，BGP 会话才建得起来。BGP 不负责发现直连邻居的 IP。
  • 通告一条前缀，并不自动把自己的整张 IGP 表泄露出去。通告什么由 network、重分布和策略决定。
  • AS_PATH 能挡住 AS 级环路。AS 内部的转发环路要靠 IGP 自己避免。

下一跳在 AS 内不变

EBGP 邻居 203.0.113.1 把 198.51.100.0/24 通告进来，NEXT_HOP 是 203.0.113.1。这台边界路由器再通过 IBGP 告诉内部路由器时，若不改下一跳，内部路由器要自己知道怎么到达 203.0.113.1。这条可达性来自 IGP 或静态路由，不是来自 IBGP 又通告一次。

配了 next-hop-self 之后，IBGP 里的下一跳改成边界路由器自己，内部只要能到达边界路由器即可。两种做法都可以，不能假设 IBGP 会自动把下一跳改成「告诉我的那台路由器」。

注意

  • 从 IBGP 学到的路由不再发给其他 IBGP。要让全网看见外部前缀，就用全互联或路由反射器。
  • Active 状态是 TCP 还没连上，不是会话已经可以更新路由。能通告 UPDATE 的只有 Established。
  • MED 默认不在不同的相邻 AS 之间比较。只把 MED 调低，不一定能吸引所有上游。

路径矢量

BGP 带着 AS_PATH。自己的 AS 号已经在路径里就丢弃，用来消除环路，而不是「清洗」。从 IBGP 学到的路由不向其他 IBGP 对等体通告，说的是路由信息，不是数据包不在 AS 内转发。Active 表示正在重试 TCP，会话能更新路由时状态是 Established。

EBGP 通告进来的下一跳通常是对方的接口地址。IBGP 默认不改这个下一跳，内部路由器必须能通过 IGP 到达它，或者在边界上配置 next-hop-self。Weight 是思科私有属性，不是所有实现的第一步。MED 越小越优先，而且默认只比较来自同一个相邻 AS 的 MED。
