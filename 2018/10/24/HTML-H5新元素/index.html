HTML5 新元素

2018-10-24
  • HTML
本文总阅读量次

如花美眷，似水流年，回得了过去，回不了当初。

这些元素解决什么

  • HTML5 起补充了画布、媒体、表单和章节语义。标签名表达「这块是什么」，具体外观仍由 CSS 决定。下面按用途列出至今仍应认识的元素，并标出已经退出规范的名字。

画布与媒体

标签 描述
<canvas> 位图绘图表面，用 Canvas 2D 或 WebGL 绘制
<audio> 音频
<video> 视频
<source> 为 audio / video / picture 提供一份候选资源
<track> 字幕、章节等文本轨道
<embed> 嵌入外部内容。能力取决于浏览器，不要用它代替 video
<picture> 按 media / type 为 img 选择不同图片源

表单

标签 描述
<datalist> 配合 <input list="id"> 给出可选建议，用户仍可输入别的值
<output> 展示计算结果，用 for 指向参与计算的控件
<meter> 已知上下限的测量，如磁盘占用。写 min、max、value
<progress> 任务进度。有 max 时为确定进度，省略 value 时为进行中
<keygen> 已从 HTML 移除，密钥生成改由平台 API 完成
  • meter 描述静态量，progress 描述一件事做到哪了。磁盘已用 70% 用 meter，上传进度用 progress。

章节与文本

标签 描述
<article> 可以单独转发、复用的一块，如博文、评论
<section> 文档里的一节，通常配自己的标题
<nav> 一组导航链接。页脚里的几条法律链接不必包一层 nav
<aside> 侧栏、引语、和正文松散相关的内容
<header> 页或某一节的头部，可包含标题与导语
<footer> 页或某一节的尾部
<main> 页面的主体，一份文档里放一个，不要放进 article 以外的重复区域
<search> 搜索区域。里面通常是表单，元素本身表示「这里是搜索」
<figure> 插图、代码、图表等自包含单元
<figcaption> figure 的说明，作为第一个或最后一个子元素
<mark> 引用时的高亮，或搜索命中。不是普通的「这里用黄色笔」
<time> 日期或时间，机器可读的值放在 datetime
<ruby> / <rt> / <rp> 旁注，如拼音。rp 是不支持 ruby 时显示的括号
<bdi> 隔离双向文本，避免用户名里的阿拉伯文把后面的标点方向带跑
<wbr> 建议的软换行点，长单词或长 URL 可以在这里断开
<details> 折叠详情，不写脚本也能展开
<summary> details 的可见摘要，必须是它的第一个子元素
<dialog> 对话框。showModal() 打开模态层，配合 ::backdrop 画遮罩
<template> 不渲染的模板，内容用脚本克隆。里面的 img 不会因此发起请求
<command> 早期草案元素，交互控件用 button

怎么选 article 和 section

  • 一块内容拿走后仍然读得通，用 article。只是长文里的一节，用 section，并给它一个标题。
  • 没有标题的盒子用 div。section 不是 div 的同义词，大纲算法依赖标题来标识这一节。
  • header / footer 可以出现在 article、section 里面，表示这一节自己的头尾，不限于整页。

常见坑

  • <main> 里不要再套站点级的 header 导航重复件。一个页面保留一个 main。
  • <dialog> 用 show() 是非模态，用 showModal() 才有焦点圈定和 ::backdrop。把 open 写死在标签上时，它一开始就可见。
  • <time datetime> 用机器格式（2017-03-05 或带时区的时刻）。标签里的可见文字可以本地化，二者不必逐字相同。
  • 废弃元素 font、center、big、strike、acronym 不要出现在新页面里。对齐、字号、删除线交给 CSS，缩写用 abbr。

picture 与 template

  • <picture> 里最后的 <img> 是必须的，它负责 alt、尺寸和真正显示的那张图。浏览器按 source 顺序挑第一份支持的类型，选不中就用 img 的 src。
  • srcset 还可以按宽度描述符（400w、800w）配 sizes，那是同一张图的不同分辨率，和 picture 换格式、换裁切可以叠在一起用。
  • <template> 里的标记不会显示，脚本用 template.content.cloneNode(true) 复制出来再插入文档。克隆之后里面的 img 才会请求。

dialog 的开关

  • method="dialog" 的提交会关闭对话框，并把按下的按钮的 value 放到 dialog.returnValue，不会真的导航。模态框用脚本调用 showModal()，按 Esc 会关闭并触发 cancel 事件。
  • 打开期间焦点应留在对话框内。浏览器对 showModal() 会做一层焦点圈定，自己用 div 模拟遮罩时，这些行为都要补上。
