HTML 是什么

HTML（HyperText Markup Language，超文本标记语言）描述网页结构。浏览器解析之后，与 CSS、JavaScript 一起呈现页面。结构放 HTML，外观放 CSS，行为放脚本。用表格或废弃标签去排版，后面会难以改。

文档骨架

  1. <!DOCTYPE html>：文档类型声明，让浏览器用标准模式。它不是元素，也不区分大小写。
  2. <html>：根元素。lang 告诉辅助技术和浏览器这段文字是什么语言。
  3. <head>：元数据。<meta charset="UTF-8"> 应出现在文档前 1024 字节里，否则浏览器可能已经按错误编码猜过一遍。
  4. <title>：文档标题，用在标签页、书签和搜索结果，不会显示在页面正文里。
  5. <body>：可见主体。
  6. <h1> 到 <h6>：标题层级，不要为了字号跳级。
  7. <p>：段落。

文件实际保存的编码要和 charset 一致。UTF-8 的文件若声明成 GBK，中文会乱码。

标签、元素、属性

标签是尖括号里的记号，例如 <p>、</p>。元素通常是开始标签、内容、结束标签这一整段：<p>这是一个段落</p>。属性写在开始标签上，推荐把值放进引号：<a href="https://example.com">。布尔属性存在即为真，例如 <input disabled>。

HTML 里标签和属性名不区分大小写。XHTML 要求小写并且严格闭合。现在写页面按 HTML 来，不要把 XHTML 的规则当成 HTML5 的语法错误。习惯上仍然全部小写。

空元素没有结束标签，也不能包内容。常见的有 br、img、input、meta、link、hr。HTML 里写成 <br> 即可，<br /> 也接受，那是为了迁就 XML 写法，不是更正确。

注释是 <!-- 说明 -->，里面不要再写 --。注释不会显示，但会随页面源码下载，不要往里放口令。

<、>、& 在正文里要写成 &lt;、&gt;、&amp;。属性值里的引号冲突时用 &quot;。

页面结构示意

一个页面通常再分成页眉、主体和页脚。这些区域用 header、main、footer 表示，具体元素见下一篇。div 只在没有更合适的语义时使用。

HTML 4.01 是 4.0 的修订，不是两个并行的语言。2014 年的 W3C 推荐标准是一个时间点；浏览器现在跟随 WHATWG 的活标准。新页面只写 <!DOCTYPE html>。

注意

  • 能显示不等于写对了。浏览器会补结束标签、挪走不该嵌套的元素。p 里面不能放 div，a 里面不能再放 a。
  • h1 到 h6 表示大纲，不是六种字号。样式用 CSS 改。
  • 字符实体、属性引号和 DOCTYPE 都是源码的一部分。少了 DOCTYPE 或编码声明，页面会在别人的浏览器里变成另一套盒模型或另一套汉字。
