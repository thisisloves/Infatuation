属性写在开始标签上

  • 属性给元素补元数据或行为，形式是 name="value"。HTML 里属性名不区分大小写；放到 XML/XHTML 或 SVG 的 XML 解析里则区分。
  • 值用双引号或单引号包起来。无空格、无 =、无引号的短值可以不写引号，遇到空格就会被截断，所以统一加引号。
  • 未知属性不会让页面报错，浏览器忽略不认识的名字。自定义数据用 data-*，不要自造裸属性。

布尔属性看「在不在」

  • hidden、disabled、checked、readonly、required、multiple、autofocus 等是布尔属性。出现即为真，值和名字相同或为空字符串也都是真。
  • hidden="false"、disabled="disabled" 都是真。要关掉，从标签上删掉该属性，或用脚本的 element.hidden = false / removeAttribute。
  • 用 setAttribute("hidden", "false") 仍然会隐藏元素。

常见全局属性

属性 说明
class 一个或多个类名，用空格分开，供 CSS 和脚本选取
id 文档内唯一。不能含空格。给 <label for>、片段链接和脚本用
style 行内 CSS，特异性高，难维护
title 补充说明。是否弹出提示由浏览器决定，不能当作唯一的说明文字
lang 这段内容的语言，BCP 47，如 zh-CN。影响换行、字体和读屏
dir ltr、rtl 或 auto
data-* 自定义数据。data-user-id 在 dataset 里是 userId
hidden 不显示。用户代理样式相当于 display: none，作者样式仍可能把它改成可见
tabindex 0 按 DOM 顺序进入 Tab 序列；正整数会打乱顺序，尽量不用；-1 可被脚本聚焦，但不进 Tab 序列
contenteditable 元素内容可编辑
draggable 是否允许拖拽
spellcheck 是否检查拼写
inert 元素及其后代不可聚焦、不可点击，读屏也会跳过
translate yes / no，提示机器翻译要不要动这段文字

只属于某些元素的属性

  • href 用于 a、link、area；src 用于 img、script、video 等；alt 是 img、area 的替换文本，图片加载失败或读屏时用它，装饰图写 alt=""。
  • type 在不同元素上含义不同：input 的类型、script / source 的 MIME、ol 的编号样式。
  • for 把 label 绑到控件的 id。包住控件时可以不写 for，一个标签里放两个控件时必须写。

data-* 与 dataset

  • dataset 的值永远是字符串。数字要自己转换。属性名不要用 xml 开头，也不要在 data- 后面直接写大写字母。

常见坑

  • 同一文档里两个相同 id，getElementById 和片段链接只能稳定命中第一个，CSS 选择 #id 的行为也会变怪。
  • class 以数字开头在 CSS 里要转义，类名用字母起头。
  • tabindex 大于 0 会把这项插到所有 0 之前，后面的页面结构一变，焦点顺序就和视觉顺序分家。
  • title 在触摸屏上往往没有悬停，关键信息要写进可见文本或 aria-describedby。
  • 全局属性 slot、popover、part 分别服务 Web Components 插槽、弹出层和样式穿透，用到对应能力时再查文档，不必堆在每个标签上。

属性与 DOM 属性不是同一个值

  • HTML 属性是标签上的初始文本。DOM 属性是脚本看到的当前状态。input 的 value 属性对应默认值，用户输入改的是 DOM 的 value 属性，getAttribute("value") 仍可能是最初那份。
  • checked、selected 同样：属性表示初始是否选中，脚本读 element.checked 才是现在的状态。
  • setAttribute("class", "on") 会整段替换类名。只增删一个类时用 classList.add / classList.remove，避免把别的类一起擦掉。

ARIA 不是用来代替语义标签的

  • 能用 button、a、label 表达的，就不要只放一个 div 再加 role。ARIA 补浏览器还不认识的语义，补不上键盘行为。
  • aria-label 会盖过元素内部的可见文字，两者不一致时读屏只报标签。可见文字已经说清楚时，不必再写一遍。
  • alt、label、aria-labelledby 指同一控件时，优先让可见标签和可访问名称一致。
