网络 IP 地址

2018-04-09
  • 网络
本文总阅读量次

沉舟侧畔千帆过，病树前头万木春。

IP 地址做什么

IPv4 地址是 32 位逻辑地址，写成四个 0～255 的十进制数，例如 192.168.1.10。它标识接口在网络层的位置，用来屏蔽不同链路的物理地址差异。写信要门牌号，发 IP 分组要目的地址，这个类比只说明「逻辑位置」，不说明地址如何分配。

当前全球单播地址由 IANA 分给各地区互联网注册机构（RIR），再逐级分给运营商和用户。InterNIC 是 20 世纪 90 年代的名称，不能当成现在的分配机构。

32 位从左到右是网络位在前、主机位在后。点分十进制只是写法：把每 8 位换成十进制。

分类编址

分类编址看第一个字节的高位。下面的范围是整个类别，包含该类别里的网络地址和广播地址，不是「可分配给主机的起止」。

类 高位 范围 默认掩码 用途
A 0 0.0.0.0～127.255.255.255 /8 大型网络；0/8 保留，127/8 环回
B 10 128.0.0.0～191.255.255.255 /16 中型网络
C 110 192.0.0.0～223.255.255.255 /24 小型网络
D 1110 224.0.0.0～239.255.255.255 无主机位 组播
E 1111 240.0.0.0～255.255.255.255 无 保留，实验用

A 类里真正可做单播的是 1.0.0.0～126.255.255.255。127.0.0.1 是本机环回，不能写成「1.0.0.1 到 127.255.255.254」。

D 类组播地址表示一组愿意接收该组数据的接口，没有网络号和主机号，也不能当源地址。255.255.255.255 落在 E 类的数值范围里，含义却是本链路广播，不是实验单播。

在一个具体网段里，主机位全 0 是网络地址，主机位全 1 是定向广播，这两个不能配给主机。例如 192.168.1.0/24 的可用主机是 192.168.1.1～192.168.1.254，共 2^8 - 2 = 254 个。

私有地址与特殊地址

私有地址只保证在机构内部唯一，不能直接在公网路由。出公网要做地址转换（NAT）。

块 范围 等价写法
A 类私有 10.0.0.0～10.255.255.255 10.0.0.0/8
B 类私有 172.16.0.0～172.31.255.255 172.16.0.0/12
C 类私有 192.168.0.0～192.168.255.255 192.168.0.0/16

172.16.0.0/12 的前缀是 12 位，第二字节只覆盖 16～31，一共 2^20 个地址。写成 172.16.0.0/16 会把 172.17.0.0 以后划出去。

地址 含义
0.0.0.0 源地址表示本机地址未知；路由表里表示默认路由；套接字上表示监听所有本地地址
127.0.0.0/8 环回，不离开本机
169.254.0.0/16 链路本地，DHCP 失败时自动配置
100.64.0.0/10 运营商级 NAT（CGNAT），不是 RFC 1918 私有地址
192.0.2.0/24 等 文档用例（另有 198.51.100.0/24、203.0.113.0/24），不能当真实业务地址
255.255.255.255 本链路受限广播，路由器不转发
目的网络广播 主机位全 1，例如 192.168.1.255/24；许多路由器默认不转发定向广播

掩码与超网

掩码中连续的 1 对应网络位，连续的 0 对应主机位。把地址和掩码做按位与，得到网络地址：

子网是向主机位借位，把一个大网切成若干小网。超网相反，用更短的前缀把多个小网合成一个大网。192.168.0.0/24 与 192.168.1.0/24 的前 23 位相同，可汇总为 192.168.0.0/23。192.168.1.0/24 和 192.168.2.0/24 不能汇总成 /23，因为它们不在同一个 23 位边界上。

分类地址已经不够用，现网用 CIDR，地址一律写成「地址/前缀长度」。可用主机数仍是 2^主机位 - 2（/31、/32 另说，见子网划分）。

注意

  • 一个接口可以有地址，一台主机可以有多个接口，所以「一台主机一个 IP」并不严格。
  • 公有、私有是使用范围，A/B/C 是历史分类，两者不是同一套划分。10.1.1.1 既是 A 类形状，也是私有地址。
  • IPv6 是 128 位，写成 8 组十六进制。本文的分类和私有范围都只针对 IPv4。

和 MAC 怎么分工

MAC 只在一条二层链路上标识接口，帧出了这台交换机就会被换掉。IP 标识网络层位置，路由器按它选路。更换网卡通常改变 MAC，地址规划不变则 IP 不变；主机换到别的网段，IP 必须改，MAC 可以不动。

同一网段里，发送前用 ARP 把下一跳 IP 变成 MAC。跨网段时，源主机解析的是网关的 MAC，目的 IP 仍然写远端主机。没有 IP 也能在本地二层互传，跨网络则靠 IP，而不是把 MAC 一直带到远端。

源地址若是组播或广播，中间设备应丢弃。环回地址 127.0.0.1 的分组也不会出现在网线上。
